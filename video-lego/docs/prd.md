## 1. 产品概述

### 1.1 产品愿景

用代码批量生产「一分钟学会 MIT 线性代数」风格的 60 秒黑板快闪知识视频。

每个概念作为**知识单元**整体呈现在一屏黑板上：中文名 + 英文名 + 别名 + 公式 + 2D 图解 + 一句话释义。

### 1.2 核心价值

| 维度 | 手工（剪映） | 代码（BlackboardFlash） |
|------|-------------|----------------------|
| 单条时间 | 30-60 分钟 | 数据编写 5 分钟 + 渲染 30 秒 |
| 批量效率 | 不可能 | 10 条 / 10 分钟 |
| 公式渲染 | 截图粘贴，模糊 | KaTeX 矢量渲染 |
| 中英文+别名 | 手动排版 | 结构化数据自动排版 |
| 2D 图解 | 找图/画图 | React SVG 组件库复用 |
| 视觉一致性 | 每条不同 | 主题系统统一 |

## 2. 用户故事

### 2.1 Epic 列表

| Epic | 描述 |
|------|------|
| E-01 | 黑板布局 — `BlackboardLayout` 组件 |
| E-02 | 知识单元 — `KnowledgeUnit` 积木（一屏整体呈现） |
| E-03 | 示例视频 — MIT 线性代数 60s |

### 2.2 用户故事

**US-01: 知识单元整体呈现**
> 作为 AI 视频编导，
> 我想要每个概念（如「特征值」）在一屏黑板上同时展示中文名、英文名、别名、公式、图解、释义，
> 以便观众在 4-6 秒内获得一个概念的全貌。

验收标准：
- Given 一个知识单元数据 `{zhName: '特征值', enName: 'Eigenvalue', aliases: ['固有值'], formula: 'Ax=\\lambda x', diagram: 'EigenDiagram', explanation: '矩阵作用后方向不变的向量'}`
- When Remotion 渲染该知识单元
- Then 一屏黑板上整齐展示所有 6 个维度

**US-02: 逐元素入场动画**
> 作为 AI 视频编导，
> 我想要每个维度按顺序入场（中文→英文→别名→图解→公式→释义），
> 以便产生节奏感和视觉冲击。

验收标准：
- Given 知识单元时长 5 秒
- When 渲染
- Then 0-0.3s 中文弹入 → 0.3-0.6s 英文滑入 → ... → 4.5-5.0s 整体淡出

**US-03: 黑板背景**
> 作为 AI 视频编导，
> 我想要全屏深色磨砂黑板背景，
> 以便视觉上有「教室板书」的高级感。

验收标准：
- Given `layout: 'blackboard'`
- When 渲染
- Then 背景为墨绿/深灰 + 噪点纹理

**US-04: 60 秒 MIT 线性代数示例**
> 作为 AI 视频编导，
> 我想要一个可直接预览的 MIT 线性代数 60s 示例视频数据文件，
> 以便验证整个系统端到端可用。

验收标准：
- Given `npx remotion preview` 启动
- When 选择 `linear-algebra-flash` composition
- Then 60 秒内展示 10-12 个线性代数知识单元，动画流畅

## 4. 验收标准

### 4.1 功能验收

1. `npx remotion preview` 可预览「MIT 线性代数」60s 黑板快闪视频
2. 每个知识单元一屏整体呈现：中文 + 英文 + 别名 + 公式 + 图解 + 释义
3. 逐元素入场动画节奏感强
4. KaTeX 公式渲染正确
5. 60 秒展示 10-12 个知识单元
6. 现有 KNN split 视频不受影响
7. TypeScript 无编译错误

### 4.2 非功能验收

1. 渲染 < 30 秒 / 条
2. 代码变更不影响现有积木系统
