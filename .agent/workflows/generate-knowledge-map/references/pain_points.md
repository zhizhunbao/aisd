# 通用痛点库（全学科适用）

> 本文件为 **单一来源**，被以下步骤引用：
> - `steps/step-07-pitfalls.md` — Pitfalls 维度的坑分类依据
> - `steps/step-12-video.md` — 视频 Hook 选择素材

---

## 一、学生真实痛点

| # | 痛点 | 一句话 |
|---|------|--------|
| 1 | 只甩任务不教思路 | 老师说"做个项目"，不教步骤、不讲逻辑、不给范例 |
| 2 | 上课念PPT | 真正的难点、坑点、踩雷点一句不讲 |
| 3 | 知识碎片化 | 学完不知道怎么串起来、怎么用 |
| 4 | 全靠AI生成 | 能跑能交能过，但完全不懂为什么 |
| 5 | 名词多黑话多 | 故意把简单东西讲复杂 |
| 6 | 评分看细节不看本质 | 你懂原理没用，他考你名词参数格式 |
| 7 | 越学越怀疑自己 | 明明逻辑很简单，被搞得又乱又难 |
| 8 | 没人讲行业真相 | 真实工作怎么干？学校从来不讲 |

## 二、学生真实需求（视频要解决的）

| # | 需求 | 解法 |
|---|------|------|
| 1 | 要人话不要黑话 | → Concepts 维度白话定义 |
| 2 | 要体系不要碎片 | → Map + Bridge 维度知识网络 |
| 3 | 要逻辑不要死记 | → Tutorial Why-First + First Principles |
| 4 | 要避坑不要踩雷 | → Pitfalls 维度 ❌/✅ 对比 |
| 5 | 要真相不要装逼 | → History + 行业真相 |
| 6 | 要自信不要内耗 | → "不是你笨，是教学体系烂" |

---

## 三、坑的分类（按学生需求组织）

| 分类 | 对应痛点 | 坑的组织方式 |
|------|---------|-------------|
| **概念理解坑** | 痛点 5, 7 | 名词包装下的简单逻辑，被误导的理解方式 |
| **代码实操坑** | 痛点 1, 4 | 能跑但不懂，抄了但踩雷 |
| **作业/项目坑** | 痛点 1, 6 | 先看要求不是先动手，结构先于内容 |
| **考试/答辩坑** | 痛点 6 | 回到大逻辑不被细节带偏 |
| **认知/心态坑** | 痛点 7, 8 | 不是你笨，是教学体系烂 |
