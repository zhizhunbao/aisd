## 1. 产品概述 (Product Overview)

**Antigravity SSOToken Manager** 是一款桌面端 SSO 令牌管理工具，用于管理 Antigravity AI 编程助手的账号认证、令牌生命周期、服务器连接，以及 AI 模型配额监控。

### 1.1 核心价值主张

| 维度         | 说明                                                           |
| ------------ | -------------------------------------------------------------- |
| **目标用户** | Antigravity AI 编程助手的使用者                                |
| **核心痛点** | SSO Token 手动管理繁琐、账号过期中断工作流、多模型配额不透明   |
| **解决方案** | 提供一站式可视化管理工具，自动刷新令牌，实时监控配额和连接状态 |

## 2. 功能模块 (Feature Modules)

### 2.1 📊 当前账号状态 (Current Account Status)

账号的全局状态看板，位于界面左上区域。

| 功能项               | 说明                                                               |
| -------------------- | ------------------------------------------------------------------ |
| **账号有效性标识**   | 绿色"有效"徽章，一眼判断账号是否可用                               |
| **刷新当前账号状态** | 手动触发账号状态刷新（蓝色按钮）                                   |
| **账号 ID**          | 显示当前账号 ID（脱敏展示，如 `1700...5690`），提前 5 分钟自动刷新 |
| **账号过期时间**     | 精确到秒的过期时间戳（如 `2026/02/21 13:25:04`）                   |
| **账号最后更新时间** | 最近一次账号信息刷新的时间戳                                       |

#### 2.1.1 配额状态 (Quota Status)

以卡片形式展示各 AI 模型的使用配额：

| 模型                  | 配额占比 | 附加信息                         |
| --------------------- | -------- | -------------------------------- |
| **Gemini 3 Pro High** | 80%      | 显示剩余时间（如 `1小时40分钟`） |
| **Gemini 3 Image**    | 100%     | 显示剩余时间（如 `4小时59分钟`） |
| **Claude Opus 4.6**   | 100%     | 显示剩余时间（如 `4小时59分钟`） |

- **PRO 标识**: 金色 ⭐ PRO 徽章，表示当前为付费/高级账户
- **配额刷新按钮**: 右上角有手动刷新配额的按钮

### 2.2 🔗 服务器连接 (Server Connection)

服务器连接管理面板，位于界面右上区域。

| 功能项                 | 说明                                                  |
| ---------------------- | ----------------------------------------------------- |
| **连接状态**           | 实时显示（如"连接正常"），并有"已连接"绿色徽章        |
| **设置按钮**           | ⚙️ 齿轮图标，用于配置服务器连接参数                   |
| **SSO Token 到期时间** | 显示 SSO Token 的过期时间（如 `2026/03/17 15:28:04`） |
| **SSO 使用量统计**     | 进度条 + 数字显示（如 `11/16`，占 `69%`）             |
| **测试连接**           | 手动测试服务器连接是否正常的按钮                      |

### 2.3 🔧 账号操作 (Account Operations)

三个核心操作按钮，位于界面中下区域，以色彩区分操作风险：

| 操作                      | 颜色    | 说明                                            |

## 4. 核心业务流程 (Core Business Flows)

### 4.1 Token 自动续期流程

```
账号即将过期（提前5分钟）
    ↓
自动触发刷新
    ↓
获取新 Token → 更新账号ID + 过期时间
    ↓
日志记录刷新操作
```

### 4.2 服务器连接管理流程

```
启动应用
    ↓
自动连接服务器 → 显示连接状态
    ↓
定时心跳检测 → 更新 SSO 使用量
    ↓
连接异常 → 提示用户 → [测试连接] / [重启进程]
```

### 4.3 账号申请流程

```
[申请新账号]
    ↓
（推测）填写申请信息 / 自动注册
    ↓
获取新 SSO Token
    ↓
同步至服务器 → 更新本地状态
```

## 5. 关键数据模型 (Data Model)

```
Account {
  id: string           // 账号ID（如 1700...5690）
  status: enum         // 有效 | 无效 | 过期
  tier: enum           // PRO | FREE
  expiresAt: datetime  // 过期时间
  lastUpdated: datetime // 最后更新时间
}

SSOToken {
  token: string        // SSO 令牌值
  expiresAt: datetime  // 到期时间（如 2026/03/17）
  usageCount: number   // 已使用次数（如 11）
  usageLimit: number   // 使用上限（如 16）
}

ModelQuota {
  model: string        // 模型名称（Gemini 3 Pro High 等）
  usagePercent: number // 使用百分比
  remainingTime: duration // 剩余可用时间
}

ServerConnection {
  status: enum         // 连接正常 | 断开 | 错误
  endpoint: string     // 服务器地址
}

OperationLog {
  timestamp: datetime
  action: string
  result: enum         // 成功 | 失败
  details: string
}
```

## 6. 非功能性需求 (Non-Functional Requirements)

| 类别           | 要求                                       |
| -------------- | ------------------------------------------ |
| **自动化**     | Token 过期前 5 分钟自动刷新，无需人工干预  |
| **可靠性**     | 连接断开时自动重连，异常时提供手动恢复手段 |
| **安全性**     | 账号 ID 脱敏显示，Token 值本地加密存储     |
| **可观测性**   | 操作日志完整记录所有关键动作               |
| **响应速度**   | 状态刷新 < 2 秒，连接测试 < 5 秒           |
| **多模型支持** | 灵活展示不同 AI 模型的配额，可扩展新模型   |

## 7. 总结 (Summary)

**Antigravity SSOToken Manager** 是一个为 Antigravity AI 编程助手打造的 **桌面端令牌管理工具**，核心解决以下问题：

1. **账号生命周期管理** — 自动续期、状态监控、一键申请
2. **SSO Token 管理** — 令牌存储、同步、使用量追踪
3. **服务器连接监控** — 实时状态、心跳检测、一键排障
4. **AI 模型配额可视化** — 多模型配额实时展示、PRO 等级标识
5. **进程控制** — 启停 Antigravity 后台进程
6. **SSH 同步** — 跨设备令牌同步能力

产品定位为 **运维级工具**，服务于需要稳定使用 Antigravity AI 助手的开发者，确保认证链路畅通无阻。
