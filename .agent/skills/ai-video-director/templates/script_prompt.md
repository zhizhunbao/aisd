# 旁白稿模板（Claude 直接生成）

> **理论根基**：McKee *Story* + Snyder *Save the Cat!* + Heath *Made to Stick*
> **使用方法**：Claude 根据 History 文件 + 选定风格直接生成旁白，每段一行输出

---

## 模板 A：标准 3 分钟旁白

### 输入
- History 文件内容（`_history.md`）
- 风格选择：袁腾飞 / 老高 / 罗翔 / 精简

### 输出格式
每段一行，直接存为 `narration/script.txt`，供 TTS 使用。

### 结构模板（Snyder Beat Sheet × 3 分钟）

```
[00:00-00:03] Opening Image — 第一句话定基调
[00:03-00:15] 钩子 — 反直觉事实，吸引注意力
[00:15-00:25] Catalyst — 触发事件：谁在什么困境下做了什么
[00:25-00:45] Debate — 挣扎：这个方法靠谱吗？当时的人怎么看？
[00:45-01:10] B Story — 用类比解释核心概念
[01:10-01:20] Midpoint — 假胜利或假失败
[01:20-01:45] Bad Guys — 困境加深：有什么致命缺陷？
[01:45-02:05] All Is Lost — 最低点 + 反思
[02:05-02:40] Finale — 突破+价值翻转：谁解决了问题？
[02:40-02:50] Final Image — 今天的回响
[02:50-03:00] Tag — 一句话收尾
```

### 自检清单（SUCCESs）
- [ ] Simple — 只讲一个核心概念
- [ ] Unexpected — 钩子有反直觉点
- [ ] Concrete — 有具体类比
- [ ] Credible — 有人名/年份/论文
- [ ] Emotional — 有触发情感的瞬间
- [ ] Stories — 是故事不是论述

## 模板 B：1 分钟精华版（竖屏）

从 3 分钟版本压缩：
```
[00:00-00:03] 钩子（最反直觉的一句话）
[00:03-00:45] 核心故事（只保留最精彩的一个反转）
[00:45-01:00] 金句收尾 + 关注引导
```

---

## 模板 C：配套文章

```markdown
# [反直觉标题]

> [一句话摘要，≤30字]

[钩子 — 100 字]

## [起源]
[200-300 字，有人名/年份/细节]

## [困境与突破]
[300-400 字，有类比]

## [今天的回响]
[150 字]

## 🧪 动手试试
[一个小实验或思考题]
```

## 画面建议模板

旁白稿每段配一个画面建议：

| 时间 | 旁白摘要 | 画面类型 | 素材来源 |
|------|---------|---------|---------|
| 00:00-00:15 | 钩子 | 老照片/文字卡 | Wikipedia |
| 00:15-00:45 | 起源故事 | 人物肖像+论文截图 | Google Scholar |
| 00:45-01:10 | 类比解释 | Manim 动画 | 代码生成 |
| 01:10-01:45 | 困境 | 数据可视化 | Manim |
| 01:45-02:40 | 突破 | 产品截图/现代素材 | Pexels |
| 02:40-03:00 | 收尾 | 文字卡（金句） | FFmpeg 生成 |

画面类型：
- **老照片** — 讲人物/历史用
- **Manim** — 讲算法/公式用
- **论文截图** — 引用具体研究
- **文字卡** — 金句/强调重点
- **产品截图** — 讲现代应用
- **B-roll** — 通用氛围素材（Pexels）
