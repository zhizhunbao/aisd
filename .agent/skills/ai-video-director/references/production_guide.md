# 视频制作实战参考

## 1. 完整工作流（5步）

```
Claude 写稿 → Qwen3-TTS 生成音频 → 准备视觉素材 → 组装视频 → 导出
```

| 步骤 | 工具 | 耗时 |
|------|------|------|
| **1. 写稿** | Claude（4种风格可选） | 2 分钟 |
| **2. TTS** | Qwen3-TTS（本地GPU，声音克隆） | 5-10 分钟 |
| **3. 视觉素材** | Pexels + Manim + 手动搜图 | 10-30 分钟 |
| **4. 组装** | assemble_video_v3.py（自动字幕） | 1 分钟 |
| **5. 微调** | CapCut（可选，精调字幕/BGM） | 5-15 分钟 |

## 2. 四种叙事风格

| 风格 | 适合主题 | 声音建议 | 画面风格 |
|------|---------|---------|---------|
| **袁腾飞** | 技术史、人物故事 | 预设声音(uncle_fu) | 老照片+大字金句 |
| **老高** | 前沿技术、神秘话题 | 预设声音(aiden) | 科幻素材+数据可视化 |
| **罗翔** | 算法原理、概念解释 | 预设声音 | Manim动画+张三漫画 |
| **精简** | 教程、技术讲解 | 自己的声音克隆 | 代码录屏+原理图 |

## 3. 视觉素材规则

### 讲历史/人物 → 用历史素材
| 内容 | 该用什么画面 | 来源 |
|------|-------------|------|
| 人物故事、学术八卦 | 老照片、人物肖像 | Wikipedia, 大学官网 |
| 论文发表 | 论文首页截图 | Google Scholar |
| 历史事件 | 历史文献、年代照片 | Pexels, Unsplash |
| 金句/感悟 | 大字文字卡（深色背景+白字） | 脚本自动生成 |

### 讲算法/原理 → 用动画
| 内容 | 该用什么画面 | 来源 |
|------|-------------|------|
| 分类过程 | Manim 散点图动画 | 代码生成 |
| 公式推导 | Manim 公式动画 | 代码生成 |
| 算法流程 | Manim 流程图 | 代码生成 |
| 代码演示 | IDE 屏幕录制 | OBS |

### 讲现状/应用 → 用现代素材
| 内容 | 该用什么画面 | 来源 |
|------|-------------|------|
| 现代应用 | App截图、产品画面 | 手动截图 |
| 数据中心 | 服务器机房素材 | Pexels |
| AI产品 | 产品官网截图 | 手动截图 |

### ⚠️ 一段旁白只用一种画面类型，不要混搭

## 4. 字幕方案

| 方案 | 精度 | 操作 |
|------|------|------|
| **脚本均分** | ★★★ | assemble_video_v3.py 自动按字数分 |
| **Whisper** | ★★★★★ | `stable-ts` 从音频识别精准时间轴 |
| **CapCut** | ★★★★★ | CapCut 自动字幕 → 导出 SRT |

### 字幕样式
```
字体：微软雅黑 / 思源黑体
大小：22px（1080p）
颜色：白色 + 2px黑色描边
位置：底部居中，距底 40px
```

## 5. 脚本文件清单

```
.agent/skills/ai-video-director/scripts/
├── generate_video_script.py     # 项目脚手架（创建目录+风格选择）
```
