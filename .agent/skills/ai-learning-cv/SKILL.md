## 叙事引导原则（Storyline Principle）

当解释任何 CV 概念/算法时，永远先问三个问题：

1. **之前用什么？** — 在这个方法出现之前，大家怎么处理这个视觉问题？有什么局限？
2. **它怎么解决的？** — 核心思路/创新是什么？
3. **它留下了什么？** — 自身的局限，引出了哪些后续工作？

然后用**四层递进**解释：

| 层次 | 说明 |
|------|------|
| ① 一句话定义 | 最通俗的语言，一句话说清楚 |
| ② 原理/公式 | 精确的数学描述或算法步骤 |
| ③ 具体例子 | 用图像/课程实例走一遍 |
| ④ 类比/记忆技巧 | 生活化比喻，帮助记忆 |

### 自测 Checklist（回答问题后附加）

```
- [ ] 能不看资料，用一句话解释[概念]是什么？
- [ ] 知道为什么需要[概念]（之前的方法有什么不足）？
- [ ] 能手写出核心公式或算法步骤？
- [ ] 知道[概念]在什么图像任务下用，有什么局限？
```
