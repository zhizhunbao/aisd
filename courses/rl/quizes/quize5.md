# Stable-Baselines3 Quiz Answers

## Question 1

**Which of the following is a design principle of Stable-Baselines3 (SB3)?**

Options:

- SB3 is user-friendly.
- SB3 focuses on model-free, single agent Reinforcement Learning.
- All of these answers.
- SB3 is to be a set of reliable Reinfocement Learning algorithms.
- SB3 favours readability and simplicity over modularity.

**Answer:** All of these answers.

## Question 2

- SB3 provides a selection of algorithms, both on-policy and off-policy.

## Question 3

**Which of the following is a proper ordering of steps when using Stable-Baselines3?**

Options:

- Save an agent, train the agent, define the agent, load the agent.
- Define an agent, train the agent, save the agent, load the agent.
- None of these answers.
- Load an agent, define the agent, train the agent, save the agent.
- Train an agent, define the agent, load the agent, save the agent.

**Answer:** Define an agent, train the agent, save the agent, load the agent.

## Question 5

**What does the Stable-Baselines3 model.learn() method do?**
