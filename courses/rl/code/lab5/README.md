# Lab 5: Docker Containerization

Author: Peng Wang (041107730)

## Overview

Docker containerization of the ROS 2 Humble + Assignment 2 project. The container packages the complete Create3 simulator environment with Gazebo, camera URDF, red ball actor, and the Gymnasium RL training environment.

## Directory Structure

```
lab5/
  Dockerfile                  - Multi-stage Dockerfile (clone → build → runtime)
  docker-compose.yml          - Compose file with host networking, X11, GPU support
  setup_lab5.sh               - One-click build script
  patches/
    camera.urdf.xacro         - Camera URDF patch (from Lab 3)
    red_ball_actor.xml         - Red ball actor snippet (from Lab 4)
  assn2/                      - (Generated by setup_lab5.sh) Assignment 2 code
  prompts/
    prompt_template.md         - Filled-out AI prompt template
    prompt_response.md         - AI response with Dockerfile/compose
    followup_prompts.md        - Follow-up prompts and responses
```

## Quick Start

```bash
# 0. Enter the lab5 directory (WSL)
cd /mnt/c/Users/40270/Desktop/workspace/aisd/courses/rl/code/lab5

# 1. Build the Docker image
docker compose build

# 2. Run the container (Terminal 1 — drops into bash)
docker compose run ros2-create3

# 3. Launch Gazebo (inside the container)
ros2 launch irobot_create_gazebo_bringup create3_gazebo_aws_small.launch.py

# 4. Open a second shell (Terminal 2 — new WSL window)
docker compose exec ros2-create3 /ros_entrypoint.sh bash

# 5. Undock the robot (wait for Gazebo to fully load first)
cd /ros2_ws/assn2
bash undock.sh

# 6. Run an agent (after undock completes)
python3 null.py          # Null agent (baseline, does nothing)
python3 non-rl.py        # Rule-based agent (no RL)
python3 qlearning.py     # Q-Learning agent
python3 dqn.py           # DQN agent (Deep Q-Network)
python3 ppo.py           # PPO agent (Proximal Policy Optimization)
```
