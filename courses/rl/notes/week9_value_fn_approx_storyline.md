## 🎬 序幕：我们在解决什么问题？

回顾 Week 2-5 的旅程：我们学会了 Q-Learning，用一张 Q-Table 记录每个 (state, action) 的价值。在 4×4 CliffWalking、小规模 BlocksWorld 上都表现不错。

但现在，假设你要训练一个 Agent 玩围棋（Go）。围棋有多少种状态？

| 游戏 | 状态数量 | Q-Table 存得下吗？ |
|------|---------|-------------------|
| CliffWalking (4×12) | ~48 | ✅ 轻松 |
| BlocksWorld (5×5) | ~几十万 | ⚠️ 勉强 |
| Backgammon（西洋双陆棋） | 10²⁰ | ❌ 完全不可能 |
| Computer Go（围棋） | 10¹⁷⁰ | ❌ 宇宙中原子都没这么多 |

> 💡 **核心矛盾：** Q-Table 为每个 (state, action) 分配一个格子。当状态空间是天文数字时，表格就彻底失效了——存不下、学不完、没见过的状态直接返回 0。

这就是 Week 9 要解决的核心问题：**如何在巨大的状态空间中学习 Q 值？**

## 📚 第一章：Q-Table 的极限——为什么表格方法不够用

### 1.1 Q-Learning 的 TD(0) 公式回顾

Week 2 学到的 Q-Learning 更新公式：

```
Q[s][a] = Q[s][a] + α * (r + γ * max(Q[s']) - Q[s][a])
```

| 符号 | 含义 | 类比 |
|------|------|------|
| `Q[s][a]` | 状态 s 下采取动作 a 的价值 | 字典里的一个条目 |
| `α` (alpha) | 学习率/步长 | 每次更新"走多远" |
| `r` | 即时奖励 | 这一步拿到的分数 |
| `γ` (gamma) | 折扣因子 | 未来奖励的"打折力度" |
| `max(Q[s'])` | 下一状态的最大 Q 值 | 对未来的最乐观估计 |

这是一个 TD(0) (Temporal Difference) 更新：不用等整个 episode 结束（Monte Carlo），只看一步之后就更新。

### 1.2 ❌ 表格方法的三大致命问题

| 问题 | 具体表现 | 本质原因 |
|------|---------|---------|
| **存储爆炸** | 10²⁰ 个状态 × N 个动作 = 表格存不下 | 离散枚举每个状态 |
| **泛化缺失** | 没访问过的状态，Q 值永远为初始值 0 | 表格条目之间完全独立 |
| **收敛太慢** | 需要每个状态都被访问足够多次 | 无法利用"相似状态"之间的信息 |

> 💡 **类比：** Q-Table 就像一本纸质字典。每个词（状态）必须有自己的条目。如果语言有 10²⁰ 个词，你根本造不出这本字典。更糟糕的是，遇到一个从未查过的新词，字典直接告诉你"不知道"——它**没有泛化能力**。

> 🔑 **故事转折点：** Q-Table 在大规模环境下彻底崩溃 → 我们需要一种方法，不用为每个状态单独存储一个值，而是能从**有限经验**中**推断**未见状态的价值 → **函数近似 (Function Approximation)** 登场！

## 🧠 第二章：值函数近似——用函数替代表格

### 2.1 核心思想：从"查表"到"拟合曲线"

值函数近似的核心突破在于一个简单的替换：

| 维度 | Q-Table | 函数近似 |
|------|---------|---------|
| Q 值存储 | 一张巨大的表格 | 一个带参数 **w** 的函数 |
| 表示方式 | Q[s][a] = 具体数字 | q̂(s, a, **w**) ≈ q_π(s, a) |
| 参数数量 | = |S| × |A|（随状态增长） | = |**w**|（固定大小，远小于状态数） |
| 泛化能力 | ❌ 没见过 = 不会 | ✅ 相似状态 → 相似 Q 值 |
| 更新方式 | 直接修改表格条目 | 用 MC 或 TD 学习更新权重 **w** |

数学表达：

- 状态价值函数近似：**v̂(s, w) ≈ v_π(s)**
- 动作价值函数近似：**q̂(s, a, w) ≈ q_π(s, a)**

其中 **w** 是**神经网络的权重向量**。

### 2.2 泛化——函数近似的超能力

函数近似最重要的特性是**泛化**（Generalize from seen states to unseen states）：

- Q-Table: 没见过状态 s₁₀₀₀ → Q 值 = 0（完全不知道）
- 函数近似: 没见过状态 s₁₀₀₀，但它和 s₉₉₉ 很像 → 神经网络会给出相似的 Q 值

> 💡 **类比：** 函数近似就像从"纸质字典"升级到"AI 翻译器"——不再逐词查找，而是通过学习语言规律，能对从未见过的句子给出合理翻译。参数 w 就是翻译器学到的"语言规律"。

### 2.3 权重 w 如何更新？

关键是：**用 MC 或 TD 学习来更新 w**。

- **MC 方法**：走完整个 episode，用实际累积奖励作为目标，调整 w
- **TD 方法**：只看一步（bootstrapping），用 r + γ · v̂(s', w) 作为目标，调整 w

TD 方法更常用，因为它不需要等 episode 结束，可以**在线学习**。

> 🔑 **故事转折点：** 函数近似解决了"表格存不下"的问题 → 但具体用什么函数？线性函数太简单 → 用**深度神经网络**作为函数近似器 → **DQN** 登场！

## 🏗️ 第三章：DQN——值函数近似的深度学习实现

### 3.1 DQN 就是 Q-Learning + 神经网络

DQN (Deep Q-Network) 的核心可以用一句话概括：**把 Q-Table 换成 Q-Network**。

| 维度 | Q-Learning | DQN |
|------|-----------|-----|
| Q 值来源 | Q-Table（查表） | Q-Network（前向传播） |
| 更新方式 | 直接修改表格条目 | 反向传播更新网络权重 |
| 输入 | state + action → 一个 Q 值 | state → 所有动作的 Q 值向量 |
| 输出 | 标量 Q(s,a) | 向量 [Q(s,a₁), Q(s,a₂), ..., Q(s,aₙ)] |

> 💡 **关键理解：** Q-Network 的**输入是 State**，**输出是所有动作的 Q 值**（输出层神经元数 = 动作数）。选动作时，直接取 argmax。

### 3.2 ❗ 直接替换的问题——训练不稳定

如果直接把 Q-Table 换成神经网络，会发现训练非常不稳定。为什么？

**问题 1：追自己尾巴**
- 在 Q-Learning 中，TD 目标是 `r + γ * max Q[s']`——这里的 Q 值来自表格，相对稳定
- 如果用同一个网络计算当前 Q 值和目标 Q 值：每次更新网络，目标也跟着变 → 训练目标不断漂移

**问题 2：样本相关性**
- Agent 连续采集的经验高度相关（连续走10步都在同一条走廊）
- 神经网络用相关的数据训练 → 过拟合到最近的经验

> 🔑 **故事转折点：** 简单替换表格为网络不够 → 需要两个关键稳定技巧 → **双网络 + 经验回放**登场！

### 3.3 DQN 的双网络架构：Online + Target

DeepMind 2015 年论文的核心创新——引入**两个**网络：

| 网络 | 更新频率 | 作用 |
|------|---------|------|
| **Online Network** | 每个训练步都更新 | 学习者——通过梯度下降最小化 TD 误差 |
| **Target Network** | 每 N 步同步一次 | 考官——提供稳定的 Q 值目标 |

**更新方式：**
- **硬更新 (Hard Update)：** 每隔 target_update_interval 步，直接复制 `Q_target ← Q_online`
- **软更新 (Polyak/Soft Update)：** 每步按比例混合 `Q_target ← τ·Q_online + (1-τ)·Q_target`，τ 很小（如 0.005）

> 💡 **类比：** Online Network 是"学生"，不断学习进步。Target Network 是"考试标准"——如果考试标准每天都变，学生根本不知道自己在进步还是退步。固定一段时间的标准，学生才能有稳定的学习方向。

### 3.4 DQN 损失函数——TD 误差的平方

$$L = E\left[\left(r + \gamma \cdot \max_{a'} Q_{target}(s', a') - Q_{online}(s, a)\right)^2\right]$$

拆解这个公式：

| 组成部分 | 含义 | 谁提供的？ |
|---------|------|----------|
| `r` | 即时奖励 | 环境 |
| `γ · max Q_target(s', a')` | 未来价值的折扣估计 | **Target Network** |
| `r + γ · max Q_target(s', a')` | TD 目标 (y) | 奖励 + 目标网络 |
| `Q_online(s, a)` | 当前估计 | **Online Network** |
| `y - Q_online(s, a)` | TD 误差 | 目标与估计的差距 |
| `(...)²` | 平方误差 | MSE 损失 |
| `E[...]` | 期望/平均 | 在 mini-batch 上取平均 |

> 💡 **直觉：** 损失函数衡量的是"Online Network 预测的 Q 值"与"基于 Target Network 计算的目标值"之间的差距。训练就是不断缩小这个差距。

### 3.5 DQN 算法四步循环

DQN 的训练可以总结为一个不断重复的四步循环：

```
┌─────────────────────────────────────────────────────────┐
│              DQN 训练四步循环                              │
│                                                         │
│  ① 交互 (Interaction)                                    │
│     Agent 在环境中执行动作                                │
│     收集 (s, a, r, s') 转移                              │
│     注意：前 learning_starts 步是随机探索                  │
│                                                         │
│           ↓ 存入                                         │
│                                                         │
│  ② 经验回放 (Replay Buffer)                               │
│     存储所有历史转移                                      │
│     目的：打破时间相关性                                  │
│     随机采样 mini-batch 用于训练                          │
│                                                         │
│           ↓ 采样                                         │
│                                                         │
│  ③ 训练 (Training)                                       │
│     Online Q-Network 在随机批次上                         │
│     最小化 MSE 损失（TD 误差的平方）                      │
│     默认每 4 次交互训练一次                               │
│                                                         │
│           ↓ 同步                                         │
│                                                         │
│  ④ 目标更新 (Target Update)                               │
│     Polyak (软更新) 或 Hard (硬更新)                      │
│     将 Online 权重复制/混合到 Target Network              │
│     默认每 10,000 步一次                                  │
│                                                         │
│                    ↺ 循环                                │
└─────────────────────────────────────────────────────────┘
```

### 3.6 关键超参数一览

| 超参数 | 默认值 | 含义 |
|--------|-------|------|
| `learning_starts` | — | 开始训练前的随机探索步数（填充 Buffer） |
| 训练频率 | 每 4 次交互 | Online Network 的更新频率 |
| `target_update_interval` | 10,000 步 | Target Network 的同步频率 |
| `tau` (τ) | 小值 | 软更新的混合比例 |
| `batch_size` | — | 每次从 Buffer 采样的样本数 |
| `gamma` (γ) | — | 折扣因子 |

## 🎭 第四章：PPO——另一种使用值函数近似的方法

### 4.1 从 DQN 到 PPO：不同的算法家族

DQN 属于**基于价值 (Value-Based)** 的方法——只学 Q 值，策略是隐含的（argmax Q）。

PPO (Proximal Policy Optimization) 属于 **Actor-Critic** 方法——同时学习两样东西：

| 网络 | 学什么 | 输出 |
|------|-------|------|
| **Actor Network** | 策略 π(a\|s) | 每个动作的概率 |
| **Critic Network** | 价值函数 V(s) | 状态的价值估计 |

### 4.2 PPO 中的值函数近似

PPO 的 Critic Network 就是在做**值函数近似**——用神经网络逼近 V(s)。

这和本周的主题（值函数近似）完全一致：

| 维度 | DQN | PPO |
|------|-----|-----|
| 近似目标 | Q(s,a) — 动作价值函数 | V(s) — 状态价值函数 |
| 网络数量 | 2 个同结构网络 (Online + Target) | 2 个不同结构网络 (Actor + Critic) |
| 动作选择 | argmax Q(s,a) | 从 π(a\|s) 采样 |
| 动作空间 | 仅 Discrete | Discrete 或 Continuous |
| 适用场景 | 离散动作（游戏等） | 连续动作（机器人控制等） |

> 💡 **关键理解：** DQN 和 PPO 都使用值函数近似——DQN 近似的是 Q(s,a)，PPO 的 Critic 近似的是 V(s)。两者殊途同归，都是用神经网络替代表格来处理大规模问题。

## 🤖 第五章：实战应用——Gazebo 仿真中的 RL 机器人

### 5.1 为什么需要 Gazebo 仿真？

训练 RL Agent 需要大量交互数据。在真实机器人上：

- 每一步都很慢（物理世界有延迟）
- 失败可能损坏硬件（机器人摔倒、撞墙）
- 无法并行训练

**Gazebo** 提供了一个物理仿真环境：可以快速、安全、并行地训练 RL Agent。

### 5.2 Gazebo Actors：仿真世界中的移动目标

Gazebo 支持两种角色动画：

| **Trajectory Animation** | 轨迹动画——角色在世界中移动 | 红球沿正方形路径移动 |

Ref: https://gazebosim.org/docs/harmonic/actors
