Part 1: Rule-based NLP chatbot (ELIZA)
Background
ELIZA is one of the earliest chatbots, created in 1966 by Joseph Weizenbaum at MIT. It was
designed to simulate a psychotherapist by using simple rule-based pattern matching, not real
understanding.
ELIZA works by looking for keywords or patterns in the user’s input and then applying simple
IF–THEN rules to decide how to respond. It generates replies using predefined templates and
often reflects the user’s own words back as questions. Although this can make the conversation
seem meaningful, ELIZA does not actually understand the meaning, emotions, or context of
what the user says.
Task Description
Your task is to design and implement a simple ELIZA chatbot that uses a set of predefined rules
to analyze user input, match patterns using regular expressions, and generate appropriate
responses based on those rules.

**The ELIZA chatbot system works by first receiving a user’s text input, which is then normalized**

The system is working as follows:
by converting it to lowercase and removing extra whitespace. The system evaluates the input
against a predefined list of rules in a fixed priority order. For each rule, it applies a regular
expression to check for a match. If a match is found, the system extracts any captured groups
from the input and applies necessary transformations, such as swapping pronouns (for
example, “I” becomes “you” and “my” becomes “your”), to make the response coherent. It then
selects a response template associated with the rule and substitutes the transformed text into
the template. Once a response is generated, rule evaluation stops. If none of the rules match
the input, the system applies a fallback rule to return a generic default response.
Rules
Rule Group 1: Greetings
Rule
IF the user input contains:
hello | hi | hey
THEN respond with one of:
“Hello. How are you feeling today?”
“Hi there. What would you like to talk about?”
“Hello. Please tell me what is on your mind.”
Rule Group 2: Feelings (Core ELIZA Behavior)
Rule
IF the input matches:
I feel (.*)
THEN respond with:
“Why do you feel <1>?”
“Do you often feel <1>?”
“What makes you feel <1>?”


### ✍️ Notes

> **📝 笔记:**

> **ELIZA 系统流程:**
> 1. **规范化**: 输入转小写、去除多余空格。
> 2. **规则评估**: 按固定优先级顺序匹配正则。匹配成功即停止后续规则。
> 3. **人称转换**: 提取捕获组并转换代词。
> 4. **响应填充**: 将处理后的文本放入模板。
> 
> **技术语法 (基于规则组 1 & 2):**
> - `|` (或运算符): 在 `hello | hi | hey` 中用于匹配任意一个问候语。
> - `(.*)` (捕获组): 在 `I feel (.*)` 中匹配并提取“我感觉”之后的所有内容。
> 
> **逻辑细节:**
> - 对于问候语，要求从三个候选模板中“随机选择”一个。
> - 对于感受类，需捕获内容并处理。

> **代词转换 (Pronoun Substitution):**
> - **技术逻辑**: 在将捕获内容 `<1>` 填入回复前，必须进行映射转换。

**For each review, you will count how many positive and negative words appear in the text using**

pattern matching techniques. Based on these counts, you will assign a sentiment label: positive,
negative, or neutral.
Dataset
You will use the IMDb movie reviews dataset available from the nltk Python package. This
dataset contains movie reviews labeled as either positive or negative. Each review is raw text
and may include punctuation, HTML tags, or URLs.
Data Preprocessing
For this step, you may use NLTK or spaCy to reprocess the data. Your preprocessing should
include:

• Converting all text to lowercase.

• Removing HTML tags (e.g., <br>).

• Removing URLs and web links.

• Removing punctuation, numbers, and special characters.

• Removing extra whitespace.

Sentiment Annotation and Evaluation
Analyze each preprocessed review by counting the number of positive and negative words from
your sentiment lexicon. Assign a label to the review based on which count is higher: pos for
positive, neg for negative, or neutral if they are equal or no words match. This simple annotation
method will allow you to evaluate the sentiment of the text before comparing it with the true
labels.
The sentiment annotation step should include:

• Define your set of sentiment lexicon with positive and negative words (e.g., “good”,

“bad”, “excellent”, “terrible”).

• For each review, count how many positive and negative words appear.

• Assign a sentiment label:

o pos if positive words > negative words
o neg if negative words > positive words
o neutral if counts are equal or no words match

• Apply your sentiment annotation on the dataset.

• Calculate the accuracy of your predictions against the true labels.

• Display a sample review showing:

▪ Original text
▪ Preprocessed text


### ✍️ Notes

> **📝 笔记:**
> 
> **文本预处理逻辑:**
> 1. **toLowerCase**: 转换为小写。
> 2. **去除 HTML**: 清除如 `<br>` 之类的标签。
> 3. **去除 URL**: 清除网页链接。
> 4. **清除噪声**: 去除标点、数字和特殊字符。
> 5. **去除空格**: 处理多余空白。
> 
> **情感标注逻辑:**
> - **正向 vs 负向词频**: 统计词典词汇出现次数。
> - **决策规则**:
>   - `pos`: 正向词数 > 负向词数。
>   - `neg`: 负向词数 > 正向词数。
>   - `neutral`: 词数相等或无匹配。
