Part 1: Rule-based NLP chatbot (ELIZA) 
Background 
ELIZA is one of the earliest chatbots, created in 1966 by Joseph Weizenbaum at MIT. It was 
designed to simulate a psychotherapist by using simple rule-based pattern matching, not real 
understanding. 
ELIZA works by looking for keywords or patterns in the user’s input and then applying simple 
IF–THEN rules to decide how to respond. It generates replies using predefined templates and 
often reflects the user’s own words back as questions. Although this can make the conversation 
seem meaningful, ELIZA does not actually understand the meaning, emotions, or context of 
what the user says. 
Task Description 
Your task is to design and implement a simple ELIZA chatbot that uses a set of predefined rules 
to analyze user input, match patterns using regular expressions, and generate appropriate 
responses based on those rules.

 The system is working as follows: 
The ELIZA chatbot system works by first receiving a user’s text input, which is then normalized 
by converting it to lowercase and removing extra whitespace. The system evaluates the input 
against a predefined list of rules in a fixed priority order. For each rule, it applies a regular 
expression to check for a match. If a match is found, the system extracts any captured groups 
from the input and applies necessary transformations, such as swapping pronouns (for 
example, “I” becomes “you” and “my” becomes “your”), to make the response coherent. It then 
selects a response template associated with the rule and substitutes the transformed text into 
the template. Once a response is generated, rule evaluation stops. If none of the rules match 
the input, the system applies a fallback rule to return a generic default response.
