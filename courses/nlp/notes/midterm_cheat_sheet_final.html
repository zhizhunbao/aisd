⭐⭐⭐ TF-IDF (Term Frequency-Inverse Document Frequency, 词频-逆文档频率) — Formulas 📖
  • Word in every doc: IDF=log(1)=0 → zero weight
  • Word in 1 doc: IDF=log(N) → highest weight
  • Why log: compress extreme values to manageable range
TF(t,d) = count(t in d) / total words in d
IDF(t) = log(N / df(t))
TF-IDF(t,d) = TF(t,d) × IDF(t)

⭐⭐⭐ CountVectorizer vs TfidfVectorizer (计数向量器 vs TF-IDF向量器) 📖
  • CountVec: doc1('hot sun') & doc3('hot encoding') most similar (0.408) — misleading!
  • TF-IDF: doc2('chocolate milk') & doc4('latte milk') most similar (0.232) — smarter!
  • ngram_range=(1,2) | Unigrams + bigrams
  • Vector dim | Total n-grams in vocabulary

W5: Language Models (语言模型) & RNN/LSTM
📌 Quiz Key Points
  • RNN gradient: True — ∂L/∂θ via BPTT
  • Stateful computation: True — hₜ across time steps
  • Training data: True — diverse public datasets
  • Bigram prob: B=0.4 — Count(AB)/Count(A)

  • N-gram semantics: False — statistical only, no deep reasoning
  • Low LR: False — slow convergence, not faster
⭐⭐⭐ Probability Basics (概率基础) 📖
  • Chain Rule = foundation of ALL Language Models
P(X|Y) = P(X,Y) / P(Y)
P(w₁...wₙ) = P(w₁) × P(w₂|w₁) × P(w₃|w₁w₂) × ...
⭐⭐⭐ N-gram LM (N-gram Language Model, N元语言模型) 📖
  • Markov Assumption: only previous n-1 words
  • Limitations: sparsity, fixed window, no semantics
#Limitation
1Data Sparsity (数据稀疏性)
2Computational Complexity (计算复杂度)
3Context Limitations (上下文限制)
P(wₜ|wₜ₋ₙ₊₁...wₜ₋₁) = Count(wₜ₋ₙ₊₁...wₜ) / Count(wₜ₋ₙ₊₁...wₜ₋₁)
4-gram: students opened their ___
books: 400/1000 = 0.4
exams: 100/1000 = 0.1
⚠️ "N-gram uses deep semantic reasoning" → False (statistical only)
⚠️ Bigram P(happy|feel) = 40/100 = 0.4; Count(happy)=30 is DISTRACTOR
⭐⭐⭐ RNN (Recurrent Neural Network, 循环神经网络) 📖
  • Stateful computation: hₜ carries info across time steps
  • Parameter sharing: same Wₕ, Wₑ at every step
  • BPTT: error propagates backward through time
hₜ = σ(Wₕ·hₜ₋₁ + Wₑ·eₜ + b)
ŷₜ = softmax(U·hₜ + b₂)
J = -(1/T) Σ log P(correct word at t)
⭐⭐⭐ FFNN (Feed-Forward NN, 前馈神经网络) vs RNN 📖
FeatureFFNN (前馈NN)RNN (循环NN)
Sequence❌ Fixed-length✅ Variable-length
Temporal dep.❌ None✅ Via hₜ
Param sharing❌ Different per layer✅ Same every step
Memory❌ No state✅ Hidden state hₜ
⭐⭐⭐ Gradient Problems (梯度问题) 📖
  • Example | "she tried to print her tickets... installed toner... finally printed her ___"
  • Problem | RNN needs to connect 'tickets' (early) to prediction (end) — signal lost
  • Math | Gradients multiply by Wₕ at each step: if |Wₕ|<1 → exponential shrinkage
ProblemCauseEffect
Vanishing (梯度消失)Gradient→0Can't learn long-range deps

⭐⭐⭐ LSTM (Long Short-Term Memory, 长短期记忆网络) 📖
  • Dual state: hₜ (short-term) + cₜ (long-term cell state)
  • Cell update uses ADDITION (not multiplication) → gradient flows
GateFormulaFunction
Forget (遗忘门)fₜ=σ(Wf·[hₜ₋₁,xₜ]+bf)Discard old info
Input (输入门)iₜ=σ(Wi·[hₜ₋₁,xₜ]+bi)Store new info
Candidatec̃ₜ=tanh(Wc·[hₜ₋₁,xₜ]+bc)New values
Cell updatecₜ=fₜ⊙cₜ₋₁+iₜ⊙c̃ₜADDITION!
Output (输出门)oₜ=σ(Wo·[hₜ₋₁,xₜ]+bo)Output info
Hiddenhₜ=oₜ⊙tanh(cₜ)Short-term out

⭐⭐⭐ Attention (注意力机制) — Definition & Steps 📖
  • 1. score_i = dot(decoder_state, encoder_state_i)
  • 2. α = softmax(scores) → attention distribution
  • 3. context = Σαᵢ × encoder_state_i → attention output
  • 4. [decoder_state ; context] → concat → prediction
StepDetail
DefinitionAttention = weighted average over a set of inputs
1. SimilarityCompute pairwise similarity: each encoder state vs decoder state
2. DistributionConvert scores to probability distribution (softmax)
3. Weighted avgCompute weighted average of encoder hidden states
Translation: 'il a m' entarté' → 'he hit me with a pie'
Decoding 'he': attention focuses on 'il' (highest α)
Decoding 'hit': attention shifts to 'a'
Decoding 'me': attention on 'm''
Decoding 'pie': attention on 'entarté'
Each step: score→softmax→weighted sum→concat→predict

⚡ Quick Review
  • ✅ Transformer = 2017 turning point (self-attention)
  • ✅ NLP goal = understand + interpret + generate
  • ✅ Text Classification = NLU (NOT NLG)
  • ✅ Zipf's Law = few high-freq + many rare words
  • ✅ Tokenization = pipeline first step
  • ✅ SpaCy: NO Stemming; NLTK: both
  • ✅ Poetry: do NOT stem/lemmatize
  • ✅ WordNet: Hypernym/Hyponym=IS-A, Meronym/Holonym=PART-OF
  • ✅ BOW ignores word order
  • ✅ TF-IDF = high-dim sparse, no semantics
  • ✅ IDF = log(N/df); all docs → IDF=0
  • ✅ cos≈1 → similar
  • ✅ Embedding dim 50-300 (NOT vocab size)
  • ✅ Gensim W2V default: vector_size=100
  • ✅ CBOW: context→center; Skip-gram: center→context
  • ✅ GloVe = global co-occurrence + local window
  • ✅ FastText = subword n-grams, handles OOV
  • ✅ Self-supervised = no manual labels
  • ✅ king-man+woman≈queen
  • ✅ Chain Rule = foundation of ALL LMs
  • ✅ N-gram = statistical, no semantics
  • ✅ P(B|A) = Count(AB)/Count(A); ignore Count(B)
  • ✅ RNN: stateful computation via hₜ
  • ✅ LSTM 3 gates: forget/input/output; ADDITION→gradient flows
  • ✅ Low LR → SLOW (not fast!)
  • ✅ Bi-LSTM cannot generate text
  • ✅ Seq2Seq bottleneck → Attention eliminates
  • ✅ Exposure Bias: train=ground truth, test=own prediction
  • ✅ Attention: score→softmax→weighted sum→concat
  • ✅ 5 seq archs: 1-1, 1-many, many-1, many-many×2
  • ✅ BERT=encoder/bidirectional; GPT=decoder/autoregressive
  • ✅ Perplexity: low=good, high=confused
  • ✅ BPTT = RNN backpropagation method
