# Lecture 9 故事线：从“固定词向量不够用”到 Transformer 成为现代 NLP 基座

> **Source:** `lecture_9_W26.pdf`
> **Key references:** *Attention Is All You Need* (2017), Hugging Face / O'Reilly slides cited by instructor
> **核心主题：** 如何让模型在理解一个词时，动态读取整句上下文，并且比 RNN 更快地处理长序列？
> **故事线：** 这讲不是从零发明 Transformer，而是在回答三个连续问题：静态词向量为什么不够、单次注意力为什么不够、只有注意力为什么反而足够强。

---

## 序幕：我们到底要解决什么问题？

词向量时代已经让词可以被映射成向量，但 `bank` 在 “river bank” 和 “bank account” 中明显不是同一个意思。

> **Source:** `lecture_9_W26.pdf`, slides 4-7

静态嵌入的问题不只是“一个词多个义项”，还包括：

- 同一个词在不同上下文里只能共用一个向量
- 训练后向量固定，不能根据当前句子动态调整
- OOV 问题依然存在
- 对词形变化和细微语义差异不敏感

于是本讲的核心问题变成：

> 怎么让每个词在当前句子里，临时生成一个“此时此地”的表示？

---

## 第一章：从静态嵌入到上下文化嵌入

### 1.1 问题：词义不能脱离上下文

词的意义取决于周围词。一个合理的表示应该满足：

- 同一个词在不同句子里可以有不同向量
- 一个词的表示可以吸收其他相关词的信息

### 1.2 第一层答案：让词主动查看整句

自注意力的出发点非常直接：

> 构造某个词的新表示时，不要只看它自己，而要让它对整句其他词进行“相关性加权”。

这意味着每个词都要回答一句话：

> 哪些词最值得我关注？

### 1.3 为什么这是关键转折？

以前的序列模型通常依赖按顺序传递状态；现在则尝试让每个词和所有词直接建立联系。  
这不是“更大的窗口”，而是“全连接式上下文读取”。

> **故事转折点：** 一旦允许每个词直接看整句，模型就不再需要依赖逐步传话的记忆链了。

---

## 第二章：Self-Attention 如何工作

> **Source:** `lecture_9_W26.pdf`, slides 19-27

### 2.1 一句话定义

**自注意力 (Self-Attention)**：序列中的每个词，用一组分数衡量自己与其他词的相关性，再把这些词的信息按权重聚合起来。

### 2.2 它到底在做什么？

可以把它理解成一场“班级讨论”：

- 当前词是提问者
- 其他词是候选回答者
- 相关性高的词说话更大声
- 最终当前词把整场讨论压缩成一个新的上下文化表示

### 2.3 为什么需要缩放点积？

slide 22-26 反复强调 softmax 对数值很敏感。维度高时，点积容易变大，softmax 会变得过尖，训练不稳定。

因此 scaled dot-product attention 的核心补丁是：

- 先算 Query 和 Key 的点积
- 再做缩放
- 再 softmax
- 再对 Value 加权求和

这一步的本质不是“数学技巧炫技”，而是为了让注意力分布更稳定、可训练。

### 2.4 为什么单头不够？

单头注意力只得到一份加权视角，容易把不同关系混成一锅。

例如一句话里可能同时存在：

- 主谓关系
- 修饰关系
- 指代关系
- 长距离依赖

**多头注意力 (Multi-Head Attention)** 的价值就在于：

- 不同头可以看不同模式
- 同一个词可以同时从多种关系中获益

> **故事转折点：** 单次聚合只能得到一种理解，多头并行才让“多角度理解”成为可能。

## 第三章：只有注意力还不够，模型还需要骨架

> **Source:** `lecture_9_W26.pdf`, slides 11-18, 28-30

Transformer 不是“注意力函数”本身，而是一套由多个部件堆起来的架构。

### 3.1 位置编码：没有循环，顺序从哪来？

RNN 靠处理顺序天然携带位置信息；Transformer 完全并行，因此必须显式告诉模型：

- 谁在前
- 谁在后
- 两个词相距多远

位置编码就是把顺序信息加到词嵌入上。  
这一步解决的是：

> 没有循环结构后，序列顺序如何保留？

### 3.2 前馈层：注意力负责“找谁重要”，FFN 负责“怎么变换”

注意力做的是跨词信息路由；前馈层做的是每个位置上的非线性特征变换。  
两者分工很清楚：

- Attention：信息交换
- FFN：局部表达升级

### 3.3 残差与 Add & Norm：让深层网络能稳定训练

残差连接不是锦上添花，而是深层 Transformer 能训练起来的必要结构之一。  
它让每层更像是在旧表示上做修正，而不是每次完全重写。

> **故事转折点：** 注意力给了模型“全局看”的能力，但位置编码、FFN、残差和归一化才让这套机制真正可堆叠、可训练、可扩展。

## 第四章：为什么 Transformer 比 RNN 时代更强

> **Inference from slides 31-39:** 这部分课程重点在“并行 + 编码器/解码器分工 + 掩码机制”。

### 4.1 并行处理：第一次真正拥抱 GPU

RNN 的核心弱点不是只能建模短依赖，而是它必须按时间步顺序执行：

`token1 -> token2 -> token3 -> ...`

Transformer 改成：

- 整句一次性算出 Query / Key / Value
- 整层并行完成注意力

这让它在工程上拥有巨大优势：

- 训练更快
- 吞吐更高
- 更容易扩模型规模

### 4.2 Decoder 为什么要 mask？

解码器做生成任务时，当前位置不能偷看未来词，否则训练和推理逻辑就断裂了。

masked self-attention 保证：

- 第 `t` 个位置只能看 `<= t` 的词
- 模型保留自回归生成能力

### 4.3 Cross-attention：生成时如何读取输入？

如果说 encoder 负责“把源句编码成一组高质量表示”，那 cross-attention 就是 decoder 的取数接口：

- decoder 当前状态提出需求
- encoder 输出提供候选信息
- cross-attention 选择此刻最相关的源端内容

这就是 encoder-decoder Transformer 能做翻译、摘要、问答等序列到序列任务的关键。

## 第五章：从架构走向生态

> **Source:** `lecture_9_W26.pdf`, slides 40-46

到这里，老师把重点从“模型结构”切到了“模型世界”：

- Hugging Face ecosystem
- Hugging Face Hub
- 现成 pipeline
- 分类、NER、问答、摘要等应用

这意味着 Transformer 的价值不只是理论更漂亮，而是它已经成为：

> 一个可复用、可迁移、可微调、可部署的工业标准平台。

这也是“Transformer-based language models”这个标题真正想表达的意思：

- 不是一个单模型
- 而是一整套模型家族与应用范式

## 第六章：为什么它还没有完美到终局

> **Source:** `lecture_9_W26.pdf`, slide 47

课程最后没有把 Transformer 神化，而是明确列出挑战：

- 对大量数据有依赖
- 长文档仍然困难
- 透明度和可解释性有限
- 容易学习训练语料中的偏差
- 跨语言与资源不平衡问题明显

这说明故事并没有结束。Transformer 虽然成为主流，但它也引出了新的研究方向：

- 长上下文建模
- 更高效注意力
- 更可解释的模型
- 更公平的训练与部署

> **故事转折点：** Transformer 解决了 RNN 时代的瓶颈，但新的规模时代又暴露出新的成本、偏差和长度问题。

## 全局回顾：技术演进路线图

```text
固定词向量 (word2vec / static embeddings)
  + 词有向量表示
  - 同一个词在不同上下文里只有一个向量
            |
            v
上下文化表示需求
  + 词义必须依赖句子环境
  - 如何动态读取整句信息？
            |
            v
Self-Attention
  + 每个词可直接关注整句所有词
  + 长距离依赖路径更短
  - 单头视角有限
            |
            v
Multi-Head Attention
  + 并行建模多种关系
  - 还需要完整架构支撑
            |
            v
Transformer
  + Self-Attention + Positional Encoding + FFN + Residual + Norm
  + 可并行、可扩展、适合大规模训练
            |
            v
Transformer-based Language Models
  + 微调与迁移学习成为主流
  + 形成 Hugging Face 等完整生态
  - 带来长文档、偏差、透明度等新挑战
```

### 转折总结表

| 从 | 到 | 解决的核心问题 |
| --- | --- | --- |
| 静态词向量 | 上下文化表示 | 一个词一个向量无法表达上下文差异 |
| 上下文化需求 | Self-Attention | 如何让词直接读取整句信息 |
| 单头注意力 | 多头注意力 | 一种相关性视角不够表达复杂关系 |
| 注意力机制 | Transformer 架构 | 需要把注意力变成可训练、可堆叠、可生成的完整系统 |
| Transformer | 应用生态 | 从论文模型走向迁移学习和工业化复用 |
