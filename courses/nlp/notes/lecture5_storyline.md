## 🎬 序幕：我们要解决什么问题？

### 一句话概括

> 给定一句话的前半部分，预测下一个词是什么。

**例子：**

```
"the students opened their ________"
→ books?  minds?  exams?  laptops?
```

这就是**语言建模 (Language Modeling)** 的核心任务。能做这件事的系统叫做**语言模型 (Language Model, LM)**。

### 为什么这很重要？

语言模型是现代 NLP 的基石，几乎所有热门应用都依赖它：

| 应用 | 语言模型的作用 |
|------|--------------|
| **手机输入法自动补全** | 预测你想输入的下一个词 |
| **Google 翻译** | 生成目标语言中最可能的词序列 |
| **语音识别 (Siri/Alexa)** | 在多个候选句子中选最像"人话"的 |
| **ChatGPT** | 本质上就是一个超大型语言模型 |

### 本讲的故事线

```
📖 故事脉络：

提出问题 → 数学基础 → 尝试方案1（失败）→ 尝试方案2（部分成功）
→ 尝试方案3（成功但有致命缺陷）→ 最终方案（解决缺陷）→ 如何评价好坏

具体来说：
语言建模 → 概率论 → N-gram → 前馈神经网络 → RNN → LSTM → Perplexity
```

## 📚 第一章：数学基础——概率论复习

> **对应 Slides:** Page 9-13  
> **为什么先讲这个？** 因为语言模型的核心就是"算概率"。不懂概率，后面全白搭。

### 1.1 有放回抽样——用彩球袋理解"预测"

**场景：** 袋子里有 15 个形状（不同颜色、不同形状），每次随机抽一个看完后放回去。

```
P(某个形状) = 该形状数量 / 总数量

例如：P(blue) = 5/15 = 1/3
```

**关键概念：** 因为放回了，每次抽取是**独立的**。连续抽多次的概率 = 各次概率的**乘积**。

```
P(连续抽到 4 个形状) = P(第1个) × P(第2个) × P(第3个) × P(第4个)
```

> 💡 **与语言模型的联系：** 预测下一个词，本质上就是在"词汇袋"里抽取最可能的词。每个词出现的概率 = 该词在特定上下文中出现的频率。

### 1.2 条件概率——"已知A，B发生的概率是多少？"

```
P(X|Y) = P(X, Y) / P(Y)
```

- **P(X|Y)：** 已知 Y 发生，X 发生的概率
- **P(X, Y)：** X 和 Y 同时发生的联合概率

> 💡 **对应语言模型：** P("books" | "students opened their") = 已知前面是"students opened their"，下一个词是"books"的概率

### 1.3 链式法则——将一句话的概率拆解成连续预测

**问题：** 如何计算一整句话出现的概率？

**答案：** 用链式法则将联合概率拆成一连串条件概率：

```
P("the students opened their books")
= P("the") 
  × P("students" | "the") 
  × P("opened" | "the students") 
  × P("their" | "the students opened") 
  × P("books" | "the students opened their")
```

> 💡 **核心洞察：** 链式法则告诉我们，一句话的概率可以分解为"逐词预测"的乘积。这就是语言模型做的事！

## 🧮 第二章：方案一——N-gram（数数派）

> **对应 Slides:** Page 18-22  
> **核心思想：** 不看完无限长的历史，只看前面 n-1 个词就够了

### 2.1 什么是 N-gram？

```
N-gram = 连续的 N 个词

Unigram  (N=1):  "the", "students", "opened"  → 单个词
Bigram   (N=2):  "the students", "students opened"  → 两个连续词
Trigram  (N=3):  "the students opened"  → 三个连续词
4-gram   (N=4):  "the students opened their"  → 四个连续词
```

### 2.2 N-gram 怎么预测？——靠数数

**方法：** 直接去一大堆文本（语料库）里数数！

**例子（4-gram）：**

```
在语料库中：
  "students opened their" 出现了 1000 次
  "students opened their books" 出现了 400 次
  "students opened their exams" 出现了 100 次

→ P(books | students opened their) = 400/1000 = 0.4  ✅ 最可能！
→ P(exams | students opened their) = 100/1000 = 0.1
```

### 2.3 ❌ N-gram 的三大致命问题

| 问题 | 说明 | 具体例子 |
|------|------|----------|
| **数据稀疏** | 很多词组合在训练数据中从未出现 | "students opened their quantum physics textbooks" → 计数=0, 概率=0 |
| **计算复杂度** | N 越大，需要存储的组合数呈指数增长 | 词汇量 5 万，4-gram 需存储 50000⁴ = 天文数字 |
| **上下文限制** | 只看前 n-1 个词，无法捕捉更远的依赖 | "as the proctor started the clock, the students opened their ____" 用 4-gram 只看 "opened their ?"，完全忽略了"proctor"和"clock"这些关键上下文 |

> 🔑 **故事转折点：** N-gram 的局限性推动我们寻找更强大的方法 → 进入神经网络时代！

## 🧠 第三章：方案二——前馈神经网络（初次尝试用"AI"）

> **对应 Slides:** Page 23-30  
> **核心思想：** 用神经网络学习词的表示和预测，而不是死板地数数

### 3.1 快速回顾神经网络基础

**三层结构（从下到上）：**

```
输入层 (Input Layer)
  ↓  权重 (weights) — 每个箭头是一个浮点数
隐藏层 (Hidden Layer) — 对所有输入的某种组合
  ↓  权重
输出层 (Output Layer) — 最终预测结果
```

**神经元 (Neuron) 的本质：**

```
输入: x₁, x₂, ..., xₘ
      ↓ × 权重 w₁, w₂, ..., wₘ
求和: v = Σ(wⱼ × xⱼ) + b  (b = 偏置 bias)
      ↓
激活函数: y = f(v)  → 引入非线性
```

> 一个神经元 = **加权求和 + 非线性变换**

### 3.2 用神经网络做语言模型

**流程：**

```
输入词 (one-hot 向量)
  ↓
词嵌入 (Word Embedding) — 将高维稀疏向量变成低维密集向量
  ↓ 拼接
隐藏层
  ↓
输出分布 — 词汇表中每个词的概率
```

**例子：**

```
输入: "the", "students", "opened", "their"
         ↓            ↓           ↓          ↓
     词嵌入向量   词嵌入向量   词嵌入向量   词嵌入向量
              ↓ 拼接 (concatenate)
           [一个长向量]
              ↓
           隐藏层
              ↓
  输出: P(books)=0.35, P(laptops)=0.25, P(exams)=0.15, ...
```

### 3.3 ❌ 前馈 NN 的致命问题——还是"固定窗口"！

**问题 1：窗口大小固定**

```
"as the proctor started the clock the students opened their ____"
                                         ↑
                                    只看这 4 个词（固定窗口）
                                    前面的 proctor、clock 全丢了！
```

**问题 2：无法处理顺序/语义反转**

```
句子 A: "The food was good, not bad at all"    → 正面情感
句子 B: "The food was bad, not good at all"    → 负面情感

如果窗口恰好只看到 "not bad" 或 "not good"，可能判断正确。
但如果窗口位置不对，这两句在模型眼里可能一样！
```

**问题 3：短文本 vs 长文本**

```
短评: "Just watched the new movie. Loved it! #entertained"
长评: "The storyline was captivating, the characters were well-developed, 
      and the cinematography was impressive. Overall, a fantastic movie night!"

长评传达同样的信息但用了更多词 → 固定窗口无法处理这种长度差异
```

> 🔑 **故事转折点：** 我们需要的不是更大的窗口，而是一种**能记住任意长度历史**的机制！

## 🔄 第四章：方案三——循环神经网络 RNN（终于有"记忆"了！）

> **对应 Slides:** Page 31-42  
> **核心思想：** 用一个不断更新的"隐藏状态"来传递记忆

### 4.1 我们到底需要什么？——四大需求

在提出解决方案之前，先明确需求：

| 需求 | 说明 | N-gram 能做到吗？ | FFNN 能做到吗？ |
|------|------|:---:|:---:|
| **处理变长序列** | 3 个词和 300 个词都要能处理 | ❌ 固定 N | ❌ 固定窗口 |
| **追踪长期依赖** | "cat" 和 "was" 隔很远也能关联 | ❌ 只看 N-1 个词 | ❌ 只看窗口内 |
| **维护顺序信息** | "dog bites man" ≠ "man bites dog" | ❌ 只看局部 | ⚠️ 取决于窗口 |
| **信息共享** | 一个位置学到的模式能用在其他位置 | ❌ 完全独立 | ❌ 不同位置用不同权重 |

> 我们需要一个**全部 ✅** 的方案 → RNN 登场！

### 4.2 理论保障——通用近似定理 (UAT)

> 由 George Cybenko 于 **1989 年**证明：
> **一个足够大的神经网络可以以任意精度近似任意连续函数**

这意味着：不管语言模式多复杂，理论上神经网络**都能学出来**。这为用深度学习做语言模型提供了数学上的底气。

### 4.3 RNN 的核心架构——有状态的计算

**一句话理解 RNN：**

> RNN = 一个神经元 + 一根"回忆线"。每处理一个词，它都会更新自己对"到目前为止看到了什么"的总结。

**核心公式：**

```
yₜ, hₜ = f(xₜ, hₜ₋₁)

输入:  xₜ    = 当前词 (如 "opened")
       hₜ₋₁  = 到目前为止的记忆摘要
输出:  yₜ    = 当前预测 (如下一个词的概率分布)  
       hₜ    = 更新后的记忆摘要 → 传给下一步
```

**展开形式——看清信息如何流动：**

```
时间: t=1        t=2            t=3            t=4
输入: "the"    "students"     "opened"       "their"
      ↓          ↓              ↓              ↓
     [h₀]→[h₁]→[h₂]→[h₃]→[h₄] → 预测: books? exams?
      ↓          ↓              ↓              ↓
     y₁         y₂             y₃             y₄

隐藏状态更新公式:
hₜ = Wₓ·xₜ + Wₕ·hₜ₋₁ + b

Wₓ: 怎么理解当前输入 (所有时间步共享！)
Wₕ: 怎么保留历史记忆 (所有时间步共享！)
```

> 💡 **关键洞察：** hₜ 就像一个**不断更新的笔记**。每读一个新词，就在笔记上追加一句话。到最后一步，笔记里浓缩了整个句子的信息。

### 4.4 与 FFNN 的对比

| | 传统 NN | RNN |
|---|---|---|
| **输入** | 所有词一次性丢进去 | 每个词按顺序逐个处理 |
| **隐藏层** | 1 个，不相连 | 多个，彼此**水平相连** |
| **顺序信息** | ❌ 丢失 | ✅ 保留 |
| **记忆** | ❌ 没有 | ✅ 通过 hₜ 传递 |
| **变长输入** | ❌ 固定大小 | ✅ 任意长度 |
| **参数共享** | ❌ | ✅ 同一套权重重复使用 |

### 4.5 如何训练 RNN？

**训练目标：** 让模型在每一步都尽可能准确地预测下一个词。

**逐步看训练过程 (以 "the students opened their exams" 为例)：**

```
Step 1: 输入 "the"       → 模型预测 → 真实答案是 "students"  → 算损失 J₁
Step 2: 输入 "students"  → 模型预测 → 真实答案是 "opened"    → 算损失 J₂
Step 3: 输入 "opened"    → 模型预测 → 真实答案是 "their"     → 算损失 J₃
Step 4: 输入 "their"     → 模型预测 → 真实答案是 "exams"     → 算损失 J₄
```

**损失函数 = 负对数概率 (Negative Log Probability)：**

```
Jₜ = -log P(真实下一个词 | 到目前为止的输入)

例: J₁ = -log P("students" | "the")

概率越高 → -log 越小 → 损失越小 → 预测越好 ✅
```

**总损失：**

```
J(θ) = (1/T) × Σ Jₜ    (所有时间步损失的平均)
```

**训练方法：时间反向传播 (Backpropagation Through Time, BPTT)**

```
前向传播: 输入 → 词嵌入 → 隐藏状态 → 预测 → 损失
反向传播: 损失 ← 调整权重 ← 从最后一步往回传误差

与普通反向传播的区别:
- 普通 BP: 误差从上层往下层传
- BPTT:    误差还要在时间步之间（从右到左）传 → "Through Time"
```

### 4.6 趣味应用：RNN 生成 Obama 演讲稿

用大量 Obama 演讲训练 RNN → 模型学会了他的用词习惯和句式结构 → 自动生成新的演讲稿！

> 💡 这就是 ChatGPT 的最早雏形——原理相同，只是规模和架构进化了。

### 4.7 ❌ RNN 的致命缺陷——梯度消失 (Vanishing Gradient)

**RNN 看起来很完美，但有一个致命问题……**

**问题的数学根源（链式法则展开）：**

```
∂J₄/∂h₁ = ∂h₂/∂h₁ × ∂h₃/∂h₂ × ∂h₄/∂h₃ × ∂J₄/∂h₄
           ~~~~~~~~   ~~~~~~~~   ~~~~~~~~
           这些值通常 < 1

如果每个值 ≈ 0.5:
→ 0.5 × 0.5 × 0.5 = 0.125  (已经缩小到 1/8)

如果序列长度=100:
→ 0.5⁹⁹ ≈ 0  → 梯度完全消失！
```

> 🔑 **类比：** 想象你在传话游戏中，每个人只传递 50% 的内容。经过 10 个人后，原始消息就完全变了。经过 100 个人？什么都听不到了。

**直观理解（看 NN 层的梯度分布）：**

```
Input Layer → Hidden₁ → Hidden₂ → Hidden₃ → Output Layer
  梯度极小      梯度小     梯度中     梯度大     梯度正常
   ████         ██████    █████████  ████████████  ██████████████
   
→ 越靠近输入的层，梯度越小，越学不动！
```

**实际 NLP 中的灾难性后果：**

```
"When she tried to print her [tickets], she found that the printer 
was out of toner. She went to the stationery store to buy more 
toner. It was very overpriced. After installing the toner into the 
printer, she finally printed her ___________"

人类一眼就知道：tickets！（因为整个故事都在讲打印机票的事）

但 RNN：
- "tickets" 在第 7 个位置
- 要预测的空在第 35+ 个位置
- 梯度从第 35 步传回第 7 步时已消失
  → RNN 根本学不到 "tickets" 和空格之间的长距离依赖！
```

> 🔑 **故事转折点：** RNN 理论上能看到所有历史，但梯度消失让它**实际上只能记住最近几步**。我们需要一种方法让梯度能"无损传递"过很长的序列！

## 🏰 第五章：最终方案——LSTM（给记忆上锁！）

> **对应 Slides:** Page 52-58  
> **核心思想：** 用"门控机制"主动控制信息的遗忘、存储和输出

### 5.1 LSTM 是什么？

**全称：** Long Short-Term Memory（长短期记忆）  
**发明者：** Hochreiter & Schmidhuber (1997)  
**目标：** 让 RNN 能记住长期信息——专治梯度消失！

### 5.2 LSTM vs RNN——关键区别

**RNN 只有一个状态 hₜ（隐藏状态），LSTM 有两个：**

| 状态 | 名称 | 作用 | 类比 |
|------|------|------|------|
| **hₜ** | Hidden State (隐藏状态) | 捕捉**短期**依赖 | 工作台上正在用的笔记 |
| **cₜ** | Cell State (细胞状态) | 存储**长期**信息 | 上了锁的保险箱 |

> 💡 **类比：** RNN 只有一个笔记本，什么都往里写，写满就覆盖旧内容。LSTM 多了一个保险箱——重要信息锁进去，不会被轻易覆盖。

### 5.3 LSTM 的三扇门（核心创新）

LSTM 的革命性设计：**用三扇"门"来主动控制信息流！**

```
每扇门 = 一个 0~1 之间的向量
  0 = 完全关闭（不让信息通过）
  1 = 完全打开（完全让信息通过）
通过 Sigmoid 函数 σ 实现，根据当前输入动态决定
```

#### 🚪 门 1：遗忘门 (Forget Gate) — "哪些旧记忆该丢掉？"

```
fₜ = σ(W_f · [hₜ₋₁, xₜ] + b_f)
```

**作用：** 看一下当前输入 xₜ 和上一步记忆 hₜ₋₁，决定保险箱里哪些旧信息该扔掉。

**例子：**
```
处理 "她养了一只猫。... 后来她养了一只狗。"

当看到 "狗" 时：
→ 遗忘门 fₜ → 在"宠物类型"这个维度上趋近 0
→ 效果：擦除"猫"的记忆，为"狗"腾出空间
```

#### 🚪 门 2：输入门 (Input Gate) — "存入什么新信息？"

```
iₜ = σ(W_i · [hₜ₋₁, xₜ] + b_i)        ← 决定存多少
c̃ₜ = tanh(W_c · [hₜ₋₁, xₜ] + b_c)     ← 候选新记忆

cₜ = fₜ × cₜ₋₁ + iₜ × c̃ₜ              ← 更新保险箱！
     ~~~~~~~~     ~~~~~~~~
     遗忘旧的      加入新的
```

**作用：** 先用 tanh 生成候选新信息 c̃ₜ，再用输入门 iₜ 控制实际存入多少。

> 💡 **关键公式解读：** `cₜ = fₜ × cₜ₋₁ + iₜ × c̃ₜ`  
> - 先遗忘：`fₜ × cₜ₋₁` = 保留旧记忆中有用的部分  
> - 再添加：`iₜ × c̃ₜ` = 加入新学到的信息  
> - **注意这是加法 (+) 不是乘法 (×)！** 这就是梯度能顺利传播的秘密！

#### 🚪 门 3：输出门 (Output Gate) — "当前需要输出什么？"

```
oₜ = σ(W_o · [hₜ₋₁, xₜ] + b_o)
hₜ = oₜ × tanh(cₜ)
```

**作用：** 不是所有保险箱里的信息现在都需要。输出门决定从保险箱中取出多少给当前步使用。

### 5.4 完整流程总结

```
每个时间步 LSTM 做 6 件事：

1️⃣  计算遗忘门 fₜ     → "保险箱里这些旧东西还要吗？"
2️⃣  遗忘部分旧记忆     → cₜ₋₁ × fₜ
3️⃣  计算输入门 iₜ      → "新东西要存多少？"
4️⃣  生成候选新记忆 c̃ₜ  → "有什么新东西？"
5️⃣  更新细胞状态 cₜ    → fₜ × cₜ₋₁ + iₜ × c̃ₜ
6️⃣  计算输出门 oₜ      → "现在需要用到什么？"
7️⃣  输出隐藏状态 hₜ    → oₜ × tanh(cₜ)
```

### 5.5 为什么 LSTM 能解决梯度消失？

```
RNN 的梯度传播路径:
h₁ → (×W) → h₂ → (×W) → h₃ → (×W) → h₄    ← 不断乘 W，梯度消失！

LSTM 的 Cell State 传播路径:
c₁ → (×f₂ + new₂) → c₂ → (×f₃ + new₃) → c₃   ← 加法！梯度直通！
```

**Cell State 就像一条高速公路：**
- 旧信息沿着顶部**直线**流过
- 只经过一次乘法（遗忘门）和一次加法（输入门）
- 梯度可以沿这条线**几乎无损**地传回很远的时间步

> 💡 对比：RNN 的梯度要经过 `W × W × W × ...`（指数衰减），  
> 而 LSTM 的 Cell State 梯度主要通过**加法**传递，衰减极小。

### 5.6 代码实现（Keras）

```python
from keras.models import Sequential
from keras.layers import Dense, Activation, LSTM

model = Sequential()
model.add(LSTM(10, input_shape=(TIMESTEPS, FEATURE_LENGTH)))  # 10个隐藏节点
model.add(Dense(NUMBER_OF_OUTPUT_NODES))  # 全连接输出层
model.add(Activation('softmax'))  # 概率分布
```

> 💡 就这么简单！框架帮你封装了所有三个门的内部计算。

## 📏 第六章：如何评估语言模型？——困惑度 (Perplexity)

> **对应 Slides:** Page 61

### 公式

```
PPL = 语料库的逆概率，按词数归一化
```

### 直觉理解

| PPL 值 | 含义 | 类比 |
|--------|------|------|
| **PPL 低 (如 20)** | 模型预测准 | 填空题几乎都答对了 |
| **PPL 高 (如 200)** | 模型很困惑 | 填空题大部分都猜错了 |

> 💡 PPL 可以理解为"模型在每个位置平均需要从多少个词中选择"。  
> PPL=10 → 平均在 10 个等可能的词中选 → 还算确定  
> PPL=50000 → 在 5 万个词中随机猜 → 完全不知道
