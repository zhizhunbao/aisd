## 🎬 序幕：计算机如何"猜"下一个词？

### 核心挑战

人类输入 "the students opened their" 时，手机键盘立刻建议 "books"、"eyes"、"laptops"。这个功能背后的系统叫做**语言模型 (Language Model)**。

**语言模型的目标：给定已经出现的词序列，预测下一个词的概率分布。**

```
Input:  "the students opened their"
Output: P(books) = 0.4, P(exams) = 0.1, P(laptops) = 0.15, ...
```

前面我们已经学习了如何把词变成向量（Word2Vec、GloVe、FastText）。这些向量编码了词的**含义**。但光有含义还不够——我们还需要理解词与词之间的**顺序关系**。

> 💡 **翻译类比：** 词嵌入就像掌握了每个单词的意思（词典），但语言模型是掌握了**语法和搭配规律**（语感）。两者缺一不可。

```

## 📚 第一章：概率论基础——语言模型的数学根基

### 1.1 有放回抽样 (Sampling with Replacement)

语言模型的核心是**概率**。先用一个简单的袋子游戏理解基本概念：

- 袋中有15个形状（不同颜色/类型），随机取出一个再放回
- P(blue) = 5/15, P(red) = 5/15
- 条件概率：P(△|red) = 3/5 → "已知是红色，是三角形的概率"
- 序列概率：连续取多次，各步概率相乘

> 💡 **掷骰子类比：** 有放回抽样就像反复掷同一个骰子——每次的概率不变。语言模型把"预测下一个词"也看作一次次的"抽样"。

> 💡 **和语言模型的关系：** 有放回抽样展示了"序列概率 = 各步概率连乘"的基本形式。这是链式法则的特例（各步独立）。语言模型是**非独立版本**——每一步的概率取决于前面所有的词，而不是每次概率不变。

### 1.2 条件概率 (Conditional Probability)

**条件概率**是语言模型的数学灵魂：

```
P(X|Y) = P(X, Y) / P(Y)
```

"在Y已经发生的条件下，X发生的概率"。

**语言模型中的应用：** P(books | students opened their) = "在已经看到'students opened their'的条件下，下一个词是'books'的概率"。

### 1.3 链式法则 (Chain Rule)

链式法则把一个长句的联合概率拆成一连串条件概率：

```
P(the, students, opened, their, books)
= P(the)
× P(students | the)
× P(opened | the, students)
× P(their | the, students, opened)
× P(books | the, students, opened, their)
```

**这就是语言模型要计算的东西！** 每一步都是"给定前面所有的词，预测下一个词的概率"。

> 💡 **故事接龙类比：** 链式法则就像接龙写故事——每个人说一个词，必须考虑前面所有人说了什么。P(这个词|前面所有词) 就是你选这个词的"合理程度"。

## 🎭 第二章：方案一——N-gram统计（❌ 近视的统计方法）

### 2.1 核心思想：数频率

N-gram的思路极其简单粗暴：

1. **统计**：在大量文本中数每个N个词组合出现了几次
2. **预测**：用频率估计概率

```
P(books | students opened their)
= count("students opened their books") / count("students opened their")
= 400 / 1000
= 0.4
```

### 2.2 马尔可夫假设——主动"近视"

链式法则要求考虑**前面所有的词**，但这在统计上不可能——"the students opened their"这种4个词的组合在语料库中出现的次数已经很少了，更长的序列几乎找不到。

**马尔可夫假设（Markov Assumption）：** 假定下一个词**只依赖前面n-1个词**。

```
完整条件：P(books | the students opened their)  ← 太长，统计不到
马尔可夫：P(books | students opened their)      ← 只看前3个词（4-gram）
极简版：  P(books | their)                      ← 只看前1个词（bigram）
```

### 2.3 4-gram实例

```
句子：as the proctor started the clock the students opened their ______

用4-gram（只看前3个词）：
  P(books  | students opened their) = 400/1000 = 0.4
  P(exams  | students opened their) = 100/1000 = 0.1
  P(laptops| students opened their) = 200/1000 = 0.2
```

### 2.4 ❗ N-gram的三大致命问题

| 问题               | 解释                                                     | 例子                                                 |
| :----------------- | :------------------------------------------------------- | :--------------------------------------------------- |
| **数据稀疏**       | 很多n-gram在语料中从未出现过 → 概率为0                   | "students opened their horizons" 可能从未出现        |
| **上下文窗口固定** | 只看n-1个词，无法理解更远的依赖                          | 4-gram看不到句首的"proctor"                          |
| **计算复杂度**     | n越大，需要存储的n-gram组合数呈指数增长                  | 词表5万，4-gram组合数 = 5万⁴ ≈ 6.25×10¹⁸            |

> 💡 **近视类比：** N-gram就像一个只能看前面3步的人——"students opened their"之前发生了什么完全不知道。而且如果这3步没走过（语料中没见过），他就完全没有判断力（概率=0）。

> 🔑 **故事转折点：** N-gram受制于数据稀疏和固定窗口——我们需要一种能从有限数据中**泛化**的方法 → **神经网络语言模型**登场！

## 📖 第三章：方案二——前馈神经网络语言模型（⚡ 有泛化能力，但仍有固定窗口）

### 3.0 先搞清楚：什么是神经网络？什么是"前馈"？

在讲"前馈神经网络语言模型"之前，先把基本概念理清：

**神经网络 (Neural Network)** 是一种模仿人脑神经元连接方式的计算模型。最基本的单元叫**感知器 (Perceptron)**——把所有输入乘以权重加起来，通过一个激活函数决定输出：

```
输入 x₁, x₂, ..., xₘ
  ↓  各乘权重 w₁, w₂, ..., wₘ
  ↓  加起来 + 偏置 b
  ↓  通过激活函数
  → 输出 y
```

把很多感知器排列成层、层层连接，就得到了**多层神经网络**。根据信息流动方向的不同，分为两大类：

```
前馈 (Feedforward): 输入 ──→ 隐藏层 ──→ 输出    （数据单向流动，不回头）
循环 (Recurrent):   输入 ──→ 隐藏层 ──→ 输出    （隐藏层有回路，信息可以循环）
                             ↑____↩
```

**"前馈"就是"数据只往前走，不往回传"**——最朴素、最基本的神经网络结构。"前馈"这个名字其实是有了 RNN 之后才加的——在 RNN 之前，大家就叫它"神经网络"，不需要加前缀。

### 3.1 为什么神经网络能帮忙？

N-gram的致命问题在于**泛化能力为零**——没见过的组合概率就是0。但如果我们知道"students"和"pupils"含义接近（词嵌入！），那么见过"students opened their books"就应该能推断"pupils opened their books"也有较高概率。

**前馈神经网络语言模型的核心改进：用词嵌入替代独热编码，用隐藏层学习组合模式。**

### 3.2 架构详解

```
输入层:    "students"     "opened"      "their"     ← 3个词（窗口=3）
           ↓               ↓              ↓
嵌入查找:  e_students     e_opened      e_their     ← 每个词查表得到一个300维向量
           ↓               ↓              ↓
拼接:      [e_students ; e_opened ; e_their]        ← 拼成一个 900维 的长向量
           ↓
隐藏层:    h = f(W · [拼接向量] + b)                 ← 非线性变换
           ↓
输出层:    softmax → P(books), P(exams), ...          ← 词表上的概率分布
```

> **公式里每个符号的意思：**
>
> | 符号 | 是什么 | 说明 |
> |:-----|:-------|:-----|
> | **W** | 权重矩阵 (Weight Matrix) | 一张数字表。列数 = 输入维度（3词×300维=900），行数 = 隐藏层节点数（自己选的超参数，比如100）→ 即 100×900。**训练前是随机数，训练后被梯度下降调好——W 就是模型学到的"知识"所在** |
> | **b** | 偏置 (Bias) | 一个额外的调节项，让模型更灵活 |
> | **f** | 激活函数 | 加入非线性（如 tanh、ReLU），否则多层矩阵乘法等于一层，叠再多层也没用 |
> | **softmax** | 概率转换 | 把输出的原始分数转成概率分布（所有词的概率加起来 = 1） |

> 💡 **"查表"到底怎么查？**
>
> **第1步：给每个词编号**
> ```
> "a"=1, "about"=2, ..., "students"=4237, ..., "zoo"=50000
> ```
>
> **第2步：建一个大表（嵌入矩阵）**
> ```
> 嵌入矩阵: V行 × d列（V=词表大小，d=嵌入维度，都是人为选择的超参数）
>           例如 V=5万, d=300 → 5万行×300列，一行一个词，5万行就是5万个词
>
> 行 0001: [0.12, 0.05, -0.33, ..., 0.67]   ← "a" 的含义向量
> 行 0002: [0.41, -0.22, 0.15, ..., 0.03]   ← "about" 的含义向量
> ...
> 行 4237: [0.23, -0.45, 0.12, ..., 0.78]   ← "students" 的含义向量
> ...
> ```
>
> **第3步：输入 "students" → 查编号 4237 → 取出那一行 → 得到 300 个数字**
>
> 就是这么简单，没有什么神秘计算，**就是查表**。
>
> ⚠️ 有些教科书会写"先转成 one-hot 向量，再乘以嵌入矩阵"——这只是**数学上的等价写法**，让所有操作统一成矩阵乘法。实际代码里没人创建 5 万维的 one-hot 向量，就是直接按编号取一行（`embedding[4237]`）。
>
> **拼接后的实际维度：** 3个词 × 每词300维 = 900维向量 → 这才是隐藏层真正吃进去的输入。

> 💡 **这 300 个数字哪来的？** 嵌入矩阵可以是**预训练**的（别人用 Word2Vec/GloVe 在几十亿词上训练好，你下载现成的表），也可以**随模型一起训练**（一开始是随机数，训练过程中一边用一边调）。无论哪种方式，关键是：含义相近的词（students/pupils）的向量会很接近，这就是泛化能力的来源。

> 💡 **为什么是 300 维，不是 5 万维？**
>
> 5 万维就是 one-hot——每个词占一个维度，剩下 49,999 个位置全是 0，浪费且没有含义信息。300 维不是"每个词一个坑"，而是"每个维度描述一种语义特征"。类比：地球上几百万个城市，只要 2 个数字（经度、纬度）就能唯一定位，不需要"每个城市一个维度"。300 是实验调出来的经验平衡点——太少语义区分不够，太多浪费算力。更大的模型会用更高维度（BERT 用 768，GPT-3 用 12288）。

> ⚠️ **每一维到底代表什么？人不知道。** 这 300 个数字是算法从几十亿词的上下文中**自己学出来的**，没人设计也没人标注。我们唯一能观察到的是**效果**：dog 和 puppy 的向量很接近，dog 和 table 的很远。至于哪几维起了什么作用——黑盒，看不出来。这是神经网络的本质特点：**好用但不可解释**。

### 3.3 比N-gram好在哪？

| 维度         |     N-gram     | 前馈NN语言模型 |
| :----------- | :------------: | :------------: |
| 泛化能力     | ❌ 没见过=概率0 | ✅ 嵌入相似→概率相似 |
| 特征表示     |    独热编码    |    稠密嵌入    |
| 学习方式     |    直接计数    |    梯度下降    |
| 上下文窗口   |    固定(n-1)   |    固定(仍然!) |

### 3.3b 前馈NN的训练——梯度下降初登场

前馈NN和N-gram不同，它不是"数频率"——它通过**梯度下降 (Gradient Descent)** 和**反向传播 (Backpropagation)** 来训练：

```
1. 随机初始化权重 → 前馈计算 → 得到预测概率分布
2. 用损失函数（交叉熵）衡量"预测"与"实际下一个词"的差距
3. 反向传播：计算每个权重的梯度（"往哪个方向调能减小误差"）
4. 按梯度方向更新权重 → 重复
```

**梯度**就是"调整方向信号"——告诉每个权重"你该变大还是变小"。没有梯度，权重就只能随机瞎猜，模型永远学不会。

> 💡 **为什么前馈NN没有梯度问题？** 前馈NN语言模型通常只有**1~2个隐藏层**，梯度只需传回1~2层，衰减可以忽略。但后面我们会看到，RNN展开后相当于**几十层深**的网络——梯度要连乘几十次，问题就来了（详见4.6节）。

### 3.4 ❗ 前馈NN的致命问题——仍然是固定窗口

**问题1：窗口外的信息被丢弃**

```
"as the proctor started the clock the students opened their ______"
 └─────────── 被丢弃 ──────────┘  └── 只看这3个词 ──┘
```

**问题2：窗口太窄导致语义错判**

```
"The food was good, not bad at all" → 正面情感
"The food was bad, not good at all" → 负面情感
```

如果窗口大小=3，两句话的末尾窗口分别截取到 `"bad at all"` 和 `"good at all"`，看起来第一句含 "bad"（其实是正面），第二句含 "good"（其实是负面）——固定窗口丢失了前文的否定关系，导致语义判断完全颠倒！

**问题3：无法处理变长输入**

- 短句 "Loved it!" (2个词) 和长句 "The storyline was captivating..." (15个词) 需要不同大小的窗口
- 但前馈NN的输入大小是**固定的**

> 🔑 **故事转折点：** 前馈NN解决了泛化问题（通过词嵌入），但窗口大小固定→看不到远处的上下文、无法处理变长序列。我们需要一种能**逐词处理并记住历史**的架构 → **RNN**登场！

## 🏆 第四章：方案三——循环神经网络 RNN（✅ 有记忆，❌ 记忆太短）

### 4.1 序列建模的四大需求

在引入RNN之前，先明确我们对理想序列模型的需求：

1. **处理变长序列** — 不限制输入长度
2. **追踪长距离依赖** — 句首的信息也要能影响句尾的预测
3. **保持词序信息** — "not bad" ≠ "bad not"
4. **共享参数** — 不同位置用同样的处理方式

### 4.2 RNN的核心思想：有状态的计算

RNN的革命性创新：**隐藏状态 (hidden state)**

```
传统NN:  输入 → 处理 → 输出（处理完就忘了）
RNN:     输入 + 上一步的记忆 → 处理 → 输出 + 更新记忆
```

每一步的计算：
```
hₜ = tanh(W_xh · xₜ + W_hh · hₜ₋₁ + b)    ← f 通常是 tanh（将值压缩到 -1~1）
yₜ = softmax(W_hy · hₜ)                     ← g 在语言模型中是 softmax（输出概率分布）
```

其中：
- xₜ = 时间步t的输入（当前词的嵌入向量）
- hₜ₋₁ = 上一步的隐藏状态（"记忆"）
- hₜ = 更新后的隐藏状态（融合了当前输入+历史信息）
- yₜ = 时间步t的输出（对下一个词的预测概率分布）
- W_xh, W_hh = **所有时间步共享**的权重矩阵
- tanh 将隐藏状态压缩到 [-1, 1] 范围，防止数值无限增长
- softmax 将输出转换为概率分布（所有词的概率之和 = 1）

> 💡 **更新笔记类比：** hₜ就像一个不断更新的笔记本。每读一个新词，你就在笔记本上记一笔（把新信息和旧笔记混合）。最终笔记本包含了你读过的所有内容的"摘要"。

### 4.3 RNN展开视图

把循环"展开"后，RNN就变成一条链：

```
h₀ ──W_hh──→ h₁ ──W_hh──→ h₂ ──W_hh──→ h₃ ──W_hh──→ h₄
              ↑              ↑              ↑              ↑
             W_xh           W_xh           W_xh           W_xh
              |              |              |              |
             x₁="the"      x₂="students"  x₃="opened"   x₄="their"
              |              |              |              |
             y₁             y₂             y₃             y₄
         P(students)    P(opened)      P(their)       P(books=0.4)
```

**关键洞察：**
- 所有时间步**共享同一组权重** (W_xh, W_hh) → 参数效率高
- 理论上，h₄ 包含了 x₁~x₄ 的信息 → 不限制上下文长度
- 可以处理任意长度的序列

### 4.4 RNN训练：BPTT

**训练过程：**
1. 逐词输入语料："the" → "students" → "opened" → "their" → "exams"
2. 每一步预测下一个词，计算交叉熵损失
3. 总损失 = 所有步骤损失之和
4. 通过**时间反向传播 (BPTT, Backpropagation Through Time)** 更新权重

```
总损失 = -log P("students"|"the")
       + -log P("opened"|"the","students")
       + -log P("their"|"the","students","opened")
       + -log P("exams"|"the","students","opened","their")
       + ...
```

### 4.5 前馈NN vs RNN 对比

| 维度         | 前馈NN语言模型 | RNN语言模型 |
| :----------- | :------------: | :---------: |
| 输入长度     | 固定窗口 | 任意长度 |
| 上下文范围   | 窗口内n-1个词 | 理论上无限 |
| 记忆机制     | 无 | 隐藏状态hₜ |
| 参数共享     | 不同位置拼接为输入，无时间维度共享 | 所有时间步共享W |
| 词序感知     | 通过拼接位置 | 自然保持顺序 |

### 4.6 ❗ RNN的致命问题——梯度消失 (Vanishing Gradient)

理论上RNN可以记住任意远的信息，但**实际训练中做不到**。

在3.3b节我们提过，前馈NN也用梯度下降训练，但只有1~2层，梯度传播没有问题。RNN的情况完全不同——展开后变成**几十层深**的网络，梯度要连乘几十次。下面先回顾梯度的基本概念，再解释为什么这种连乘会致命。

#### 为什么需要梯度？

神经网络的权重（W）一开始是**随机的**。训练的本质就是：**试错 + 知道往哪个方向调**。

```
梯度 = ∂Loss/∂W = "如果把 W 稍微调大一点，Loss 会变大还是变小？"

梯度为正 → W 增大会让 Loss 变大 → 应该减小 W
梯度为负 → W 增大会让 Loss 变小 → 应该增大 W

更新公式：W_new = W_old - 学习率 × 梯度
                              ↑       ↑
                         往反方向走  每步走多远
```

> 💡 **蒙眼下山类比：** 想象你蒙着眼站在山上，目标是走到谷底（Loss最小）。你看不见路，只能用脚试探地面的倾斜方向——往低处迈一步。脚下感知到的「倾斜方向」就是梯度。**没有梯度 = 没有方向感 = 权重无法更新 = 模型永远是随机瞎猜。**

#### 为什么梯度会消失？

RNN 中同一组权重 W_hh 在每个时间步**重复使用**。反向传播时，梯度要从最后一步传回第一步，每经过一个时间步都要**乘以 W_hh**：

```
∂Loss/∂h₁ = ∂Loss/∂h₄ × ∂h₄/∂h₃ × ∂h₃/∂h₂ × ∂h₂/∂h₁
                         ^^^^^^^^    ^^^^^^^^    ^^^^^^^^
                         每一步都要乘以 W_hh 的某种变体
```

**连乘的指数级后果（假设每步乘以 0.9）：**

```
传 1 步:  0.9¹  = 0.90  ← 还好
传 5 步:  0.9⁵  = 0.59  ← 快减半了
传10 步:  0.9¹⁰ = 0.35  ← 明显变小
传20 步:  0.9²⁰ = 0.12  ← 快没了
传30 步:  0.9³⁰ = 0.04  ← 几乎为零！
```

- 如果 |W_hh| < 1 → 梯度**指数级衰减**（消失）→ 前面的层收到的调整信号约等于零
- 如果 |W_hh| > 1 → 梯度**指数级爆炸**（爆炸）→ 参数更新不稳定

> *（简化说明：W_hh 是矩阵，这里把它类比为标量来展示指数连乘的效果。严格来说应看 W_hh 的最大特征值是否 > 1 或 < 1。）*

**实际后果：**

```
"When she tried to print her tickets, she found that the printer
 was out of toner. She went to the stationery store to buy more
 toner. It was very overpriced. After installing the toner into
 the printer, she finally printed her ______"

模型在第30步预测错了，需要告诉第7步："你处理 tickets 的方式有问题"
但梯度经过 23 步连乘后 ≈ 0 → 纠错信号传不回去 → RNN 学不会这个关联！
```

> 💡 **传话游戏类比：** 30个人排队传悄悄话。第30个人说"第1个人处理 tickets 的方式要改"，消息每传一个人就失真一点。传到第1个人时，收到的信息是"..."——什么都没收到。**这就是梯度消失：纠错信号传不回远处。**

| 特性         | 理论值 | 实际效果 |
| :----------- | :----: | :------: |
| 上下文范围   | 无限   | ~5-10步  |
| 长距离依赖   | 可以捕获 | 几乎不可能 |
| 短距离依赖   | 很好   | 很好     |

> 🔑 **故事转折点：** RNN的隐藏状态理论上可以携带无限远的信息，但梯度消失使得实际上只能学到5~10步以内的依赖。我们需要一种机制，让重要信息**不衰减地**穿越长距离 → **LSTM**登场！

## 🔑 第五章：方案四——LSTM长短期记忆网络（✅ 解决长距离依赖！）

### 5.1 LSTM的诞生

1997年，Hochreiter & Schmidhuber 提出LSTM（Long Short-Term Memory），正面解决RNN的梯度消失问题。

**核心创新：** 在隐藏状态之外，增加一条**细胞状态 (Cell State)** 通道——一条信息高速公路。

```
RNN:    只有 hₜ（隐藏状态） → 所有信息挤在一条线上
LSTM:   hₜ（隐藏状态）+ Cₜ（细胞状态） → 短期记忆和长期记忆分离

    Cₜ₋₁ ──────────────────────────────→ Cₜ   ← 细胞状态（长期记忆高速公路）
              │          │         │
          [遗忘门]    [输入门]   [输出门]       ← 三个"阀门"控制信息流
              │          │         │
    hₜ₋₁ ──────────────────────────────→ hₜ   ← 隐藏状态（短期记忆/输出）
              ↑
             xₜ                                ← 当前输入
```

> 💡 **公共汽车vs高速公路类比：** RNN的隐藏状态像公共汽车——每站都要停，信息不断被覆盖和遗忘。LSTM的细胞状态像高速公路——信息可以直接穿越很远的距离，只在需要的"出口"下车。

### 5.2 三大门控机制

LSTM通过三个**门 (Gate)** 来精确控制信息的流入流出：

#### 门1：遗忘门 (Forget Gate) — "该忘什么？"

```
fₜ = σ(Wf · [hₜ₋₁, xₜ] + bf)
```

- σ (sigmoid) 输出0~1之间的值
- fₜ = 0 → **完全遗忘**旧信息
- fₜ = 1 → **完全保留**旧信息

> 💡 类比：阅读一个长故事时，遇到"话题已经换了"就忘掉之前的细节，遇到"还在同一个话题"就继续记住。

#### 门2：输入门 (Input Gate) — "该记什么新东西？"

```
iₜ = σ(Wi · [hₜ₋₁, xₜ] + bi)       ← 决定更新哪些位置
c̃ₜ = tanh(Wc · [hₜ₋₁, xₜ] + bc)    ← 生成候选新信息
```

**细胞状态更新：**
```
Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ c̃ₜ
     └──忘旧──┘   └──记新──┘
```

> 💡 类比：更新笔记——先用橡皮擦掉不要的旧内容（遗忘门），再写上重要的新内容（输入门）。

#### 门3：输出门 (Output Gate) — "该输出什么？"

```
oₜ = σ(Wo · [hₜ₋₁, xₜ] + bo)
hₜ = oₜ ⊙ tanh(Cₜ)
```

细胞状态存储了所有记忆，但不是所有记忆都跟当前预测有关。输出门选择性地从细胞状态中提取相关信息作为隐藏状态输出。

> 💡 类比：你记了很多笔记（细胞状态），但考试时只需要写相关的知识点（输出门过滤后的隐藏状态）。

### 5.3 LSTM 为什么能解决梯度消失？

关键在于细胞状态的更新方式：

```
Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ c̃ₜ
```

这是一个**加法**操作（不是乘法）！梯度沿着这条加法通道传播时：

```
∂Cₜ/∂Cₜ₋₁ ≈ fₜ  ← 遗忘门的值（0~1之间）
```

> ⚠️ **简化说明：** 严格来说 iₜ⊙c̃ₜ 项也间接依赖 Cₜ₋₁（通过 hₜ₋₁ = oₜ₋₁⊙tanh(Cₜ₋₁)），所以完整梯度不只是 fₜ。但关键区别在于：**RNN 的梯度只能走 W_hh 连乘这一条路，而 LSTM 多了一条近似恒等映射的加法捷径。** 这条捷径是梯度能远距离传播的核心原因。

只要遗忘门 fₜ 接近1（"记住"），**梯度就几乎不衰减地沿加法通道传回去**。网络可以学会对重要信息保持 fₜ ≈ 1，让梯度穿越几十甚至上百步。

```
RNN:   梯度只能走 → W_hh × W_hh × ... × W_hh  ← 连乘→指数衰减
LSTM:  梯度可以走 → fₜ × fₜ₋₁ × ... × f₂      ← 加法捷径，门值接近1→几乎不衰减
```

> 💡 **类比：** RNN 像只有一条乡间小路——每经过一个村子信号就衰减一点。LSTM 多修了一条高速公路（细胞状态）——信号可以直接飞过去，几乎不减弱。

### 5.4 LSTM vs RNN 完整对比

| 维度             |      RNN       |            LSTM             |
| :--------------- | :------------: | :-------------------------: |
| 状态             | 只有hₜ         | hₜ（短期）+ Cₜ（长期）     |
| 信息控制         | 无门控         | 3个门精确控制               |
| 长距离依赖       | ❌ ~5-10步     | ✅ 几十到上百步             |
| 参数量           | 少             | 约4倍于同等RNN              |
| 梯度流           | 连乘→消失      | 加法通道→保持                |

### 5.5 Keras实现

```python
from keras.models import Sequential
from keras.layers import Dense, Activation, LSTM

model = Sequential()
model.add(LSTM(10, input_shape=(TIMESTEPS, FEATURE_LENGTH)))
# 10 = units数，即 hidden state 和 cell state 的维度（两者维度相同）
# TIMESTEPS = 序列长度
# FEATURE_LENGTH = 每个时间步的输入维度（词嵌入维度）
model.add(Dense(NUMBER_OF_OUTPUT_NODES))
model.add(Activation('softmax'))
```

## 📹 第六章：语言模型的评估——困惑度 (Perplexity)

有了 N-gram、前馈NN、RNN、LSTM 四种语言模型后，自然要回答一个问题：**怎么判断哪个模型更好？** 我们需要一个统一的评估标准——**困惑度 (Perplexity)**。

### 6.1 什么是困惑度？

**Perplexity (PPL)** 衡量语言模型在预测下一个词时有多"困惑"。

```
完整公式：
PPL(W) = P(w₁w₂...wₙ)^(-1/N)
       = exp( -(1/N) × Σ log P(wᵢ | w₁...wᵢ₋₁) )

简记：PPL = exp(平均每词的交叉熵损失)    ← 此处 log = ln（自然对数）

其中：N = 词数，P(wᵢ|...) = 模型对第 i 个词的预测概率
```

- **PPL低** → 模型预测准确，"不困惑" 🎯
- **PPL高** → 模型预测差，"很困惑" 😵

### 6.2 直觉理解

```
PPL = 10  → 模型平均在10个候选词中犹豫
PPL = 100 → 模型平均在100个候选词中犹豫
PPL = 1   → 模型100%确信下一个词是什么（理想状态）
```

PPL可以理解为**"有效词表大小"**——模型在每步预测中实际考虑的候选词数量。

> 💡 **选择困难类比：** PPL就像你在餐厅点菜时的犹豫程度。PPL=3意味着你在3道菜之间犹豫，PPL=100意味着菜单上每道菜你都觉得可能吃。好的模型就像在熟悉的餐厅——知道自己最想吃什么，PPL很低。
