> A hands-on build challenge where entrepreneurs, makers, designers, and engineers team up to create a **physical + digital product** — something that exists physically but connects to intelligence, data, or an application.

核心四大方向：

### 1. Create Something Real（做出真东西）

> Possibility to go beyond mockups. Build a tangible prototype you can hold, demo, and show off.

> Integrate AI and new technologies into your workflow and product build, using AI as thought partners and assistants.

## 🏆 推荐项目方向 (详细)

### 🥇 TOP 1: Physical AI Device（物理AI设备）

**为什么最推荐**：完美融合你的 NLP + RL 技能

- **产品形态**：一个桌面实体设备（3D打印外壳 + Raspberry Pi/Arduino）
- **核心功能**：能对话、回应、从用户互动中学习
- **你的角色**：
  - 集成 LLM API（GPT / Claude）做对话
  - 用 RL 优化交互体验（根据用户反馈调整行为）
  - 语音识别 + 语音合成
  - 数据存储与分析

**技术栈示例**：

```
硬件: Raspberry Pi + Speaker + Microphone + 3D打印外壳
软件: Python + LLM API + Speech-to-Text + Text-to-Speech
AI:   NLP对话 + RL交互优化 + 用户数据学习
```

### 🥇 TOP 2: Sensor Cube（传感器方块）

**为什么推荐**：ML + MV 的直接应用

- **产品形态**：一个便携方块（内含传感器 + 处理器）
- **核心功能**：感知环境 → ML推理 → 实时给出答案
- **你的角色**：
  - 训练传感器数据分类/回归模型
  - 设计数据 pipeline
  - 实时推理部署（edge AI）
  - 数据可视化仪表板

**技术栈示例**：

```
硬件: Arduino + 温湿度/光照/声音传感器 + 显示屏
软件: Python + scikit-learn/PyTorch + Flask API
AI:   环境分类模型 + 异常检测 + 实时预测
```
