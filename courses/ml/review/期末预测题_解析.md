## PART 1: True / False (Q1 ~ Q10) — 每题3分，共30分

> 💡 教授陷阱模式复习："always"、"only"、"identical"、"cannot" 等绝对表达一出现立刻警惕！名称和定义对调的模式也是高频考点。

### Q1. In imbalanced class problems, accuracy is always a reliable metric for evaluating classifier performance.

**FALSE** ❌

**解析**：在不平衡数据(Imbalanced Data)中，准确率(Accuracy)是不可靠的指标。例如：正样本10个、负样本990个的情况下，即使将所有预测为负类，准确率也能达到99%，但正类一个都没有抓到。这种情况下，Precision（精确率）、Recall（召回率）、F1-measure 更为合适。

> 💡 TIP: "always"是核心陷阱。在不平衡数据中 accuracy 具有误导性！

---

### Q2. Oversampling the minority class works by randomly duplicating instances of the minority class to balance the dataset.

**TRUE** ✅

**解析**：过采样(Oversampling)是通过复制(Duplicate)少数类(Minority Class)的实例来与多数类实现平衡的技术。方法简单但由于反复使用相同实例，存在过拟合(Overfitting)的风险。改进版就是 SMOTE。

> 💡 TIP: 单纯复制(Duplicate) = Oversampling。合成生成(Synthetic) = SMOTE。必须区分！

---

### Q3. SMOTE generates synthetic minority class instances by duplicating existing minority class instances and adding a small amount of random noise.

**FALSE** ❌

**解析**：SMOTE (Synthetic Minority Oversampling Technique) 不是简单的复制+噪声。它在少数类实例与其 k-最近邻(k-NN) 之间的线段(Line Segment)上生成新的合成实例。具体方式是计算差异(Difference)，乘以0~1之间的随机值后加到原实例上。

> 💡 TIP: SMOTE 不是"copy+noise"，而是"邻居间线段上的插值(Interpolation)"！方法论描述微妙出错是陷阱。

---

### Q4. A randomly guessing model has an Area Under the ROC Curve (AUC) of 0.5.

**TRUE** ✅

**解析**：在 ROC 曲线(Receiver Operating Characteristic Curve)中，随机猜测(Random Guessing)模型沿对角线(Diagonal)分布，其下方面积(AUC, Area Under the Curve) = 0.5。完美模型 AUC = 1.0，完全反向预测则 AUC = 0.0。

> 💡 TIP: AUC：Random = 0.5, Perfect = 1.0。ROC 曲线的 x轴是 FPR，y轴是 TPR。

---

### Q5. In Bagging, each bootstrap sample is created by sampling from the original training set without replacement.

**FALSE** ❌

**解析**：Bagging (Bootstrap AGGregatING)中的自助样本(Bootstrap Sample)是从原始数据进行**有放回抽样(Sampling WITH Replacement)**生成的。不是"without"而是"with" replacement。正因为有放回抽样，同一个实例可能被多次抽中，每个样本中大约包含63.2%的原始数据。

> 💡 TIP: "without" ↔ "with" 换词陷阱！Bagging = with replacement（有放回抽样）。

---

### Q6. In AdaBoost, correctly classified instances have their weights increased in the next round so that the model focuses on easy samples.

**FALSE** ❌

**解析**：AdaBoost 中是**错误分类(Misclassified)**的实例权重增加，**正确分类(Correctly Classified)**的实例权重减少。这使得下一轮的分类器专注于困难样本(Hard Examples)。题目正好说反了，是设置的陷阱。

> 💡 TIP: 权重方向相反！Boosting = 错误的权重 UP，正确的 DOWN。

---

### Q7. Random Forest combines Bagging with random feature selection at each split point to create diverse decision trees.

**TRUE** ✅

**解析**：随机森林(Random Forest)：(1) 通过自助采样(Bagging)为每棵树使用不同的训练数据，(2) 在每个内部节点(Internal Node)随机选择 p 个特征(Feature)来确定分裂标准。这两种随机性(Randomness)确保了树之间的多样性(Diversity)。

> 💡 TIP: Random Forest = Bagging + Random Feature Subset。两种随机性是关键。

---

### Q8. The confidence of an association rule {X} → {Y} is calculated as the support of {X ∪ Y} divided by the total number of transactions.

**FALSE** ❌

**解析**：题目描述的公式是 Support（支持度）的定义。Confidence（置信度）的正确公式是：
Confidence({X}→{Y}) = Support({X ∪ Y}) / Support({X})
即 X 和 Y 共同出现的比例除以 X 出现的比例。不是除以总交易数。

> 💡 TIP: Support = σ(X∪Y) / |T|（除以总数）。Confidence = σ(X∪Y) / σ(X)（除以X）。分母不同！

---

### Q9. According to the Apriori principle, if an itemset is infrequent, then all of its supersets must also be infrequent.

**TRUE** ✅

**解析**：Apriori 原则(Apriori Principle)：如果某个项集是非频繁的(Infrequent)，那么包含它的所有超集(Superset)也一定是非频繁的。这是因为支持度(Support)的反单调属性(Anti-monotone Property)——项集变大时支持度只会相同或减少。利用这个原则可以大幅减少候选项集数量，节省计算量。

> 💡 TIP: Apriori = "如果子集非频繁，那么超集也非频繁"。这是剪枝(Pruning)的核心依据。

---

### Q10. In association rule mining, rules generated from the same frequent itemset always have identical support and identical confidence.

**FALSE** ❌

**解析**：从同一频繁项集(Frequent Itemset)生成的规则，Support（支持度）确实相同（因为是同一项集的出现频率）。但是 Confidence（置信度）可能不同。例如：{Milk,Beer}→{Diaper} 和 {Diaper}→{Milk,Beer} 的 Support 相同，但分母不同所以 Confidence 不同。

> 💡 TIP: "identical support"部分正确，但"identical confidence"错误。部分正确的陷阱！

### Q11. In a confusion matrix, False Positive (FP) refers to:

a) The model correctly predicted a positive instance.
b) The model incorrectly predicted a negative instance as positive.
c) The model incorrectly predicted a positive instance as negative.
d) The model correctly predicted a negative instance.

**✅ 答案: b)** 模型错误地将负类实例预测为正类。

**解析**：False Positive (FP, 假阳性, 误报)：实际是 Negative（负类）但模型预测为 Positive（正类）。

- TP (True Positive)：实际正类 → 预测正类 ✅
- FP (False Positive)：实际负类 → 预测正类 ❌ (第一类错误 Type I Error)
- FN (False Negative)：实际正类 → 预测负类 ❌ (第二类错误 Type II Error)
- TN (True Negative)：实际负类 → 预测负类 ✅

### Q12. The F1-measure is defined as:

a) (Precision + Recall) / 2
b) 2 × Precision × Recall / (Precision + Recall)
c) Precision × Recall
d) (TP + TN) / (TP + FP + FN + TN)

**✅ 答案: b)** 2 × Precision × Recall / (Precision + Recall)

**解析**：F1-measure (F1 分数)是 Precision（精确率）和 Recall（召回率）的调和平均(Harmonic Mean)。
F1 = 2pr / (p + r)
(a)是算术平均，(d)是 Accuracy 的公式。F1 是在不平衡数据中替代 accuracy 使用的核心指标。

### Q13. In the ROC curve, the x-axis and y-axis represent:

a) x = Precision, y = Recall
b) x = FPR (False Positive Rate), y = TPR (True Positive Rate)
c) x = Recall, y = Precision
d) x = TPR, y = FPR

**✅ 答案: b)** x = FPR, y = TPR

**解析**：ROC 曲线的轴：x轴 = FPR = FP / (FP + TN)，y轴 = TPR = TP / (TP + FN) = Recall。
好的模型 FPR 低而 TPR 高，因此曲线靠近左上角。

### Q15. In the Local Outlier Factor (LOF) method, if the relative density of a point x is much greater than 1, it indicates:

a) x is a normal point with high density.
b) x is surrounded by very dense neighbors and is therefore normal.
c) x is a strong outlier because its density is much lower than its neighbors.
d) x is the center of a dense cluster.

**✅ 答案: c)** x 是一个强异常值，因为它的密度远低于其邻居。

**解析**：LOF (Local Outlier Factor, 局部异常因子)：relative_density(x,k) = (邻居的平均密度) / (x的密度)。
该值 ≫1 意味着 x 周围的密度远低于邻居，因此是强异常值(Outlier)。
值 ≈1 则正常，<1 则密度比邻居还高的正常点。

### Q16. One-Class SVM (OCSVM) is designed to:

a) Classify data precisely into two balanced classes.
b) Learn a boundary around normal data points and identify points outside the boundary as outliers.
c) Perform multi-class classification using multiple hyperplanes.
d) Cluster data based on density.

**✅ 答案: b)** 学习正常数据点周围的边界，将边界外的点识别为异常值。

**解析**：One-Class SVM (OCSVM) 仅用正常数据学习，建立正常区域的边界(Boundary)。落在边界外的数据被判定为异常值(Outlier)。
核心：f(x) = w·φ(x) - ρ → f(x) ≥ 0 为正常(Normal)，f(x) < 0 为异常值(Outlier)。

### Q18. In Bagging, when n is sufficiently large, the probability that a specific training instance is included in a single bootstrap sample is approximately:

a) 0.5
b) 0.368
c) 0.632
d) 1.0

**✅ 答案: c)** 0.632

**解析**：自助样本中特定实例被包含的概率 = 1 − (1 − 1/n)^n。
当 n 足够大时 (1−1/n)^n → 1/e ≈ 0.368，因此被包含的概率 = 1 − 0.368 = **0.632**（约63.2%）。

c) Bagging only works with decision trees while Boosting works with any classifier.

**✅ 答案: b)** Bagging 并行独立训练，Boosting 顺序训练并着重错误分类实例。

### Q20. In AdaBoost, the importance (alpha) of a base classifier is calculated as:

a) α = ln(1/ε)
b) α = ½ × ln((1 − ε) / ε)
c) α = ε / (1 − ε)
d) α = 1 − ε

**✅ 答案: b)** α = ½ × ln((1 − ε) / ε)

**解析**：AdaBoost 中分类器的重要度(Importance) α = ½ × ln((1 − ε) / ε)。

**✅ 答案: b)** 权重回退至 1/n 并重复重采样过程。

### Q25. Given the rule {Milk, Diaper} → {Beer}, where σ({Milk, Diaper, Beer}) = 2, σ({Milk, Diaper}) = 3, |T| = 5, the confidence of this rule is:

### Q31. Confusion Matrix Calculations (6+6+6 = 18 marks)

Given the following confusion matrix for a medical test:

|  | Predicted YES | Predicted NO |
|--|--------------|-------------|
| Actual YES | 40 (TP) | 10 (FN) |
| Actual NO | 20 (FP) | 930 (TN) |

**(a) Calculate Precision, Recall, and F1-measure. (6 marks)**

| 指标 | 公式 | 计算 | 结果 |
|------|------|------|------|
| Precision | TP / (TP + FP) | 40 / (40+20) = 40/60 | **0.667** |
| Recall (TPR) | TP / (TP + FN) | 40 / (40+10) = 40/50 | **0.8** |
| F1-measure | 2pr / (p+r) | 2×0.667×0.8 / (0.667+0.8) | **≈ 0.727** |

**(b) Calculate Accuracy. Is it a reliable metric here? Explain. (6 marks)**

Accuracy = (TP + TN) / (TP + FP + FN + TN) = (40 + 930) / 1000 = 970 / 1000 = **0.97 (97%)**

但是该指标**不可靠(Not Reliable)**。数据是不平衡的（YES=50, NO=950），多数类(NO)是压倒性的。即使将所有预测为 NO，accuracy 也能达到95%，但正类(YES)一个都没有抓到。
Precision(0.667) 和 F1(0.727) 是比 accuracy(0.97) 更现实的性能指标。

**(c) Calculate FPR and explain its meaning in this context. (6 marks)**

FPR (False Positive Rate) = FP / (FP + TN) = 20 / (20 + 930) = 20/950 ≈ **0.021 (2.1%)**

### Q34. Outlier Detection Concepts + Calculation (6+6+6 = 18 marks)

**(a) List and briefly describe three different outlier detection methods. (6 marks)**

| 方法 | 英文名 | 说明 |
|------|--------|------|
| 统计方法 | Statistical | 建立数据的概率分布模型，将概率非常低的数据判定为异常值（如 Grubbs' Test） |
| 基于邻近度 | Proximity-based | 将与其他点距离很远的点判定为异常值。使用到第 k 个最近邻的距离作为异常值评分 |
| 基于密度 | Density-based (LOF) | 将周围密度明显低于邻居密度的点判定为异常值。利用相对密度(Relative Density) |

**(b) In OCSVM, the decision function is f(x) = w·φ(x) − ρ. Explain what happens when f(x) ≥ 0 and f(x) < 0. What does the parameter ν control? (6 marks)**

- **f(x) ≥ 0**：数据点 x 被分类为**正常(Normal)**。位于学习到的边界内部。
- **f(x) < 0**：数据点 x 被分类为**异常值(Outlier/Anomaly)**。位于边界外部。

**ν (nu) 参数**：指定全部数据中预期被分类为异常值的比例上限(Upper Bound on Fraction of Outliers)。ν = 0.05 表示设置边界使约5%的数据落在边界外。

**(c) Explain the concept of reconstruction-based outlier detection. Give an example of a dimensionality reduction method used in this approach. (6 marks)**

基于重建的异常值检测(Reconstruction-Based Anomaly Detection)：
假设正常数据存在可以用低维表示的模式。
1. 将原始数据 x 压缩(Reduce)到低维空间。
2. 将低维表示重建(Reconstruct)回原始空间 → x'。
3. 计算重建误差(Reconstruction Error) = ||x − x'||。
4. 重建误差大的数据点被判定为异常值。

降维方法示例：**PCA (Principal Component Analysis)** 或 **Auto-encoder**。

### 4-1. 补充 True / False (Q35 ~ Q49)

---

**Q35. Ensemble methods such as Bagging and Boosting have good explainability because we can explain the majority voting process to the end user.**

**FALSE** ❌

**解析**：这是教授在课堂上最强调的要点！集成方法无法回答"为什么做出这样的决定？"。多数投票(Majority Voting)过程本身确实可以解释，但无法解释每个单独的分类器**为什么(Why)**做出那样的预测。用户想要的不是"10个医生投了票"，而是"**为什么**认为是那个疾病"的简短有用的解释。

> 💡 TIP: 教授原话："The user is looking for exact explanation why the first classifier made that decision... not the explanation from 10 different decisions."

---

**Q36. In Boosting (AdaBoost), all training samples are treated equally throughout the entire training process.**

**FALSE** ❌

**解析**：Bagging 中确实同等对待所有样本（equal weight）。但在 Boosting(AdaBoost) 中每一轮都会更新权重——增加错误分类样本的权重，减少正确分类样本的权重。教授使用了"考试复习"的比喻：如果 Q-Learning 是弱项，下次复习时就要更专注于 Q-Learning。

> 💡 TIP: 教授比喻："学习时更专注于薄弱环节 = Boosting 的核心原理"

---

**Q37. In Bagging, every training instance is guaranteed to be included in every bootstrap sample.**

**FALSE** ❌

**解析**：Bagging 使用有放回抽样(WITH Replacement)，因此特定实例有可能在某个自助样本中被遗漏。实际上当 n 足够大时，每个自助样本只包含约63.2%的原始数据。

> 💡 TIP: "guaranteed"和"every" = 绝对表达。Bagging 中特定样本可能被遗漏！

---

**Q38. In AdaBoost, if an intermediate round produces an error rate greater than 50%, the algorithm terminates immediately.**

**FALSE** ❌

**解析**：教授明确说明：错误率 > 50% 时算法**不是终止**，而是将权重**重置为 1/n** 并重复重采样。错误率超过50% = 比随机猜测(Random Guessing)还差 → 忽略该分类器重新开始。

> 💡 TIP: "terminates" = 陷阱！是重置并继续，不是终止。

---

**Q39. In Random Forest, the base classifiers (decision trees) are pruned to reduce model complexity.**

**FALSE** ❌

**解析**：教授明确提到：随机森林的基分类器是**未剪枝的(Unpruned)**决策树。"base classifier are unpruned... we don't do any kind of post pruning." 不剪枝的原因：集成可以自然地抵消各棵树的高方差(Variance)。

> 💡 TIP: Random Forest = Unpruned Trees！教授直接说了 "no post pruning"。

---

**Q40. Association rules represent causal relationships between items (e.g., buying beer causes buying diapers).**

**FALSE** ❌

**解析**：教授多次反复强调：关联规则不是因果关系(Causality)，而是共现/相关性(Co-occurrence/Correlation)。"It doesn't mean that if someone wants to buy beer, he or she must buy diapers before. It just shows the correlation, kind of correlation. It's not causality." 只是一起购买的模式，一个不会"导致"另一个。

> 💡 TIP: 教授最多次强调！Association Rule = Correlation ≠ Causation。考试常客！

---

**Q41. In association rule mining, the purchase quantity of each item and the customer identity are important factors in the analysis.**

**FALSE** ❌

**解析**：教授明确提到：关联规则挖掘中不考虑数量(Quantity)和顾客信息(Customer Identity)。"What are the things here different? We don't have price... the quantity... nothing about the customers." 交易中商品是否存在(Yes/No)才是重要的。

> 💡 TIP: 教授直接提到的要点！数量、价格、顾客信息 = 在 Association Rule 中被忽略。

---

**Q42. The brute-force approach is feasible for finding frequent itemsets in large datasets with thousands of items.**

**FALSE** ❌

**解析**：教授强调：当有 D 个商品时，可能的项集数 = 2^D − 1（排除空集）。仅6个商品就有602条规则，1000个商品则有数百万条以上。"This brute force search doesn't make sense." —— 这就是需要 Apriori 算法的原因。

> 💡 TIP: 教授："6个商品就602 rules。一千个呢？Brute force 是 impossible！"

---

**Q43. In AdaBoost, the final prediction uses simple majority voting where all classifiers have equal influence.**

**FALSE** ❌

**解析**：AdaBoost 使用**加权投票(Weighted Majority Voting)**。每个分类器的重要度 α(alpha) 决定了投票权重。教授比喻："向10个医生征求意见，但给最有名的医生的意见更大的比重"。α = ½ × ln((1−ε)/ε) 计算。错误率低的分类器 α 越大。

> 💡 TIP: Simple majority vote = Bagging。Weighted majority vote = Boosting(AdaBoost)。不要混淆！

---

**Q44. In association rule mining, the two-step approach first generates rules and then finds frequent itemsets.**

**FALSE** ❌

**解析**：顺序说反了！正确的两步法(Two-step approach)：
- Step 1：频繁项集生成(Frequent Itemset Generation) —— 基于 Support
- Step 2：规则生成(Rule Generation) —— 基于 Confidence

教授："After finding the frequent itemsets... we should generate the rules."

> 💡 TIP: 顺序调换陷阱！Step 1 = 频繁项集 (Support) → Step 2 = 规则 (Confidence)

**Q45. Ensemble methods are most effective when combined with stable classifiers such as k-Nearest Neighbors (kNN).**

**FALSE** ❌

**解析**：教授强调：集成方法与**不稳定(Unstable)**分类器结合时才有效。不稳定 = 学习数据微小变化就导致模型大幅改变（如未剪枝决策树、ANN）。稳定(Stable)分类器（如 kNN）即使数据变化也不会大幅改变，因此集成效果很差。

> 💡 TIP: 教授核心："Unstable classifiers sensitive to minor perturbations" = 集成的最佳条件。

---

**Q46. Bagging primarily reduces the bias of a model, while Boosting primarily reduces variance.**

**FALSE** ❌

**解析**：完全相反！
- **Bagging**：主要降低**方差(Variance)**。用不同训练数据独立学习 → 减少预测的波动。
- **Boosting**：主要降低**偏差(Bias)**。专注前一轮的错误顺序学习 → 模型越来越精确。

> 💡 TIP: Bagging = Variance↓，Boosting = Bias↓。教授考试中经常调换出题！

---

**Q47. In the Apriori algorithm, candidate k-itemsets are generated by merging two frequent (k-1)-itemsets whose first (k-2) items are identical.**

**TRUE** ✅

**解析**：教授直接讲解的候选生成(Candidate Generation)方法：合并(Merge)两个频繁 (k-1)-项集，条件是前 (k-2) 个项相同。例如：{A,B,C} 和 {A,B,D} 的前2个(A,B)相同，合并为 {A,B,C,D}。

> 💡 TIP: 候选生成规则：前 (k-2) 个项相同 → 合并。教授用例题讲解过。

---

**Q48. In a confusion matrix, high accuracy necessarily implies the model has high recall for the minority class.**

**FALSE** ❌

**解析**：在不平衡数据中，即使 accuracy 很高，少数类的 recall 也可以为0%。例如：正样本10个、负样本990个的数据中，将所有预测为负类，Accuracy = 99% 但 Recall(正类) = 0/10 = 0%。这就是不平衡数据中 accuracy 具有误导性的原因。

> 💡 TIP: "always" + "high accuracy = high recall" = 双重陷阱。不平衡数据的核心概念！

---

**Q49. The Apriori algorithm uses the anti-monotone property of support to prune candidate itemsets before computing their support.**

**TRUE** ✅

**解析**：Apriori 算法的核心策略：在计算候选项集的 support 之前，利用反单调属性(Anti-monotone Property)进行剪枝(Pruning)。如果候选 k-项集的 (k-1) 子集中有非频繁的 → 不用计算 support 直接移除。这大幅减少了计算量。

> 💡 TIP: 教授："Without finding the support, without calculating the support, that's why we use Apriori."

### Q50. Explainability of Ensemble Methods (12 marks)

A student argues: "Ensemble methods like Bagging are explainable because we can tell the user that 10 different classifiers voted and we took the majority." Is this statement correct? Explain why.

### Q51. AdaBoost Weight Update Process (12 marks)

Suppose the training set has 10 samples. In round 1, all initial weights are equal (1/10 = 0.1). Classifier C1 correctly classifies samples 1-7 but misclassifies samples 8, 9, 10. The error rate ε₁ = 0.3.

**(a) Calculate the classifier importance α₁. (4 marks)**

α₁ = ½ × ln((1 − ε₁) / ε₁) = ½ × ln(0.7 / 0.3) = ½ × ln(2.333)
ln(2.333) ≈ 0.847
**α₁ ≈ 0.424**

**(b) Describe how the weights change for correctly classified and misclassified samples. (4 marks)**

- **正确分类的样本 (1-7)**：权重**减少**。
  w_new = w_old × e^(−α₁) / Z（Z = 归一化常数）
  e^(−0.424) ≈ 0.655 → 减小到原权重的约65.5%

- **错误分类的样本 (8-10)**：权重**增加**。
  w_new = w_old × e^(+α₁) / Z
  e^(+0.424) ≈ 1.528 → 增大到原权重的约152.8%

关键：权重之和始终归一化(Normalization)为1。

**(c) In round 2, is sample 8 more or less likely to be selected? Why? (4 marks)**

样本8在第1轮中被错误分类，因此权重增加了。所以在第2轮中**被选中的概率更高**。

教授的"轮盘赌(Roulette Wheel)"比喻：权重越高的样本在轮盘上占的面积越大，被选中的概率就越高。这使得下一个分类器更加关注之前分错的"困难样本"。

### Q52. Hyperparameter Tuning (12 marks)

## PART 5: 📌 教授强调重点最终整理 — 考试前必须确认！

> 以下是教授在课堂录音和最终总结中反复强调的核心要点。考试前快速复习这部分。

### 📗 Week 9: Imbalanced Class Problem（类不平衡问题）

| 概念 | 核心整理 |
|------|---------| 
| Accuracy 的陷阱 | 不平衡数据中 accuracy 具有误导性。99% accuracy 也可能一个少数类都没抓到 → 使用 F1, Precision, Recall |
| Oversampling vs SMOTE | Oversampling = 单纯复制(Duplicate)。SMOTE = 通过 k-NN 间线段上的插值(Interpolation)合成生成。方法论差异必须精确区分！ |
| ROC/AUC 核心数值 | AUC: Random Guessing = 0.5, Perfect = 1.0。ROC 曲线: x轴 = FPR, y轴 = TPR |
| LOF 解读 | relative_density ≫ 1 → Outlier（密度低于邻居）。≈1 → Normal |
| OCSVM 核心 | f(x) ≥ 0 → Normal, f(x) < 0 → Outlier。ν = 异常值比例的上限 |
| 基于重建的检测 | 原始 → 压缩 → 重建 → 重建误差大的 = Outlier。方法: PCA, Auto-encoder |

### 📗 Week 10: Classifier Fusion / Ensemble（分类器融合/集成学习）

| 概念 | 核心整理 |
|------|---------| 
| Bagging vs Boosting | Bagging: 并行、有放回抽样、等权投票、Variance↓ / Boosting: 顺序、权重变化、加权投票、Bias↓ |
| Bagging 有放回抽样 | WITH replacement！约63.2%被包含。注意"without"换词陷阱 |
| AdaBoost 权重方向 | 错误样本 → 权重 UP (e^(+α))。正确样本 → 权重 DOWN (e^(-α)) |
| AdaBoost ε > 0.5 | 错误率 > 50% → 不是终止！权重重置为 1/n 并重新开始 |
| AdaBoost α 公式 | α = ½ × ln((1−ε)/ε)。ε 越小 α 越大 → 投票权重越大 |
| Random Forest 特征 | Bagging + Random Feature Subset。使用 Unpruned trees。No post-pruning！ |
| 不稳定分类器 | 集成与不稳定分类器(Decision Tree, ANN)有效。kNN 等稳定分类器效果差 |
| 可解释性 ★★★ | 集成最大弱点！Majority Vote 过程的解释 ≠ Explainability。用户想要"为什么？" |

### 📗 Week 11: Association Rule Mining（关联规则挖掘）

| 概念 | 核心整理 |
|------|---------| 
| Correlation ≠ Causation | ★★★ 教授最多次强调！关联规则只是共现(Co-occurrence)，不是因果关系(Causality) |
| 被忽略的信息 | 数量(Quantity)、价格(Price)、顾客信息(Customer ID) → 在 Association Rule 中被忽略。只看是否存在 |
| Support vs Confidence | Support = σ(X∪Y) / \|T\|（除以总数）/ Confidence = σ(X∪Y) / σ(X)（除以X）。分母不同！ |
| 同 Itemset 的规则 | Support 相同（同个 Union）。Confidence 可能不同（分母不同） |
| Apriori 原则 | Frequent 的所有 Subset 也 Frequent。逆否：Infrequent 的所有 Superset 也 Infrequent |
| Anti-monotone Property | 项集变大 → Support 相同或减少。∀X⊆Y: s(X) ≥ s(Y)。Pruning 的数学依据 |
| Two-step Approach | Step 1: 频繁项集生成 (Support)。Step 2: 规则生成 (Confidence)。顺序重要！ |
| Candidate Generation | 合并两个频繁 (k-1)-项集: 前 (k-2) 个项相同。合并后执行 Pruning |
| Pruning 方法 | 候选 k-项集的 (k-1) 子集如果非频繁 → 不计算 Support 直接移除！ |
| Brute Force 不可行 | D items → 2^D-1 itemsets, 3^D-2^(D+1)+1 rules。D=6 就有 602 rules |

### 📗 Hyperparameter Tuning（超参数调优 — 教授最后一节课）

| 概念 | 核心整理 |
|------|---------| 
| Parameter vs Hyperparameter | Parameter = 学习中自动决定 (如 centroid) / Hyperparameter = 学习前设定 (如 K, 树数, learning rate) |
| 调优方法 4种 | Manual Search, Grid Search, Random Search, Best Practice (参考论文) |
| Batch vs Iteration vs Epoch | Batch = 数据子集, Iteration = 1次更新, Epoch = 全部数据1次遍历 |
| Loss Functions | MAE (Mean Absolute Error), MSE (Mean Squared Error), Cross-Entropy |

## ⚠️ 考试陷阱模式最终检查清单

| # | 陷阱模式 | 示例 | 正确答案 |
|---|---------|------|---------| 
| 1 | **绝对表达** "always", "never", "guaranteed" | "Accuracy is always reliable" | 大多数情况 FALSE |
| 2 | **关键词换词** "with" ↔ "without" | "Bagging uses without replacement" | WITH replacement！ |
| 3 | **方向相反** 增加↔减少 | "AdaBoost: correct → weight UP" | Misclassified → UP！ |
| 4 | **定义对调** Support ↔ Confidence | "Confidence = σ(X∪Y) / \|T\|" | 那是 Support！Conf = σ(X∪Y)/σ(X) |
| 5 | **部分正确** A正确但B错误 | "Same itemset → same support AND same confidence" | 只有 Support 相同！Confidence 不同 |
| 6 | **顺序对调** | "Two-step: Rules first, then Itemsets" | 先 Itemsets！ |
| 7 | **Bias ↔ Variance 混淆** | "Bagging reduces Bias" | Bagging = Variance↓ / Boosting = Bias↓ |
| 8 | **Causation ↔ Correlation** | "Association rules = causal" | 只是 Correlation！ |
