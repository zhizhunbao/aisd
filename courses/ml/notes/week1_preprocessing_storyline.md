# Week 1 故事线：从"数据混沌"到"降维优雅"

> **Source:** `01_CST8506_Preprocessing4.pdf`
> **核心主题：** 真实世界的数据又脏又高维，如何在不丢失关键信息的前提下，把它送进机器学习模型？
> **故事线：** 四关打怪——清理脏数据 → 统一量纲 → PCA 压缩维度 → LDA 感知类别

---

## 🎬 序幕：我们要解决什么问题？

### 问题定义：模型不怕"难题"，怕"脏题"

想象你收集了一份医院的病人数据，想用 kNN 判断"这个人会不会得糖尿病"：

| 姓名  | 年龄 (岁) | 年收入 ($) | 血糖 (mg/dL) | BMI  | 吸烟？ |
| ----- | :-------: | :--------: | :----------: | :--: | :----: |
| Alice |    32     |   65,000   |     105      | 24.3 |  Yes   |
| Bob   |    NaN    |  120,000   |     NaN      | 31.1 |   No   |
| Carol |    45     |   45,000   |     210      | 28.7 | Maybe? |

你兴冲冲地把数据丢进 kNN，结果发现：

1. **Bob 的年龄和血糖是缺失的** → 模型直接报错
2. **年收入是 65000，年龄是 32** → kNN 计算距离时，年收入把年龄"淹没"了——65000 和 120000 的差距远大于 32 和 45 的差距
3. **特征有 200 列** → 维度灾难——所有病人看起来"等距"，kNN 彻底迷路

> 💡 **核心洞察：** 机器学习的名言——_"Garbage in, garbage out"_（垃圾进，垃圾出）。一个好模型配上差数据，不如一个差模型配上好数据。

### CRISP-DM：数据科学家的工作流程

在动手之前，工业界遵循 **CRISP-DM (CRoss-Industry Standard Process for Data Mining)** 标准流程：

```
┌──────────────────────────────────────────────────────────┐
│  Business          Data             Data                 │
│  Understanding  → Understanding  → Preparation          │
│       ↓                                 ↓               │
│  Deployment  ←  Evaluation  ←     Modeling              │
│       ↑_________________________________↑               │
│              (可能需要反复迭代)                           │
└──────────────────────────────────────────────────────────┘
```

> 💡 **关键教训：** 大多数新手犯的错误是直接跳到 "Modeling"（建模）。但工业界的数据科学项目中，**70-80% 的时间花在 Data Preparation（数据准备）** 上。预处理不是"杂活"，而是决定模型成败的关键。

## 📚 第一章：清洗与转换——给数据"洗澡换衣"

### 1.1 数据清洗 (Data Cleaning)

真实数据几乎不可能是干净的。常见问题和对策：

| 问题类型       | 具体表现             | 解决方法                            |
| -------------- | -------------------- | ----------------------------------- |
| **缺失值**     | NaN、空白、"N/A"     | 删除行/列、均值/中位数填充、KNN填充 |
| **重复数据**   | 同一条记录出现多次   | 去重 (drop_duplicates)              |
| **噪声**       | 录入错误、传感器故障 | 分箱平滑、聚类检测、异常值过滤      |
| **格式不一致** | "Yes"/"yes"/"Y"/"1"  | 统一编码                            |

> 🔑 **故事转折点：** 数据清洗后，数据是"干净"的了，但还不够！特征之间的**量纲差异**会让距离型算法彻底崩溃 → 我们需要"统一度量衡"！

## 🧮 第二章：量纲统一——给特征"公平竞技场"（⚠️ 有陷阱）

### 2.1 问题：量纲不同 = 不公平竞赛

回到糖尿病案例，计算 Alice 和 Bob 的 kNN 距离：

```
特征:            年收入($)     年龄(岁)
Alice:           65,000        32
Bob:             120,000       45

欧氏距离 = √[(120000-65000)² + (45-32)²]
        = √[55000² + 13²]
        = √[3,025,000,000 + 169]
        ≈ 55,000.0
```

年龄的差异 (13²=169) 被年收入的差异 (55000²=30亿) **完全吞没**！距离 ≈ 55000，几乎全由年收入决定。

> 💡 **类比：** 这就像跑步比赛，一个人的距离用"米"算(=32)，另一个用"毫米"算(=65,000,000)。毫米选手"永远领先"——但这只是单位造成的假象！

### 2.2 方案一：归一化 (Normalization / Min-Max Scaling)

**① 一句话定义：** 把所有特征压缩到 [0, 1] 范围内。

**② 公式：**

```
x' = (x - x_min) / (x_max - x_min)
```

**③ 具体例子：**

```
年收入 (原始):  [45000, 65000, 120000]
x_min = 45000, x_max = 120000

归一化:
  45000  → (45000-45000)/(120000-45000)  = 0.00
  65000  → (65000-45000)/(120000-45000)  = 0.27
  120000 → (120000-45000)/(120000-45000) = 1.00
```

**④ 优缺点：**

- ✅ 所有值严格落在 [0, 1]
- ❌ **对异常值极度敏感**——如果有人年收入 10,000,000，那 99% 的正常人被挤在 [0, 0.01] 范围里

### 2.3 方案二：标准化 (Standardization / Z-score)

**① 一句话定义：** 让每个特征的均值=0、标准差=1，即"距离平均有几个标准差"。

**② 公式：**

```
z = (x - μ) / σ
```

**③ 具体例子：**

```
年收入 (原始):  [45000, 65000, 120000]
μ = 76667, σ = 31180

标准化:
  45000  → (45000-76667)/31180  = -1.02
  65000  → (65000-76667)/31180  = -0.37
  120000 → (120000-76667)/31180 = +1.39
```

**④ 优缺点：**

- ✅ 对异常值更鲁棒（因为只是变了"中心和散布"）
- ✅ 输出值无界限，保留了数据分布信息
- ❌ 不保证严格落在某个范围

### 2.4 对比总结

| 维度       |            归一化 (Min-Max)            |        标准化 (Z-score)         |
| ---------- | :------------------------------------: | :-----------------------------: |
| 输出范围   |            [0, 1] 严格有界             |              无界               |
| 异常值影响 |              ❌ 极其敏感               |           ✅ 相对鲁棒           |
| 公式       |        (x - min) / (max - min)         |           (x - μ) / σ           |
| 适用场景   | 需要固定范围（如像素值、神经网络输入） | 距离型算法（kNN、K-Means、PCA） |

### 2.5 其他转换方法

| 方法         | 作用           | 要点                       |
| ------------ | -------------- | -------------------------- |
| **等宽分箱** | 按值域范围划分 | 每箱宽度相同，受异常值影响 |
| **等频分箱** | 按样本数量划分 | 每箱样本数相同，更均匀     |
| **随机采样** | 随机抽取子集   | 可能丢失少数类             |
| **分层采样** | 保持各类比例   | 分类问题的首选             |

### 2.6 ⚠️ 量纲统一的致命陷阱——数据泄露

> ⚠️ **数据泄露 (Data Leakage)：** 在缩放数据时，必须**先 split、再 fit！**

```
❌ 错误做法（数据泄露）：
   1. 在全部数据上 fit_transform(StandardScaler)
   2. 再 split 训练/测试

✅ 正确做法：
   1. 先 split 训练/测试
   2. 在训练集上 fit(StandardScaler)  ← 只看训练集！
   3. 用训练集的参数 transform 训练集和测试集
```

**为什么？** 如果在全部数据上计算均值/标准差，测试集的信息就"泄露"到训练过程中了。模型在考试前偷看了答案。

> 🔑 **故事转折点：** 量纲统一后，kNN 终于能公平计算距离了。但如果特征有 200 个——即使每个特征都很公平，**维度灾难**会让所有点看起来"等距"，模型再次崩溃 → 我们需要"压缩维度"！

## 🧠 第三章：方案一——PCA（✅ 压缩成功，但对类别"装聋作哑"）

### 3.1 维度灾难：为什么维度高就不行？

想象在不同维度空间里放 10 个点：

```
1D (线):     ●●●●●●●●●●         → 点很密集，kNN 有效
2D (平面):   ●   ●   ●           → 点开始分散
             ●   ●   ●
             ●   ●   ●  ●
10D (超立方): ● ... ? ... ●       → 10个点散布在巨大空间中
             每对点之间距离几乎相等！
```

**数学解释：** 空间体积 $V = L^d$，其中 $d$ 是维度。维度每加 1，体积就乘以 $L$。

```
维度 d=1:  V = 10
维度 d=2:  V = 100
维度 d=10: V = 10,000,000,000  (100亿！)
```

10 个点在 100 亿的空间里——每个点都是孤星。

> 💡 **空屋类比：** 把 10 个人放在一间 10 米长的走廊里，大家很挤。把 10 个人放在一个 10×10 的房间里，有点空但还能交流。把 10 个人放进一个 10 维超立方体——每个人都找不到别人。

### 3.2 降维：两种策略

| 策略         | 动作                   | 结果                             | 例子                      |
| ------------ | ---------------------- | -------------------------------- | ------------------------- |
| **特征选择** | 丢弃某些列，保留其他列 | 保留的特征保持原始含义           | 保留"年龄"，丢弃"身高"    |
| **特征提取** | 将所有列线性组合成新列 | 新特征是数学混合物，难以直观解释 | PC1 = 0.5×年龄 - 0.2×身高 |

> 🔑 PCA 属于**特征提取**，它不是"挑选"特征，而是"融合"特征。

### 3.3 PCA 的核心思想

**① 一句话定义：** PCA 是一种**无监督**的降维技术，它找到数据方差最大的方向，把数据投影上去。

**② 关键公式——投影后的方差最大：**

PCA 寻找一个方向向量 $w$，使得数据在这个方向上的投影方差最大：

```
PC1 = argmax Var(X·w)    subject to ||w|| = 1
```

**③ 直觉类比：**

> 💡 **拍飞碟类比：** 飞碟是个扁平的椭圆形物体。从正上方拍照（PC1），你看到最大的圆形投影——这个角度"信息量"最大。从侧面拍照（PC2），你只看到一条细线——信息量最少。PCA 就是"寻找最佳拍摄角度"。

### 3.4 PCA 五步法——Iris 数据集实战

#### Step 1: 标准化

```
原始 Iris 数据:
  sepal_length: 均值 5.84, 范围 [4.3, 7.9]
  sepal_width:  均值 3.05, 范围 [2.0, 4.4]
  petal_length: 均值 3.76, 范围 [1.0, 6.9]
  petal_width:  均值 1.20, 范围 [0.1, 2.5]

→ StandardScaler → 均值=0, 标准差=1
```

> ⚠️ **必须标准化！** 否则数值范围大的特征（如 sepal_length）会主导 PCA 的方向选择，不是因为它"信息量大"，而纯粹因为它"数值大"。

#### Step 2: 计算协方差矩阵

协方差矩阵告诉我们"哪些特征一起变化"：

```
        sepal_L  sepal_W  petal_L  petal_W
sepal_L  [1.01   -0.11    0.87     0.82  ]
sepal_W  [-0.11   1.01   -0.42    -0.36  ]
petal_L  [0.87   -0.42    1.01     0.97  ]
petal_W  [0.82   -0.36    0.97     1.01  ]
```

**解读：** petal_L 和 petal_W 相关性 = 0.97（几乎完全正相关）→ 这两个特征"说的几乎是同一件事"，有压缩空间！

#### Step 3: 计算特征值和特征向量

```
特征值:   [2.94, 0.92, 0.15, 0.02]
方差比例: [0.73, 0.23, 0.04, 0.005]
```

| 主成分 | 特征值 | 解释方差比 | 累计方差比 |
| :----: | :----: | :--------: | :--------: |
|  PC1   |  2.94  |    73%     |    73%     |
|  PC2   |  0.92  |    23%     |  **96%**   |
|  PC3   |  0.15  |     4%     |    100%    |
|  PC4   |  0.02  |    0.5%    |    100%    |

> 💡 **关键发现：** 前 2 个主成分就保留了 **96%** 的信息！也就是说，从 4 维降到 2 维，只丢失了 4% 的信息。

#### Step 4: 选择主成分数量（Scree Plot）

```
  方差
  ▲
  │ ●  (2.94)
  │ │
  │ │
  │ └── ●  (0.92)
  │         └── ●  (0.15)     ← "肘部"在这里！
  │              └── ●  (0.02)
  └────────────────────────→ 主成分编号
    PC1    PC2    PC3  PC4
```

**碎石图 (Scree Plot) 法则：** 找到曲线的"肘部"（急剧下降变平缓的转折点），肘部之前的主成分保留，之后的丢弃。

#### Step 5: 投影数据到新轴

```
原始: 4 维 → 选择 PC1、PC2 → 新数据: 2 维

准确率对比:
  ├── 原始 4 维特征:  95.33%
  ├── PCA 保留 2 维:   94.67%  (仅降 0.66%！)
  └── PCA 保留 3 维:   97.33%  (反而提升！✨)
```

> 💡 **为什么 PCA 3 维准确率反而更高？** 因为丢弃第 4 个维度（只有 0.5% 方差）相当于去噪——删掉的不是信息，而是噪声。

### 3.5 ❌ PCA 的致命缺陷——"类别盲"

PCA 是**无监督**的——它只看方差，**完全无视类别标签**。

来看一个灾难场景：

```
      ↑ 特征2
      │     ★ ★ ★ ★
      │   ★ ★ ★ ★
      │  ● ● ● ●
      │● ● ● ●
      └──────────────→ 特征1

PCA 找到的方向 (最大方差):  ↗  (沿数据的长轴)
投影后:
  ●●★●★●★●★●●★★●  ← 两类完全混在一起！
```

PCA 找到了方差最大的方向，把数据投影上去——但这个方向恰好让两个类重叠了！

**问题根源：** PCA 的目标是"保留最大方差"，而不是"保持类别可分"。有时候方差最大的方向恰恰是类别重叠最严重的方向。

> 🔑 **故事转折点：** PCA 成功地压缩了维度，但它"看不见"类别标签。在分类任务中，我们需要的不仅是"保留总方差"，更需要"最大化类别之间的差异" → LDA 登场！

## 🏰 第四章：方案二——LDA（✅ 类别感知降维！）

### 4.1 LDA 的核心思想

**① 一句话定义：** LDA 是一种**有监督**的降维技术，它找到能将不同类别**最大限度分开**的投影方向。

**② 双重优化目标：**

```
LDA 的目标 = 最大化 (类间距离) / 最小化 (类内分散)
```

> 💡 **考试分班类比：**
>
> - **类间距离最大** = 让"好学生"和"差学生"的平均分差距尽可能大
> - **类内分散最小** = 让每组学生的成绩尽可能集中
> - 如果好学生都在 90-95 分，差学生都在 30-40 分 → 完美分离！
> - 如果好学生在 50-100 分，差学生在 30-80 分 → 大量重叠，分不开！

### 4.2 LDA 五步法

| 步骤 | 内容                                            | 对应 PCA 步骤  |
| :--: | ----------------------------------------------- | :------------: |
|  1   | 计算各类别的 d 维均值向量                       | — (PCA 不需要) |
|  2   | 计算**散布矩阵** (Between-class + Within-class) | 计算协方差矩阵 |
|  3   | 计算特征值和特征向量                            |     同 PCA     |
|  4   | 按特征值降序排列，选前 k 个                     |     同 PCA     |
|  5   | 投影数据到新子空间                              |     同 PCA     |

**关键区别在于 Step 2：**

- PCA 用的是**整体协方差矩阵**（不管类别）
- LDA 用的是两个**散布矩阵**：
  - **S_B (Between-class)**: 不同类均值之间的散布 → 越大越好
  - **S_W (Within-class)**: 同类数据内部的散布 → 越小越好
  - 优化目标：最大化 $S_B / S_W$

### 4.3 LDA 的效果

回到之前 PCA 失败的场景：

```
      ↑ 特征2
      │     ★ ★ ★ ★
      │   ★ ★ ★ ★
      │  ● ● ● ●
      │● ● ● ●
      └──────────────→ 特征1

PCA 方向 (最大方差):  ↗  → 投影后两类混合
LDA 方向 (最大类分离): ↑  → 投影后两类完美分开

LDA 投影后:
  ★★★★★★★★        ← 类 A 在上方
  --------
  ●●●●●●●●        ← 类 B 在下方
```

LDA 选择了与 PCA 不同的方向，因为**它的目标不同**。

### 4.4 ⚠️ LDA 的限制

| 限制           | 说明                                                       |
| -------------- | ---------------------------------------------------------- |
| **维度上限**   | 最多只能降到 **(类别数 - 1)** 维。二分类 → 只能降到 1 维！ |
| **需要标签**   | 无标签数据无法使用 LDA                                     |
| **线性假设**   | 假设类别间的分界是线性的                                   |
| **小样本问题** | 当样本数 < 特征数时，Within-class 矩阵可能奇异             |

> ⚠️ **考试陷阱：** "有 5 个类别的数据集，LDA 最多降到几维？" 答案：**4 维** (= 5 - 1)。

### 转折点总结

| 从 → 到       | 解决了什么核心问题？               |
| ------------- | ---------------------------------- |
| 脏数据 → 清洗 | 消除缺失值、噪声、格式不一致       |
| 清洗 → 缩放   | 消除量纲差异，让距离度量公平       |
| 缩放 → PCA    | 压缩高维数据，缓解维度灾难         |
| PCA → LDA     | 从"保留方差"升级为"保留类别可分性" |

## 🎓 考试重点检查清单

### 概念理解

- [ ] 能解释 CRISP-DM 六个阶段及其循环关系
- [ ] 能区分数据清洗、数据集成、数据转换、数据归约
- [ ] 能用具体例子说明"维度灾难"
- [ ] 能解释 PCA 的"信息 = 方差"核心等式
- [ ] 能解释 LDA "最大化类间、最小化类内"的双重目标
- [ ] 能说出 PCA 与 LDA 的 3 个核心区别

### 公式掌握

- [ ] 归一化: $x' = \frac{x - x_{min}}{x_{max} - x_{min}}$
- [ ] 标准化: $z = \frac{x - \mu}{\sigma}$
- [ ] 协方差: $Cov(X,Y) = \frac{1}{n}\sum(x_i - \bar{x})(y_i - \bar{y})$
- [ ] 解释方差比: $\text{ratio}_k = \frac{\lambda_k}{\sum_i \lambda_i}$
- [ ] LDA 目标: $\max \frac{S_B}{S_W}$（类间散布 / 类内散布）

### 对比题准备

- [ ] 归一化 vs 标准化（范围、异常值敏感度、适用场景）
- [ ] 特征选择 vs 特征提取（保留原始含义 vs 创建新特征）
- [ ] PCA vs LDA（无监督 vs 有监督、方差 vs 类分离度、维度上限）
- [ ] 等宽分箱 vs 等频分箱（按范围 vs 按数量）

### 应用判断

- [ ] 什么时候用归一化？→ 需要固定范围（神经网络输入、像素值）
- [ ] 什么时候用标准化？→ 距离型算法（kNN, K-Means, PCA）
- [ ] 什么时候用 PCA？→ 无标签数据 / 纯粹降维去噪
- [ ] 什么时候用 LDA？→ 有标签 + 分类任务降维
- [ ] Scree Plot 怎么用？→ 找"肘部"确定保留主成分数
- [ ] 为什么 PCA 前必须标准化？→ 否则大数值特征主导方向选择

### 陷阱题准备

- [ ] 数据泄露：必须先 split 再 fit（不能在全部数据上 fit_transform）
- [ ] PCA 不是特征选择，是特征提取（创建新的线性组合）
- [ ] LDA 维度上限 = 类别数 - 1（二分类只能降到 1 维）
- [ ] PCA 是无监督的（不需要标签），LDA 是有监督的（需要标签）

> 📖 **故事总结：** 我们的数据经历了一场"蜕变之旅"——从满身脏污的原始状态（缺失值、噪声），到换上统一校服（标准化），再到学会"瘦身"（PCA 压缩维度），最终在分类任务中找到了最佳展示角度（LDA 感知类别）。每一步都是因为上一步的"不够好"而催生的——这就是数据预处理的因果链。
