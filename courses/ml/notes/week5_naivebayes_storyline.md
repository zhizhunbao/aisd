# Week 5 故事线：从"数数"到"推理"的概率进化

> **Source:** `Week5_NaiveBayes.pdf`
> **核心主题：** 如何在"不确定"的世界里做出最佳分类决定？
> **故事线：** 三代"推理升级"——从直觉数数（频率统计）到概率翻转（Bayes 定理）再到聪明偷懒（朴素贝叶斯）最终到灵活建模（贝叶斯信念网络）

## 🎬 序幕：我们要解决什么问题？

### 问题定义：在不确定中做决策

想象你是税务局的审查员，收到一份纳税申报表：

> **X =（没有退税，已离婚，收入 12 万）**
>
> 这个人逃税了吗？

你手里有一堆历史数据（10 条记录），知道每个纳税人的退税情况、婚姻状况、应税收入，以及他们最终是否逃税。

**直觉方法：** 数一数历史上有多少人逃税，占比多少？

| 逃税？ | 人数 | 比例 |
| ------ | ---- | ---- |
| Yes    | 3    | 30%  |
| No     | 7    | 70%  |

仅凭这个结果：70% 概率不逃税 → **判定不逃税**。

但等一下——我们**完全没有用到**这个人的退税、婚姻、收入信息！直觉告诉我们：一个已离婚、没退税、高收入的人，和一个已婚、有退税、低收入的人，逃税风险应该不同。

### 核心挑战

| 天真方法                                  | 问题                                           |
| ----------------------------------------- | ---------------------------------------------- |
| 只看比例 P(Y)                             | ❌ 完全忽略特征                                |
| 如果看 P(Y\|X)，需要枚举所有可能的 X 组合 | ❌ 组合爆炸：3 个特征各有几种取值 → 几十种组合 |
| 如果数据中没见过某个 X 组合               | ❌ 完全无法预测                                |

> 💡 **关键洞察：** 我们需要一种方法，既能利用每个特征的信息，又不需要枚举所有特征组合。

## 📚 第一章：数学基础——条件概率与贝叶斯定理

在引入解决方案前，我们需要掌握两个核心工具。

### 1.1 条件概率 (Conditional Probability)

**一句话定义：** 在已知某件事发生的前提下，另一件事发生的概率。

**公式：**

```
P(A|B) = P(A ∩ B) / P(B)
```

- P(A|B) = 已知 B 发生时，A 发生的概率
- P(A ∩ B) = A 和 B 同时发生的概率
- P(B) = B 发生的概率

**骰子例子：** 掷两个骰子，A = 两骰子之和为 8，B = 第一个骰子为 5。

- A 的所有情况：{(2,6), (3,5), (4,4), (5,3), (6,2)} → P(A) = 5/36
- B 的所有情况：{(5,1), (5,2), (5,3), (5,4), (5,5), (5,6)} → P(B) = 6/36
- P(A ∩ B) = 1/36（只有 (5,3)）
- P(A|B) = (1/36) / (6/36) = **1/6**

> 💡 **直觉：** 条件概率就是"缩小宇宙"。本来 36 种可能，知道第一个骰子是 5 后，宇宙缩小到 6 种，其中只有 1 种和为 8。

### 1.2 贝叶斯定理 (Bayes Theorem)——概率的"翻转器"

**一句话定义：** 当你知道 P(X|Y)（原因→结果）时，帮你算出 P(Y|X)（结果→原因）。

**公式：**

```
P(Y|X) = P(X|Y) × P(Y) / P(X)
```

每个部分的含义：

| 符号    | 名称                  | 含义                             | 税务例子                                   |
| ------- | --------------------- | -------------------------------- | ------------------------------------------ |
| P(Y\|X) | **后验 (Posterior)**  | 看到特征后，属于某类的概率       | 看到"离婚、无退税、12万"后逃税的概率       |
| P(X\|Y) | **似然 (Likelihood)** | 如果属于某类，出现这些特征的概率 | 逃税者中"离婚、无退税、12万"同时出现的概率 |
| P(Y)    | **先验 (Prior)**      | 不看特征时，属于某类的概率       | 历史上逃税的比例 (3/10)                    |
| P(X)    | **证据 (Evidence)**   | 这些特征出现的概率               | "离婚、无退税、12万"在所有人中出现的概率   |

**为什么需要"翻转"？**

我们想知道的是 P(逃税|特征)——看到特征后的分类结果（后验）。
但数据库里容易统计的是 P(特征|逃税)——逃税者中各特征的分布（似然）。

贝叶斯定理就是把**容易算的 P(X|Y)** 翻转成**想要的 P(Y|X)**！

> 💡 **医院检查类比：**
>
> - 你想知道：P(有病|检查阳性) — 后验
> - 医院知道：P(检查阳性|有病) = 99%（灵敏度）— 似然
> - 人群中有病的比例：P(有病) = 0.1% — 先验
> - 贝叶斯定理帮你"翻转"！

### 1.3 MAP 决策规则 (Maximum A-Posteriori)

**一句话定义：** 选择后验概率最大的那个类别。

**公式：**

```
ŷ = argmax_Y  P(Y|X₁, X₂, …, Xd)
  = argmax_Y  P(X₁, X₂, …, Xd | Y) × P(Y) / P(X₁, X₂, …, Xd)
  = argmax_Y  P(X₁, X₂, …, Xd | Y) × P(Y)   ← P(X) 对所有类别相同，可以忽略
```

> 🔑 **关键简化：** 比较不同类别时，P(X) 是常数（分母一样），所以只需比较分子：**似然 × 先验**。

### 1.4 ❌ 直接估计的致命问题——组合爆炸

MAP 公式看起来很优美，但有一个巨大的问题：**如何估计 P(X₁, X₂, …, Xd | Y)？**

假设有 3 个特征，每个有 3 种取值：

- 需要估计的参数数量 = 3 × 3 × 3 = **27 种组合**（对每个类别！）
- 如果有 10 个特征，每个 5 种取值：5¹⁰ = **约 1000 万种组合**
- 训练数据可能只有 10 条记录 → 绝大多数组合**从未出现过**

> 🔑 **故事转折点：** 直接估计联合概率 P(X₁, X₂, …, Xd | Y) 需要的数据量随特征数**指数级增长**，实际不可行 → 我们需要把联合概率**拆开**！

## 🧮 第二章：方案一——朴素贝叶斯（✅ 聪明偷懒）

### 2.1 核心创新：条件独立性假设

朴素贝叶斯的"朴素"在于一个大胆的假设：

> **在给定类别 Y 的条件下，所有特征 X₁, X₂, …, Xd 彼此独立。**

**公式分解：**

```
P(X₁, X₂, …, Xd | Y) = P(X₁|Y) × P(X₂|Y) × … × P(Xd|Y)
```

联合概率变成了各个属性条件概率的**乘积**！

**参数数量对比：**

| 方法         | 参数数量 (3个特征，各3种取值) | 参数数量 (10个特征，各5种取值) |
| ------------ | ----------------------------- | ------------------------------ |
| 直接估计联合 | 27                            | ~1000万                        |
| 朴素贝叶斯   | 3×3 = 9                       | 10×5 = 50                      |

> 💡 **条件独立性直觉——臂长与阅读能力：**
>
> - 观察：小孩臂长短，阅读能力也弱 → 看起来"相关"
> - 但如果**固定年龄**（如只看 10 岁的孩子），臂长和阅读能力不再相关
> - 是"年龄"同时影响了两者，而非彼此影响
> - **条件独立：** P(臂长|阅读能力, 年龄) = P(臂长|年龄)

### 2.2 分类公式

```
ŷ = argmax_Y  P(Y) × ∏ P(Xᵢ|Y)
```

- P(Y)：先验概率，直接从数据统计（某类占总数的比例）
- P(Xᵢ|Y)：每个特征在该类别下的条件概率

### 2.3 完整计算示例

**测试记录：** X = (Refund=No, Divorced, Income=120K)

**Step 1: 估计先验概率 P(Y)**

```
P(No)  = 7/10 = 0.7
P(Yes) = 3/10 = 0.3
```

**Step 2: 估计分类特征的条件概率**

对于 **分类属性 (Categorical)**——直接数数：

```
P(Xᵢ = c | Y = y) = nᶜ / n

其中 nᶜ = 在类别 y 中 Xᵢ 取值 c 的实例数
     n  = 类别 y 的总实例数
```

| 条件概率          | Evade=No | Evade=Yes |
| ----------------- | -------- | --------- |
| P(Refund=No \| ·) | 4/7      | 3/3 = 1   |
| P(Divorced \| ·)  | 1/7      | 1/3       |

**Step 3: 估计连续特征的条件概率**

对于 **连续属性 (Continuous)**——假设正态分布：

```
P(Xᵢ | Y) = (1/√(2πσ²)) × exp(-(Xᵢ - μ)² / (2σ²))

其中 μ = 该类别中 Xᵢ 的样本均值
     σ² = 该类别中 Xᵢ 的样本方差
```

| 统计量       | Evade=No | Evade=Yes |
| ------------ | -------- | --------- |
| μ (Income)   | 110      | 90        |
| σ² (Income)  | 2975     | 25        |
| P(120K \| ·) | 0.0072   | 1.2×10⁻⁹  |

**Step 4: 计算后验（分子）并比较**

```
P(X|No)  × P(No)  = (4/7 × 1/7 × 0.0072) × 0.7 = 0.0006 × 0.7
P(X|Yes) × P(Yes) = (1 × 1/3 × 1.2×10⁻⁹) × 0.3 = 4×10⁻¹⁰ × 0.3
```

P(X|No)×P(No) **≫** P(X|Yes)×P(Yes) → **分类为 No（不逃税）**

> 💡 **为什么 P(X|Yes) 这么小？** 因为 Income=120K 对于 Evade=Yes 类（均值 90，方差仅 25）来说是极不可能的值——相当于距均值 6 个标准差！

### 2.4 部分信息决策

朴素贝叶斯的一个优点是：**即使信息不完整，也能做出决策。**

```
信息量：                                         决策依据：
────────────────────────────────────────────────────────────
什么都不知道                                →  P(Yes)=0.3 vs P(No)=0.7 → No
只知道 Marital Status = Divorced            →  加入一项似然
知道 Divorced + Refund=No                   →  加入两项似然
知道 Divorced + Refund=No + Income=120K     →  完整计算
```

信息越多 → 分类越有信心。

### 2.5 ⚠️ 朴素贝叶斯的致命问题——零概率

假设数据中：P(Married | Evade=Yes) = **0**（没有已婚的逃税者）。

那么对于 X = (Married, …)：

```
P(X | Yes) = P(Married|Yes) × ... = 0 × ... = 0
```

**无论其他特征多么"像"逃税者，只要一个条件概率为 0，整个乘积就变成 0！**

更严重的情况：如果删掉一条记录后，两个类别都出现 0 概率：

```
P(X|No)  = ... × 0 × ... = 0
P(X|Yes) = 0 × ... × ... = 0
```

→ **完全无法分类！** 0 vs 0，没有胜者。

> 🔑 **故事转折点：** 零概率会"杀死"整个乘积，使分类器瘫痪 → 我们需要一种方法来"填补"数据中的空白！

## 🧠 第三章：方案二——拉普拉斯平滑（✅ 修补零概率）

### 3.1 核心创新：给每个计数加 1

**拉普拉斯平滑 (Laplace Smoothing)：**

```
P(Xᵢ = c | Y) = (nᶜ + 1) / (n + v)

其中 nᶜ = Xᵢ=c 且 Y=y 的实例数
     n  = Y=y 的总实例数
     v  = Xᵢ 可取值的总数
```

假设 Marital Status 有 3 种取值（Single, Married, Divorced），v = 3：

```
原始：P(Married|Yes) = 0/3 = 0          ← 死了！
平滑：P(Married|Yes) = (0+1)/(3+3) = 1/6  ← 活了！
```

> 💡 **直觉：** 就像给每个"格子"预先放一个"幽灵"计数。即使从没见过某个组合，也不会认为它"绝对不可能"——只是"非常罕见"。

### 3.2 m-估计 (m-estimate)——更灵活的平滑

```
P(Xᵢ = c | Y) = (nᶜ + m × p) / (n + m)

其中 p = 先验初始估计，通常取 1/v
     m = 对先验估计 p 的置信度（超参数）
```

- m = 0 → 完全不平滑（回到原始估计）
- m = v, p = 1/v → 等价于拉普拉斯平滑
- m 越大 → 越相信先验 p，数据的影响越小

### 3.3 ✅ 平滑解决了什么？

| 问题   | 无平滑          | 有平滑                |
| ------ | --------------- | --------------------- |
| 零概率 | ❌ 整个乘积变 0 | ✅ 给出小但非零的概率 |
| 小样本 | ❌ 估计极不稳定 | ✅ 向先验"借力"       |
| 大样本 | ✅ 估计准确     | ✅ 平滑项影响可忽略   |

## 🏰 第四章：方案三——朴素贝叶斯的局限与贝叶斯信念网络（BBN）

### 4.1 朴素贝叶斯的软肋

回顾朴素贝叶斯的"朴素"假设：**所有特征在给定类别下独立。**

但现实常常不是这样：

| 场景        | 独立？ | 例子                         |
| ----------- | ------ | ---------------------------- |
| 年龄 & 收入 | ❌     | 年龄大 → 工作年限长 → 收入高 |
| 退税 & 收入 | ❌     | 高收入更可能退税             |
| 温度 & 湿度 | ❌     | 热天往往湿度也高             |

当特征之间存在**冗余**或**相关性**时，朴素贝叶斯的假设被违反，性能可能下降。

> **但令人惊讶的是：** 即使独立性假设不成立，朴素贝叶斯在实践中仍然表现很好！因为分类只需要比较类别概率的**相对大小**，而非精确值。

### 4.2 朴素贝叶斯的优缺点总结

**优点：**

| 优势               | 解释                                               |
| ------------------ | -------------------------------------------------- |
| **对孤立噪声稳健** | 单个噪声点不会严重影响概率估计                     |
| **处理缺失值**     | 直接在概率计算中忽略缺失属性                       |
| **对无关属性稳健** | 无关属性的 P(Xᵢ\|Y) 对所有类别大致相同，不影响决策 |

**缺点：**

| 劣势              | 解释                            |
| ----------------- | ------------------------------- |
| **冗余/相关属性** | 违反条件独立假设 → 概率估计有偏 |

> 🔑 **故事转折点：** 朴素贝叶斯假设"所有特征独立"——这太简单了。现实世界中特征之间常有复杂的依赖关系 → 我们需要一种可以**建模依赖关系**的方法！

### 4.3 贝叶斯信念网络 (Bayesian Belief Network, BBN)

**一句话定义：** 用一个有向无环图 (DAG) 来表示变量之间的概率依赖关系，比朴素贝叶斯更灵活。

**BBN 的两个核心组件：**

```
1. 有向无环图 (DAG)
   - 节点 = 随机变量
   - 弧 = 依赖关系（有向箭头）

2. 概率表
   - 无父节点 → 先验概率 P(X)
   - 一个父节点 → 条件概率 P(X|Parent)
   - 多个父节点 → 联合条件概率 P(X|Parent₁, Parent₂, ...)
```

### 4.4 BBN 中的条件独立性

BBN 中的条件独立性规则：

> **一个节点在其父节点已知时，与所有非后代节点条件独立。**

```
        D
       / \
      C   (其他)
     / \
    A   B

D 是 C 的父节点, A 是 C 的子节点, B 是 D 的后代
→ 如果 C 已知, A 与 D 条件独立
```

### 4.5 朴素贝叶斯是 BBN 的特例！

```
朴素贝叶斯的 BBN 结构：

         Y (类别)
       / | \  \
      X₁ X₂ X₃ ...Xd

Y 是所有特征的唯一父节点
→ 给定 Y, 所有 Xᵢ 互相独立
→ 这正是朴素贝叶斯假设！
```

BBN 允许更复杂的结构，比如某些特征之间也可以有直接连边。

### 4.6 BBN 推理实例——心脏病预测

**网络结构：**

```
 Exercise    Diet
     \       /
      \     /
    Heart Disease
      /      \
     /        \
Chest Pain  Blood Pressure
```

**概率表（根节点 = 先验概率）：**

| P(Exercise) | Yes: 0.7          | No: 0.3             |
| ----------- | ----------------- | ------------------- |
| **P(Diet)** | **Healthy: 0.25** | **Unhealthy: 0.75** |

**概率表（Heart Disease = 取决于父节点）：**

| Exercise | Diet      | P(HD=Yes) | P(HD=No) |
| -------- | --------- | --------- | -------- |
| Yes      | Healthy   | 0.25      | 0.75     |
| Yes      | Unhealthy | 0.55      | 0.45     |
| No       | Healthy   | 0.45      | 0.55     |
| No       | Unhealthy | 0.75      | 0.25     |

**概率表（症状 = 取决于 Heart Disease）：**

|                        | HD=Yes | HD=No |
| ---------------------- | ------ | ----- |
| P(Chest Pain=Yes)      | 0.80   | 0.01  |
| P(Blood Pressure=High) | 0.85   | 0.20  |

**推理前的关键假设（来自 DAG 结构）：**

从图结构可以读出**两条条件独立性假设**：

| 假设                                                    | 来自 DAG 的依据                                     | 含义                                                                                     |
| ------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **假设1：Exercise ⊥ Diet**                              | 两个根节点之间没有连边                              | 运动习惯和饮食习惯**互相独立** → P(E, D) = P(E) × P(D)                                   |
| **假设2：Chest Pain ⊥ Blood Pressure \| Heart Disease** | CP 和 BP 都只有 HD 一个父节点，它们之间没有直接连边 | 给定是否有心脏病后，胸痛和血压**条件独立** → P(CP, BP \| HD) = P(CP \| HD) × P(BP \| HD) |

> 💡 **正是这两条假设，允许我们把联合概率拆成乘积来计算！** 如果 CP 和 BP 之间有直接连边（比如高血压本身也直接导致胸痛），就不能这样拆了。

**推理：** X = (Exercise=No, Diet=Healthy, Chest Pain=Yes, BP=High)

```
Step 1: 查 CPT — Heart Disease 取决于父节点 (Exercise, Diet)
  P(HD=Yes | E=No, D=Healthy) = 0.45     ← 直接查表
  P(HD=No  | E=No, D=Healthy) = 0.55     ← 直接查表

Step 2: 乘上子节点的似然 — 利用假设2 (CP ⊥ BP | HD) 拆成乘积
  HD=Yes: 0.45 × P(CP=Yes|HD=Yes) × P(BP=High|HD=Yes) = 0.45 × 0.80 × 0.85 = 0.306
  HD=No:  0.55 × P(CP=Yes|HD=No)  × P(BP=High|HD=No)  = 0.55 × 0.01 × 0.20 = 0.0011

Step 3: 比大小
  0.306 ≫ 0.0011 → 分类为 HD=Yes（有心脏病）
```

> 💡 **BBN 的优势展现：** 在这个网络中，Exercise 和 Diet 之间没有直接连边（它们独立），但它们通过 Heart Disease 间接关联。Chest Pain 和 Blood Pressure 也只依赖于 Heart Disease。这种灵活的结构比"全部独立"或"全部关联"都更接近现实。

```
│                    ▼                                         │
│  🔄 方式1：直接估计 P(X₁...Xd|Y)                              │
│     ✅ 利用所有特征                                            │
│     ❌ 组合爆炸：需要指数级数据来估计联合概率                   │
│                    │                                         │
│                    ▼                                         │
│  🧠 方式2：朴素贝叶斯 (Naïve Bayes)                           │
│     ✅ 假设特征独立 → 联合概率拆成乘积                         │
│     ✅ 参数量从指数级降到线性级                                 │
│     ⚠️ 零概率问题 → 用拉普拉斯平滑解决                        │
│     ❌ 独立性假设太强，无法建模特征间依赖                       │
│                    │                                         │
│                    ▼                                         │
│  🏰 方式3：贝叶斯信念网络 (BBN)                               │
│     ✅ 用 DAG 灵活建模任意依赖关系                             │
│     ✅ 朴素贝叶斯是其特例                                      │
│     ⚠️ 结构需要领域知识或结构学习                              │
└──────────────────────────────────────────────────────────────┘
```

### 转折点总结

| 从 → 到                   | 解决了什么核心问题？               |
| ------------------------- | ---------------------------------- |
| 频率统计 → 贝叶斯分类     | 从"不看特征"到"利用特征做推理"     |
| 直接估计 → 朴素贝叶斯     | 从"组合爆炸"到"独立假设拆分"       |
| 朴素贝叶斯 → 拉普拉斯平滑 | 从"零概率杀死乘积"到"平滑填补空白" |
| 朴素贝叶斯 → BBN          | 从"全部独立"到"灵活建模依赖关系"   |

## 🎓 考试重点检查清单

### 概念理解

- [ ] 能解释贝叶斯定理中 Posterior、Prior、Likelihood、Evidence 各项的含义
- [ ] 能解释为什么 MAP 决策中可以忽略 P(X)（分母对所有类别相同）
- [ ] 能解释朴素贝叶斯的"朴素"在哪里（条件独立性假设）
- [ ] 能用"臂长与阅读能力"的例子解释条件独立性
- [ ] 能解释零概率问题及其后果
- [ ] 能解释拉普拉斯平滑的原理和参数 v 的含义
- [ ] 能画出 BBN 的 DAG 并解释节点和弧的含义
- [ ] 能解释"朴素贝叶斯是 BBN 的特例"——画出其 DAG 结构

### 公式掌握

- [ ] 条件概率：P(A|B) = P(A∩B) / P(B)
- [ ] 贝叶斯定理：P(Y|X) = P(X|Y) × P(Y) / P(X)
- [ ] 朴素贝叶斯分解：P(X₁...Xd|Y) = ∏ P(Xᵢ|Y)
- [ ] MAP 决策：ŷ = argmax_Y P(Y) × ∏ P(Xᵢ|Y)
- [ ] 分类属性估计：P(Xᵢ=c|Y) = nᶜ/n
- [ ] 连续属性估计：用正态分布 P(Xᵢ|Y) = N(μ, σ²)
- [ ] 拉普拉斯平滑：P(Xᵢ=c|Y) = (nᶜ+1)/(n+v)
- [ ] m-估计：P(Xᵢ=c|Y) = (nᶜ+mp)/(n+m)

### 计算题准备

- [ ] 能从数据表中手动计算 P(Y)（先验）
- [ ] 能从数据表中手动计算 P(Xᵢ|Y)（分类特征的似然）
- [ ] 能用正态分布公式计算 P(Xᵢ|Y)（连续特征的似然）
- [ ] 能完成完整的朴素贝叶斯分类流程（先验 × 逐个似然 → 比较）
- [ ] 能应用拉普拉斯平滑重新计算被零概率阻断的概率
- [ ] 能在 BBN 中计算条件概率并做推理

### 对比题准备

- [ ] 朴素贝叶斯 vs BBN（假设强度、图结构、灵活性）
- [ ] 原始估计 vs 拉普拉斯平滑 vs m-估计（公式差异、使用场景）
- [ ] 分类属性 vs 连续属性的概率估计方法
- [ ] 朴素贝叶斯的优缺点（稳健性 vs 独立性假设限制）

### 陷阱题准备

- [ ] ⚠️ 比较时不需要算 P(X)——但要知道**为什么**不需要（分母相同）
- [ ] ⚠️ 零概率 → 整个乘积为 0，不管其他项有多大
- [ ] ⚠️ 连续属性不能直接数数，必须假设分布（通常用正态分布）
- [ ] ⚠️ BBN 中"条件独立"的条件是父节点已知，不是任意节点
- [ ] ⚠️ 拉普拉斯平滑中 v 是属性可取值的数量，不是类别数

---

> 📖 **故事总结：** 我们从"直觉数数"出发（只看比例），发现忽略了特征信息；然后用贝叶斯定理"翻转"概率方向，但遇到了联合概率的组合爆炸；于是用朴素贝叶斯的独立性假设"聪明偷懒"，把指数级问题降为线性级；遇到零概率时用拉普拉斯平滑"填补空白"；最后，对于真正需要建模依赖关系的场景，升级为贝叶斯信念网络。每一步进化都源于上一步的"致命缺陷"——这就是概率分类技术的因果链。
