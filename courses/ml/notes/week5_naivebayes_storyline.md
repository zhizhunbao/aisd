# Lecture 5 故事线：从贝叶斯定理到贝叶斯信念网络

> **Source:** `Week5_NaiveBayes.pdf`
> **核心主题：** 如何用概率进行分类？—— 从"翻转"条件概率到构建变量依赖图
> **故事线：** 从一个简单的概率翻转公式出发，一路解决"维度爆炸"、"零概率陷阱"、"独立性假设失效"三个boss，最终进化到贝叶斯信念网络。

---

## 🎬 序幕：我们要解决什么问题？

### 核心问题

给定一条新记录（如：退税=否、离婚、收入=120K），如何判断此人是否会逃税？

我们已经学过 **SVM**（用超平面和支持向量分类）和 **KNN**（用距离投票分类）。现在我们换一个全新视角：**用概率做分类**。

> 💡 **SVM 问的是："哪个超平面？" KNN 问的是："谁最近？" 贝叶斯问的是："哪个类别最可能？"**

概率方法的独特优势：

1. 输出的是**概率**而非硬标签 → 可以衡量分类的**置信度**
2. 天然支持**先验知识** → 如果99%的邮件是垃圾邮件，即使特征弱也应倾向垃圾邮件
3. 可以优雅处理**缺失值** → 缺少某个属性？从乘积中去掉即可

但概率分类有一个根本挑战：我们想知道 P(类别|特征)，但数据只告诉我们 P(特征|类别)。如何"翻转"？

---

## 📚 第一章：贝叶斯定理——概率的"翻转"魔法

### 1.1 条件概率的本质

条件概率 P(A|B) = "在 B 已经发生的世界里，A 发生的概率"。

**骰子例子：** 掷两个骰子，A = 和为8，B = 第一个骰子为5。

- 全部36种可能中，和为8的有5种 → P(A) = 5/36
- 第一个骰子为5的有6种 → P(B) = 6/36
- 两个同时满足的只有(5,3) → P(A∩B) = 1/36
- **P(A|B) = 1/36 ÷ 6/36 = 1/6**

关键洞察：P(A|B) ≠ P(B|A)。这种不对称性，正是贝叶斯定理要解决的核心问题。

### 1.2 贝叶斯定理

```
P(Y|X) = P(X|Y) × P(Y) / P(X)
```

| 符号    | 名称              | 含义                           | 类比                             |
| ------- | ----------------- | ------------------------------ | -------------------------------- |
| P(Y\|X) | 后验 (Posterior)  | 看到证据后对类别的信念         | 陪审团看完证据后的判决           |
| P(X\|Y) | 似然 (Likelihood) | 如果是该类别，这些特征有多可能 | "如果有罪，这个证据出现的可能性" |
| P(Y)    | 先验 (Prior)      | 看到证据之前的基础信念         | "犯罪率是多少？"                 |
| P(X)    | 证据 (Evidence)   | 归一化常数（所有类别相同）     | 总投票数                         |

> 💡 **医学检测类比：** 你做了一个准确率99%的疾病检测，结果阳性。你真的生病了吗？如果这种病只有万分之一的人患，即使阳性，你实际生病的概率也只有~1%。**先验改变一切。**

### 1.3 MAP 决策规则

因为 P(X) 对所有类别相同，比较时可以丢弃，只需：

```
选择 Y* = argmax_Y  P(X|Y) × P(Y)
```

> 🔑 **到此为止一切完美。但新的 boss 出现了……**

---

## 🧮 第二章：方案一——直接估计联合概率（❌ 维度灾难）

### 2.1 尝试直接估计

我们要计算 P(X₁, X₂, …, Xd | Y)。对税务数据：

- X₁ = Refund (2个值)
- X₂ = Marital Status (3个值)
- X₃ = Income (连续)

仅分类属性就有 2 × 3 = 6 种组合。每种组合还要按类别分别统计。

### 2.2 ❌ 维度爆炸

当属性增多时，问题急剧恶化：

| 属性数 d | 每个二值属性 | 组合数    | 需要的训练数据 |
| -------- | ------------ | --------- | -------------- |
| 5        | 2个值        | 32        | 至少数百       |
| 10       | 2个值        | 1,024     | 至少数千       |
| 20       | 2个值        | 1,048,576 | 至少数百万     |
| 100      | 2个值        | 2¹⁰⁰      | 比宇宙原子还多 |

大部分组合在训练数据中**从未出现**。无法估计 P(X₁, X₂, …, X₁₀₀ | Y)。

> 🔑 **故事转折点：** 直接估计联合概率是不可能的——我们需要一种方法把 O(vᵈ) 降到可计算的量级 → **朴素贝叶斯**登场！

---

## 🧠 第三章：方案二——朴素贝叶斯（✅ 解决维度灾难，⚠️ 新问题出现）

### 3.1 核心假设：条件独立

**核心思想：** 假设给定类别后，所有属性**相互独立**。

```
P(X₁, X₂, …, Xd | Y) = P(X₁|Y) × P(X₂|Y) × … × P(Xd|Y)
```

> 💡 **类比：** 就像独立掷骰子。P(3,1,4,1,5) = 1/6⁵。每个属性就像一次独立投掷——知道第一次结果不影响第二次。

这个假设把复杂度从 **O(vᵈ) 降到 O(v × d)**。10个二值属性：从1024种组合 → 仅20个概率需要估计。

### 3.2 概率估计

**分类属性：** 数数即可。

- P(Refund=No | No) = (类别=No 中 Refund=No 的个数) / (类别=No 的总数) = 4/7

**连续属性：** 假设高斯分布。

- 计算每个类别内的均值 μ 和方差 σ²
- P(Income=120K | No) = 高斯PDF(120K; μ=110, σ²=2975) = 0.0072

### 3.3 完整分类

给定 X = (退税=否, 离婚, 收入=120K)：

```
P(X|No) = 4/7 × 1/7 × 0.0072 = 0.0006
P(X|Yes) = 1 × 1/3 × 1.2×10⁻⁹ = 4×10⁻¹⁰

P(X|No)×P(No) = 0.00042 ≫ P(X|Yes)×P(Yes) = 1.2×10⁻¹⁰

→ 分类结果：不逃税 (No)
```

| 维度         | 直接估计 | 朴素贝叶斯 |
| ------------ | :------: | :--------: |
| 组合数       |  O(vᵈ)   |   O(v×d)   |
| 数据需求     |  指数级  |   线性级   |
| 分类能力     |    ✅    |     ✅     |
| 处理相关属性 |    ✅    |     ❌     |

### 3.4 ❌ 朴素贝叶斯的致命问题——零概率陷阱

如果训练数据中**没有一个已婚的人逃税**：

- P(Married | Yes) = 0/3 = **0**
- P(X|Yes) = ... × **0** × ... = **0**

一个零，全盘皆零！所有其他证据——无论多么强烈——都被这一个零彻底抹杀。

更严重的是，如果**两个类别都有零**，分类器完全瘫痪：

- P(X|No) = 0，P(X|Yes) = 0 → 无法分类！

> 🔑 **故事转折点：** 零概率会毁掉整个分类器 → 我们需要一种"永远不让概率为零"的策略 → **拉普拉斯平滑**登场！

---

## 🛡️ 第四章：拉普拉斯平滑——保底策略（✅ 解决零概率）

### 4.1 核心思路

"没见过" ≠ "不可能"。我们给每个属性值都加一个"虚拟观测"：

```
原始：         P(Xᵢ=c|y) = nc / n              可能为0 ❌
拉普拉斯平滑：  P(Xᵢ=c|y) = (nc + 1) / (n + v)  永远不为0 ✅
```

> 💡 **餐厅评价类比：** 新餐厅默认有1个好评+1个差评。即使零真实评价，评分也是50%（而非0%或100%）。随着真实评价增多，虚拟评价被稀释。

### 4.2 m-估计（通用版本）

```
P(Xᵢ=c|y) = (nc + m×p) / (n + m)
```

- p = 先验估计（如 1/v 表示均匀）
- m = 先验的"等效样本量"

拉普拉斯平滑是 m-估计的特例：m=v, p=1/v。

### 4.3 已解决与遗留问题

| 问题     | 状态                      |
| -------- | ------------------------- |
| 维度灾难 | ✅ 已解决（独立性假设）   |
| 零概率   | ✅ 已解决（拉普拉斯平滑） |
| 相关属性 | ❌ 仍然违反独立假设       |

> 🔑 **故事转折点：** 当属性之间确实存在依赖关系（如运动习惯影响饮食习惯），NB 的独立性假设就失效了 → 我们需要能建模**部分依赖**的方法 → **贝叶斯信念网络 (BBN)**登场！

---

## 🏰 第五章：贝叶斯信念网络——更灵活的概率模型（✅ 解决相关属性）

### 5.1 从"全独立"到"选择性依赖"

NB 的结构是一个扁平的星形：类别 Y 是唯一父节点，所有属性都是没有连接的子节点。

BBN 的结构是任意有向无环图 (DAG)：允许变量之间有选择性的依赖边。

```
朴素贝叶斯（NB）          贝叶斯信念网络（BBN）
    Y                    Exercise    Diet
   /|\  \                    \      /
  / | \  \                  Heart Disease
 X₁ X₂ X₃ X₄               /        \
                        Chest Pain  Blood Pressure
```

### 5.2 BBN 的核心规则

1. **每个节点**有一个条件概率表 (CPT)
2. 无父节点 → 表中是先验概率 P(X)
3. 有父节点 → 表中是 P(X|parents)
4. **条件独立性：** 知道父节点后，与所有非后代独立

### 5.3 心脏病推理实例

给定证据：运动=否, 饮食=健康, 胸痛=是, 血压=高

```
P(HD=Yes | E=No, D=Healthy) = 0.45
× P(CP=Yes | HD=Yes) = 0.8
× P(BP=High | HD=Yes) = 0.85
= 0.306

P(HD=No | E=No, D=Healthy) = 0.55
× P(CP=Yes | HD=No) = 0.01
× P(BP=High | HD=No) = 0.2
= 0.0011

0.306 ≫ 0.0011 → 分类为心脏病 = 是
```

| 维度       |   朴素贝叶斯   | 贝叶斯信念网络  |
| ---------- | :------------: | :-------------: |
| 独立性假设 |    全部独立    |   选择性依赖    |
| 结构       |    固定星形    |    灵活 DAG     |
| 参数       | O(d) per class | 取决于 DAG 结构 |
| 表达力     |       低       |       高        |
| 可解释性   |       中       | ✅ 高（因果图） |
