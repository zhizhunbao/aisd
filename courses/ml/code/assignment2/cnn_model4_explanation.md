## 设计哲学

### 有逻辑的设计 ✅（有理论依据的选择）

| 设计选择 | 背后的逻辑 |
|---|---|
| **filters 逐层翻倍**（32→64→128） | Pool 缩小空间（32→16→8），filters 翻倍来提取更多特征，补偿空间信息损失 |
| **Conv 后接 Pool** | Conv 提取特征，Pool 缩小尺寸降低计算量 |
| **最后用 Dense** | 卷积提取的是局部特征，需要全连接做全局判断 |
| **Dropout 放在 Dense 后** | Dense 参数最多最容易过拟合，所以在这加正则化 |
| **最后一层 10 个输出** | CIFAR-10 有 10 个类别，必须是 10 |
| **用 same padding** | 防止每层都缩小，让 Pool 来控制缩小节奏 |
| **3×3 卷积核** | VGGNet 论文证明小卷积核叠加效果更好、参数更少 |
| **ReLU 激活函数** | 计算简单，避免梯度消失，现在的标准选择 |
| **softmax 输出层** | 多分类任务的标准做法，输出概率分布 |

### 靠经验调的部分 🔧（没有唯一正确答案）

| 设计选择 | 为什么没有固定答案 |
|---|---|
| 几层 Conv？（2 层 or 3 层） | 试出来的，太少学不够，太多过拟合 |
| 32-64-128 还是 16-32-64？ | 试出来的，看准确率和计算成本的平衡 |
| Dense 为什么 128 不是 256？ | 试出来的，256 可能也行 |
| Dropout 为什么 0.3 不是 0.5？ | 试出来的，两个都有人用 |
| 训练 15 轮还是 50 轮？ | 试出来的，看验证集准确率什么时候不再提升 |
| 学习率用默认还是手动调？ | 经验 + 实验，Adam 优化器自动调整学习率 |

> **总结：** 架构的"骨架"有逻辑（Conv→Pool→Dense），具体的"数字"靠经验调。这就是为什么深度学习被戏称为"炼丹"。

## 通用概念速查

| 名词 | 含义 |
|------|------|
| **Output Shape** | 数据经过这一层后变成什么形状 |
| **None** | batch size 占位符，忽略它看后面的数字 |
| **Params** | 可学习的参数数量（权重 W + 偏置 b），不是维度 |
| **filters** | 卷积核数量，每个卷积核产出一张特征图 |
| **same padding** | 在图片边缘补零，让卷积后尺寸不变 |
| **units** | Dense 层的神经元数量 = 输出维度 |

### 什么是参数（Parameters）？

参数 = 模型需要**学习/训练的数字的总个数**。每个参数就是一个"旋钮"，训练过程就是不断调这些旋钮直到预测准确。

| 层类型 | 参数是什么 | 举例 |
|--------|-----------|------|
| **Conv2D** | 卷积核权重 + 偏置 | 3×3 kernel, 3通道, 32 filters → (3×3×3+1)×32 = 896 |
| **Dense** | 连接权重 + 偏置 | 128→10 → (128+1)×10 = 1,290 |
| **MaxPooling / Flatten / Dropout** | **0 参数** | 固定操作，不需要学习 |

**为什么关注参数数？**
- 参数越多 → 训练越慢，需要更多计算资源
- 参数越多 → 越容易**过拟合**（死记硬背训练数据）
- 池化层的核心作用：CNN 1 无池化 → Dense 参数 **8,388,736**；CNN 4 三层池化 → Dense 参数 **262,272**（缩小 32 倍）

### 权重（Weights）和偏置（Bias）的区别

参数 = **权重 + 偏置**，两者都通过反向传播训练得来。

```
一个神经元的计算公式:
output = activation(w₁x₁ + w₂x₂ + ... + wₙxₙ + b)
                    \_________权重部分_________/   ↑偏置
```

- **权重 w**：决定每个输入"有多重要"（占绝大多数参数）
- **偏置 b**：让激活函数可以左右移动，不被迫过零点（每个神经元只有 1 个）

类比 `y = kx + b`：没有 b 直线必须过原点；有 b 直线可以上下移动，拟合能力更强。

**训练过程（权重和偏置一起学）：**
1. **初始化**：权重随机初始化，偏置初始化为 0
2. **前向传播**：用当前权重和偏置算出预测
3. **算损失**：预测 vs 真实标签的差距
4. **反向传播**：对权重和偏置分别求梯度（∂Loss/∂w 和 ∂Loss/∂b）
5. **更新**：`w = w - lr × ∂Loss/∂w`，`b = b - lr × ∂Loss/∂b`

### Dropout 为什么不改变输出形状？

Dropout **不会删除神经元**，只是把一些值**随机变成 0**，形状不变。

```
假设输入 [0.5, 1.2, 0.8, 0.3]，Dropout rate=0.3:

输入:   [0.5,  1.2,  0.8,  0.3]    ← shape = (4,)
输出:   [0.71, 0.0,  1.14, 0.43]   ← shape = (4,)  ← 形状没变！
              ↑ 被随机置0         其他值 ÷0.7 补偿
```

- 如果真删掉（4→3），下面的 Dense 层每次输入数量不同，网络没法算
- **训练时**：随机 30% 置 0，其余值放大（÷0.7）补偿
- **推理时**：完全不做操作，所有值原样通过

### Dense 层怎么把 256 维变成 10 维？

Dense(10) 用 10 组不同的权重，把 256 个输入"投票"成 10 个分数：

```
输入: [x₁, x₂, ..., x₂₅₆]   ← 256 个数

输出₁ = w₁₁·x₁ + w₁₂·x₂ + ... + w₁,₂₅₆·x₂₅₆ + b₁  → 飞机分数
输出₂ = w₂₁·x₁ + w₂₂·x₂ + ... + w₂,₂₅₆·x₂₅₆ + b₂  → 汽车分数
...
输出₁₀ = w₁₀,₁·x₁ + ... + w₁₀,₂₅₆·x₂₅₆ + b₁₀      → 卡车分数

经过 softmax 变成概率:
[0.02, 0.01, 0.05, 0.03, 0.01, 0.02, 0.82, 0.01, 0.02, 0.01]
  飞机  汽车   鸟    猫    鹿    狗   青蛙   马    船   卡车
                                     ↑最大 → 预测为青蛙

参数: (256+1) × 10 = 2,570（256×10 权重 + 10 偏置）
```

## 卷积计算详解

### 卷一次怎么算？

```
图片一小块 (3×3):     卷积核权重 (3×3):
┌────┬────┬────┐     ┌────┬────┬────┐
│ 3  │ 1  │ 4  │     │ w1 │ w2 │ w3 │
├────┼────┼────┤  ×  ├────┼────┼────┤
│ 2  │ 5  │ 6  │     │ w4 │ w5 │ w6 │
├────┼────┼────┤     ├────┼────┼────┤
│ 7  │ 8  │ 9  │     │ w7 │ w8 │ w9 │
└────┴────┴────┘     └────┴────┴────┘

三步：对应相乘 → 全部加起来 → 加偏置 b → 得到 1 个数字
```

### 多通道（RGB → 3 通道分别算再加起来）

```
R通道 3×3 × R权重 → 一个数
G通道 3×3 × G权重 → 一个数
B通道 3×3 × B权重 → 一个数
──────────────────
三个数 + 偏置 b = 最终 1 个数字
```

### Same Padding（3×3 卷积核，四周各补 1 圈零，输出尺寸不变）

```
补零前 32×32 → 补零后 34×34 → 卷积后还是 32×32
每边补 (3-1)÷2 = 1 个零
```

## Model 0: MLP (sklearn)

> **准确率：** ~51.5% | **总参数：** ~100K（sklearn 不直接显示）

**架构：** 输入 3072 → Dense(256) → Dense(128) → 输出 10

```
输入: 32×32×3 = 3072 个像素值（图片拉成一维向量）
  ↓
Dense(256): 3072 个输入 × 256 个神经元 = 每个神经元对所有像素加权求和
  ↓
Dense(128): 256 → 128
  ↓
输出(10): 10 个类别分数
```

**每一步怎么算：**
```
Dense(256) 的第 1 个神经元:
  = w₁×像素₁ + w₂×像素₂ + ... + w₃₀₇₂×像素₃₀₇₂ + b
  = 3072 次乘法 + 求和 + 偏置 → 1 个数字

256 个神经元各算一次 → 输出 256 个数字
```

**⚠️ 致命缺点：** 图片被拉成一维，丢失了所有空间结构（邻居像素不再相邻）。

## Model 1: NN (Dense-only)

> **准确率：** ~41.0% | **总参数：** 1,707,274

**架构：** Flatten → Dense(512) → Dropout(0.3) → Dense(256) → Dropout(0.3) → Dense(10)

| 层 | 输出形状 | 参数量 | 计算过程 |
|---|---|---|---|
| Flatten | (3072,) | 0 | 32×32×3=3072，只换形状 |
| Dense(512) | (512,) | **1,573,376** | (3072+1)×512 = 1,573,376 |
| Dropout(0.3) | (512,) | 0 | 随机 30% 置零 |
| Dense(256) | (256,) | 131,328 | (512+1)×256 = 131,328 |
| Dropout(0.3) | (256,) | 0 | 随机 30% 置零 |
| Dense(10) | (10,) | 2,570 | (256+1)×10 = 2,570 |

**逐层计算：**

**Dense(512)** — 3072 → 512：
```
输入 x = [x₁, x₂, ..., x₃₀₇₂]

神经元₁ = w₁₁×x₁ + w₁₂×x₂ + ... + w₁,₃₀₇₂×x₃₀₇₂ + b₁ → 一个数
...重复 512 次...
输出 = [神经元₁, ..., 神经元₅₁₂]

权重数: 3072×512 = 1,572,864 + 偏置 512 = 1,573,376
```

**Dropout(0.3)** — 训练时随机关掉 30%：
```
输入:  [3.2, 1.5, 7.8, 5.1, ...]
mask:  [ 1,   0,   1,   1,  ...]  ← 随机
输出:  [3.2, 0.0, 7.8, 5.1, ...]
推理时不丢弃。
```

**⚠️ 问题：** 和 MLP 一样，Flatten 后丢失空间结构。参数量 170 万，但准确率反而低于 MLP。

## Model 2: CNN 1 — Conv + Dense（无池化）

> **准确率：** ~62.4% | **总参数：** 8,409,418

**架构：** Conv2D(32) → Conv2D(64) → Flatten → Dense(128) → Dropout(0.3) → Dense(10)

| 层 | 输出形状 | 参数量 | 计算过程 |
|---|---|---|---|
| Conv2D(32) | (32, 32, 32) | 896 | (3×3×3+1)×32 = 896 |
| Conv2D(64) | (32, 32, 64) | 18,496 | (3×3×32+1)×64 = 18,496 |
| Flatten | (65536,) | 0 | 32×32×64 = 65,536 |
| Dense(128) | (128,) | **8,388,736** | (65536+1)×128 = 8,388,736 |
| Dropout(0.3) | (128,) | 0 | — |
| Dense(10) | (10,) | 1,290 | (128+1)×10 = 1,290 |

**逐层计算：**

**Conv2D(32)** — 输入 (32,32,3) → 输出 (32,32,32)：
```
1 个卷积核大小: 3×3×3 = 27 个权重 + 1 偏置 = 28 个参数
工作方式: 卷积核在 32×32 图上滑动，每个位置算 1 个数
          滑 32×32 = 1024 次 → 1 张 32×32 特征图
32 个卷积核 → 32 张特征图
总参数: 28 × 32 = 896
```

**Conv2D(64)** — 输入 (32,32,32) → 输出 (32,32,64)：
```
1 个卷积核大小: 3×3×32 = 288 个权重 + 1 偏置 = 289 个参数
要同时看 32 张特征图：
  特征图₁ 的 3×3 × 权重 → 一个数
  特征图₂ 的 3×3 × 权重 → 一个数
  ...
  特征图₃₂ 的 3×3 × 权重 → 一个数
  32 个数加起来 + 偏置 = 1 个输出
64 个卷积核: 289 × 64 = 18,496
```

**⚠️ 问题：** 没有池化层 → Flatten 后 65536 维 → Dense 层参数爆炸（840 万！）。

## Model 3: CNN 2 — Conv + MaxPool + Dense

> **准确率：** ~73.5% | **总参数：** 1,179,530

**架构：** Conv(32) → MaxPool → Conv(64) → MaxPool → Conv(128) → Flatten → Dense(128) → Dropout → Dense(10)

| 层 | 输出形状 | 参数量 | 计算过程 |
|---|---|---|---|
| Conv2D(32) | (32, 32, 32) | 896 | (3×3×3+1)×32 = 896 |
| MaxPool(2×2) | (16, 16, 32) | 0 | 32÷2=16，每 2×2 取最大值 |
| Conv2D(64) | (16, 16, 64) | 18,496 | (3×3×32+1)×64 = 18,496 |
| MaxPool(2×2) | (8, 8, 64) | 0 | 16÷2=8，每 2×2 取最大值 |
| Conv2D(128) | (8, 8, 128) | 73,856 | (3×3×64+1)×128 = 73,856 |
| Flatten | (8192,) | 0 | 8×8×128 = 8,192 |
| Dense(128) | (128,) | 1,048,704 | (8192+1)×128 = 1,048,704 |
| Dropout(0.3) | (128,) | 0 | — |
| Dense(10) | (10,) | 1,290 | (128+1)×10 = 1,290 |

**逐层计算：**

**MaxPooling2D(2×2)** — 取最大值：
```
┌──────┬──────┐
│ 3.2  │ 1.5  │
├──────┼──────┤  → max(3.2, 1.5, 7.8, 5.1) = 7.8
│ 7.8  │ 5.1  │
└──────┴──────┘

32×32 切成 16×16 个 2×2 小块，每块取最大值
参数: 0（固定操作，没有要学的东西）
```

**Conv2D(128)** — 输入 (8,8,64) → 输出 (8,8,128)：
```
1 个卷积核: 3×3×64 = 576 个权重 + 1 偏置 = 577
128 个卷积核: 577 × 128 = 73,856
```

**✅ 关键改进：** MaxPool 把 32→16→8，Flatten 后只有 8192 维（vs CNN1 的 65536），Dense 层参数大幅减少。

## Model 4: CNN 3 — Conv + AvgPool + Dense

> **准确率：** ~72.8% | **总参数：** 1,179,530

**架构同 CNN 2，但把 MaxPool 换成 AvgPool**

| 层 | 输出形状 | 参数量 | 计算过程 |
|---|---|---|---|
| Conv2D(32) | (32, 32, 32) | 896 | (3×3×3+1)×32 |
| AvgPool(2×2) | (16, 16, 32) | 0 | 32÷2=16，每 2×2 取平均 |
| Conv2D(64) | (16, 16, 64) | 18,496 | (3×3×32+1)×64 |
| AvgPool(2×2) | (8, 8, 64) | 0 | 16÷2=8 |
| Conv2D(128) | (8, 8, 128) | 73,856 | (3×3×64+1)×128 |
| Flatten | (8192,) | 0 | 8×8×128 |
| Dense(128) | (128,) | 1,048,704 | (8192+1)×128 |
| Dropout(0.3) | (128,) | 0 | — |
| Dense(10) | (10,) | 1,290 | (128+1)×10 |

**AvgPool vs MaxPool 的计算区别：**
```
同一个 2×2 区域: [3.2, 1.5, 7.8, 5.1]

MaxPool → 7.8（取最大值，保留最强信号）
AvgPool → (3.2+1.5+7.8+5.1)÷4 = 4.4（取平均，保留整体趋势）
```

**📝 参数量完全一样**（1,179,530），因为池化层没有参数。区别只在于"取最大"还是"取平均"这个操作。

## Model 5: CNN 4 — Conv + MaxPool + AvgPool + Dense

> **准确率：** ~74.1% | **总参数：** 356,810

**架构：** Conv(32) → **MaxPool** → Conv(64) → **AvgPool** → Conv(128) → **MaxPool** → Flatten → Dense(128) → Dropout → Dense(10)

| 层 | 输出形状 | 参数量 | 计算过程 |
|---|---|---|---|
| Conv2D(32) | (32, 32, 32) | 896 | (3×3×3+1)×32 = 896 |
| MaxPool(2×2) | (16, 16, 32) | 0 | 32÷2=16 |
| Conv2D(64) | (16, 16, 64) | 18,496 | (3×3×32+1)×64 = 18,496 |
| AvgPool(2×2) | (8, 8, 64) | 0 | 16÷2=8 |
| Conv2D(128) | (8, 8, 128) | 73,856 | (3×3×64+1)×128 = 73,856 |
| MaxPool(2×2) | (4, 4, 128) | 0 | 8÷2=4 |
| Flatten | (2048,) | 0 | 4×4×128 = 2,048 |
| Dense(128) | (128,) | **262,272** | (2048+1)×128 = 262,272 |
| Dropout(0.3) | (128,) | 0 | — |
| Dense(10) | (10,) | 1,290 | (128+1)×10 = 1,290 |

**逐层具体计算：**

**Conv2D(32)** — 输入 RGB 图片 (32,32,3)：
```
假设卷积核权重（学出来的）:
R 层: [-1, 0, 1; -1, 0, 1; -1, 0, 1]
G 层: [-1, 0, 1; -1, 0, 1; -1, 0, 1]
B 层: [-1, 0, 1; -1, 0, 1; -1, 0, 1]
偏置 b = 0.5

盖住图片左上角 3×3 区域:
R: (-1×200)+(0×150)+(1×100)+(-1×180)+(0×160)+(1×120)+(-1×170)+(0×140)+(1×110) = -220
G: (-1×50)+(0×60)+(1×70)+(-1×55)+(0×65)+(1×75)+(-1×45)+(0×55)+(1×65) = 60
B: (-1×30)+(0×20)+(1×10)+(-1×35)+(0×25)+(1×15)+(-1×40)+(0×30)+(1×20) = -60

输出 = -220 + 60 + (-60) + 0.5 = -219.5
ReLU: max(0, -219.5) = 0

这个位置输出 0。滑到下一个位置用同样权重再算 → 滑完 1024 个位置 → 一张特征图
32 个不同卷积核 → 32 张特征图
```

**MaxPool → AvgPool → MaxPool**（三次池化，尺寸 32→16→8→4）：
```
特征图上:
位置1: MaxPool [3.2, 1.5, 7.8, 5.1] → 7.8（保留最强特征）
位置2: AvgPool [3.2, 1.5, 7.8, 5.1] → 4.4（保留整体趋势）
位置3: MaxPool [3.2, 1.5, 7.8, 5.1] → 7.8（再次挑最强的）
```

**Flatten** — 三维 → 一维：
```
128 张 4×4 特征图:
特征图₁: [a₁, a₂, ..., a₁₆]     ← 16 个数
特征图₂: [b₁, b₂, ..., b₁₆]     ← 16 个数
...
特征图₁₂₈: [z₁, z₂, ..., z₁₆]  ← 16 个数

全部拼接 → [a₁, ..., a₁₆, b₁, ..., b₁₆, ..., z₁, ..., z₁₆]
4×4×128 = 2048 个数
```

**Dense(128)** — 2048 → 128：
```
神经元₁ = w₁₁×x₁ + w₁₂×x₂ + ... + w₁,₂₀₄₈×x₂₀₄₈ + b₁
...重复 128 次...
输出 = 128 个数字

参数: 2048×128 = 262,144 权重 + 128 偏置 = 262,272
占总参数的 73.5%！
```

**Dense(10)** — 最终分类：
```
飞机 = w₁₁×x₁ + ... + w₁,₁₂₈×x₁₂₈ + b₁ = 8.3  ← 最高分 → 预测飞机 ✈️
汽车 = ... = 1.2
鸟   = ... = 0.5
...共 10 个分数

参数: 128×10 = 1,280 + 10 = 1,290
```

## 六模型横向对比

| 模型 | 架构特点 | 总参数 | 准确率 | 关键差异 |
|---|---|---|---|---|
| **MLP** | 全连接 | ~100K | ~51.5% | 无空间结构 |
| **NN** | Flatten+Dense | 1,707K | ~41.0% | 参数多但没学好 |
| **CNN 1** | Conv×2 + Dense | **8,409K** | ~62.4% | 无池化→参数爆炸 |
| **CNN 2** | Conv×3 + MaxPool×2 | 1,180K | ~73.5% | MaxPool 缩小尺寸 |
| **CNN 3** | Conv×3 + AvgPool×2 | 1,180K | ~72.8% | AvgPool 略弱于 MaxPool |
| **CNN 4** | Conv×3 + MaxPool×2 + AvgPool×1 | **357K** | **~74.1%** | 三次池化，参数最少，效果最好 |

### 核心结论

```
1. CNN > Dense-only：卷积保留空间结构，效果远好于全连接
2. 池化很重要：CNN1 无池化→840万参数；CNN4 三次池化→36万参数，效果反而更好
3. 参数多 ≠ 效果好：NN(170万参数,41%) vs CNN4(36万参数,74%)
4. MaxPool 略好于 AvgPool：73.5% vs 72.8%，混合使用效果最佳
5. 架构设计 > 堆参数：合理的架构（Conv+Pool）比暴力堆参数更重要
```

## 核心公式速查

| 层类型 | 参数量公式 | 计算方式 |
|---|---|---|
| **Conv2D** | `(核高×核宽×输入通道+1)×filters` | 对应相乘→求和→加偏置，滑动扫描 |
| **Dense** | `(输入维度+1)×输出维度` | 所有输入加权求和+偏置 |
| **MaxPool** | 0 | 每 2×2 取最大值 |
| **AvgPool** | 0 | 每 2×2 取平均值 |
| **Flatten** | 0 | 拉平成一维，只换形状 |
| **Dropout** | 0 | 随机置零，防过拟合 |

> 所有 `+1` 都是偏置 b。
