Question 1 (1 point)
In PCA, which component is chosen first?

Question 1 options:

The one that maximizes variance

The one that best separates classes

The one with the smallest eigenvalue

The one that minimizes within-class variance

> **Answer**: The one that maximizes variance
> **Explanation**:
> - **中文**：在 PCA（主成分分析）中，第一个主成分被定义为数据集中方差最大的方向。
> - **English**: In PCA (Principal Component Analysis), the first principal component is defined as the direction in the dataset that has the maximum variance.

Question 2 (1 point)
Which statement is TRUE?

Question 2 options:

LDA maximizes variance, PCA maximizes separability

PCA works only for two classes

PCA ignores class labels, LDA uses them

PCA uses class labels, LDA does not

> **Answer**: PCA ignores class labels, LDA uses them
> **Explanation**:
> - **中文**：PCA 是一种无监督学习算法，它在不考虑类别标签的情况下寻找方差；而 LDA（线性判别分析）是一种有监督学习算法，它专门利用类别标签来寻找最能区分不同类别的方向。
> - **English**: PCA is an unsupervised learning algorithm that searches for variance without considering class labels, while LDA (Linear Discriminant Analysis) is a supervised learning algorithm that specifically uses class labels to find directions that best distinguish between different classes.
