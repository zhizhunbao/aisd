Question 1 (1 point)
What is the main idea behind Support Vector Machines (SVM)?

Question 1 options:

Reduce dimensionality of data

Find a hyperplane that maximizes the margin between classes

Minimize the number of misclassified points only

Minimize the sum of squared errors

> **Answer**: Find a hyperplane that maximizes the margin between classes
> **Explanation**:
> - **中文**：支持向量机 (SVM) 的基本原理是找到一个决策边界（超平面），使得两个类别之间的几何间隔最大化，从而提高模型的泛化能力。
> - **English**: The fundamental principle of SVM is to find a decision boundary (hyperplane) that maximizes the geometric margin between two classes, thereby improving the model's generalization ability.

Question 2 (1 point)
Which of the following kernels is the most commonly used for non-linear SVM?

Question 2 options:

RBF

Linear

Sigmoid

Polynomial

> **Answer**: RBF
> **Explanation**:
> - **中文**：RBF（径向基函数）核是 SVM 中最流行的核函数，因为它能够将原始特征空间映射到无限维空间，从而处理复杂的非线性关系。
> - **English**: The RBF (Radial Basis Function) kernel is the most popular kernel function in SVM because it can map the original feature space into an infinite-dimensional space, allowing it to handle complex non-linear relationships.
