# Hybrid1 - PCA, LDA Quiz

## Question 1 (1 point)

Which one of the following is a supervised approach?

- [ ] PCA
- [x] LDA
- [ ] Both
- [ ] None

## Question 2 (1 point)

In PCA, the principal components are

- [ ] Original features with lowest variance
- [ ] Eigenvalues of the covariance matrix
- [ ] Original features with highest variance
- [x] Eigenvectors of the covariance matrix

---

## Answer Key & Explanations

1. **LDA**
   - **解析**：LDA（线性判别分析）是有监督学习方法，它利用类别标签来计算类间和类内散度，从而找到最佳投影方向；PCA 则是无监督学习。
2. **Eigenvectors of the covariance matrix**
   - **解析**：在 PCA 中，主成分对应于数据协方差矩阵的特征向量 (Eigenvectors)，特征向量的方向即为数据方差最大的方向。
