## CV 学习路线

1. **传统 CV** - 滤波、边缘检测、特征提取 (SIFT, HOG)
2. **CNN 基础** - LeNet, AlexNet, VGG, ResNet
3. **目标检测** - R-CNN, YOLO, Faster R-CNN
4. **语义分割** - FCN, U-Net, Mask R-CNN
5. **生成模型** - GAN, Diffusion Models
