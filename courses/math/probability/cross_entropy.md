## 1. 信息量 (Information Content / Self-Information)

### 1.1 直觉

> 📚 Ref: Goodfellow §3.13

一个事件的**信息量**衡量它有多"令人惊讶"。

- 必然事件（太阳明天升起）→ 信息量 = 0（不惊讶）
- 稀有事件（中彩票）→ 信息量很大（非常惊讶）

### 1.2 定义

| 符号   | 含义                               |
| ------ | ---------------------------------- |
| $x$    | 一个事件                           |
| $P(x)$ | 事件发生的概率                     |
| $I(x)$ | 事件的信息量（单位：nats 或 bits） |

$$I(x) = -\log P(x)$$

> 📚 Goodfellow Eq. 3.48

- 用自然对数 $\ln$：单位是 **nats**
- 用以 2 为底的对数 $\log_2$：单位是 **bits**

### 1.3 练习

🟢 **基础：** $P(x) = 0.5$ 时，$I(x) = ?$

$$I(x) = -\log(0.5) = \log(2) \approx 0.693 \text{ nats}$$

🟢 **基础：** $P(x) = 1$ 时，$I(x) = ?$

$$I(x) = -\log(1) = 0 \quad \text{（必然事件，零信息量）}$$

🟡 **中等：** $P(x) = 0.01$ 时，$I(x) = ?$

$$I(x) = -\log(0.01) = \log(100) \approx 4.605 \text{ nats}$$

## 2. 熵 (Entropy)

### 2.1 直觉

> 📚 Ref: Goodfellow §3.13

**熵**是一个概率分布的"平均信息量"——衡量这个分布有多"不确定"。

- 均匀分布（每个选项等可能）→ 熵最大（最不确定）
- 确定性分布（某选项概率=1）→ 熵 = 0（完全确定）

### 2.2 定义

| 符号   | 含义           |
| ------ | -------------- |
| $P$    | 概率分布       |
| $H(P)$ | 分布 $P$ 的熵  |
| $C$    | 可能的事件总数 |

$$H(P) = -\sum_{i=1}^{C} P(x_i) \log P(x_i)$$

> 📚 Goodfellow Eq. 3.49

### 2.3 练习

🟢 **基础：** 公平硬币 $P = [0.5, 0.5]$，$H = ?$

$$H = -(0.5 \log 0.5 + 0.5 \log 0.5) = -2 \times 0.5 \times (-0.693) = 0.693 \text{ nats}$$

🟡 **中等：** 不公平硬币 $P = [0.9, 0.1]$，$H = ?$

$$H = -(0.9 \log 0.9 + 0.1 \log 0.1) = -(0.9 \times (-0.105) + 0.1 \times (-2.303)) = 0.325 \text{ nats}$$

比公平硬币的 0.693 小 → 更"确定"的分布有更低的熵。

## 3. 交叉熵 (Cross-Entropy)

### 3.1 直觉

> 📚 Ref: Goodfellow §3.13

**交叉熵**衡量：用分布 $Q$ 来编码实际服从分布 $P$ 的数据，平均需要多少信息。

- 如果 $Q = P$（完美预测），交叉熵 = 熵（最优编码）
- 如果 $Q \neq P$（预测有误），交叉熵 > 熵（额外浪费）

### 3.2 定义

| 符号      | 含义     | 花卉分类中对应                       |
| --------- | -------- | ------------------------------------ |
| $P$       | 真实分布 | one-hot 标签 $[1, 0, 0, ..., 0]$     |
| $Q$       | 预测分布 | Softmax 输出 $[0.8, 0.1, 0.05, ...]$ |
| $H(P, Q)$ | 交叉熵   | 分类损失值                           |

$$H(P, Q) = -\sum_{i=1}^{C} P(x_i) \log Q(x_i)$$

> 📚 Goodfellow §3.13（交叉熵定义）

### 3.3 对 one-hot 标签的化简

在分类任务中，$P$ 是 one-hot 向量，只有正确类别 $c$ 的 $P(x_c) = 1$：

$$H(P, Q) = -\log Q(x_c) = -\log \hat{y}_c$$

> 📐 **推导（tutorial 补充）：** 这就是 PyTorch 的 `CrossEntropyLoss` 计算的值。

### 3.4 练习

🟢 **基础：** 真实类别 = 0，预测 $Q = [0.9, 0.05, 0.05]$，交叉熵 = ？

$$H = -\log(0.9) = 0.105$$

🟢 **基础：** 真实类别 = 0，预测 $Q = [0.3, 0.5, 0.2]$，交叉熵 = ？

$$H = -\log(0.3) = 1.204 \quad \text{（更差的预测 → 更大的损失）}$$

🔴 **挑战：** 证明交叉熵总是 ≥ 熵：$H(P, Q) \geq H(P)$

提示：差值 $H(P,Q) - H(P) = D_{KL}(P \| Q) \geq 0$（KL 散度非负，见 Goodfellow §3.13）

## 4. 交叉熵与分类损失的关系

### 4.1 总结对照

| 概念    | 公式                      | 在分类中的角色                        |
| ------- | ------------------------- | ------------------------------------- |
| 信息量  | $I(x) = -\log P(x)$       | 单个预测对/错的"惊讶程度"             |
| 熵      | $H(P) = -\sum P \log P$   | 理论最优损失（数据本身的不确定性）    |
| 交叉熵  | $H(P,Q) = -\sum P \log Q$ | **实际损失函数**（Assignment 1 使用） |
| KL 散度 | $D_{KL} = H(P,Q) - H(P)$  | 预测比最优差了多少                    |
