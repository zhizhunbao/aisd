## 1. 一维卷积 (1D Convolution)

### 1.1 直觉

> 📚 Ref: Goodfellow §9.1

**卷积**是一个"滑动加权求和"操作：一个小窗口（滤波器/核）在信号上滑动，每到一个位置就和对应区域做内积。

### 1.2 定义

| 符号         | 含义                     |
| ------------ | ------------------------ |
| $x(t)$       | 输入信号                 |
| $w(k)$       | 滤波器 / 卷积核 (kernel) |
| $(x * w)(t)$ | 卷积输出                 |

**连续形式：**

$$
(x * w)(t) = \int_{-\infty}^{\infty} x(\tau) \cdot w(t - \tau) \, d\tau
$$

**离散形式（在 CNN 中使用）：**

$$
(x * w)(t) = \sum_{k} x(t + k) \cdot w(k)
$$

> 📚 Goodfellow Eq. 9.1-9.2（注意：深度学习中通常用互相关代替严格的卷积。区别在于是否翻转 kernel，实际训练中无影响，因为 kernel 是学的。）

### 1.3 练习

🟢 **基础：** 输入 $x = [1, 3, 2, 4]$，kernel $w = [1, 0, -1]$，计算输出

```
位置 0: 1×1 + 3×0 + 2×(-1) = 1 + 0 - 2 = -1
位置 1: 3×1 + 2×0 + 4×(-1) = 3 + 0 - 4 = -1

输出: [-1, -1]   (长度 = 4 - 3 + 1 = 2)
```

## 2. 二维卷积 (2D Convolution for Images)

### 2.1 直觉

在图像上，卷积核是一个小矩阵（如 3×3），在图像上"滑动"并在每个位置计算加权和。

### 2.2 定义

| 符号     | 含义                     | 花卉分类中对应             |
| -------- | ------------------------ | -------------------------- |
| $X$      | 输入图像（或特征图）     | 224×224 的 RGB 图像        |
| $W$      | 卷积核 (kernel / filter) | 3×3 的可学习权重           |
| $Y$      | 输出特征图 (feature map) | 卷积后的结果               |
| $(i, j)$ | 输出位置                 | 特征图的第 $i$ 行第 $j$ 列 |

$$
Y(i, j) = \sum_{m=0}^{F-1} \sum_{n=0}^{F-1} X(i+m, j+n) \cdot W(m, n)
$$

### 2.3 练习

🟢 **基础：** 输入 4×4，kernel 3×3，计算左上角输出值

```
输入 X:               Kernel W:
[1  2  3  0]          [1  0  -1]
[0  1  2  3]          [1  0  -1]
[3  0  1  2]          [1  0  -1]
[2  3  0  1]

Y(0,0) = 1×1 + 2×0 + 3×(-1)
       + 0×1 + 1×0 + 2×(-1)
       + 3×1 + 0×0 + 1×(-1)
       = 1 + 0 - 3 + 0 + 0 - 2 + 3 + 0 - 1
       = -2
```

## 3. 输出尺寸公式

### 3.1 定义

| 符号 | 含义             | 常用值  |
| ---- | ---------------- | ------- |
| $W$  | 输入尺寸         | 224     |
| $F$  | 滤波器尺寸       | 3, 5, 7 |
| $P$  | 零填充 (padding) | 0, 1    |
| $S$  | 步幅 (stride)    | 1, 2    |
| $O$  | 输出尺寸         | —       |

$$
O = \frac{W - F + 2P}{S} + 1
$$

> 📚 Goodfellow §9.5（Eq. 9.8 的简化形式）

### 3.2 特殊情况

| 配置                 | 效果                                |
| -------------------- | ----------------------------------- |
| $P = (F-1)/2, S = 1$ | "same" padding：输出尺寸 = 输入尺寸 |
| $P = 0, S = 1$       | "valid"：输出缩小 $F - 1$           |
| $S = 2$              | 输出尺寸约减半                      |

### 3.3 练习

🟢 **基础：** $W=224, F=3, P=1, S=1$

$$O = \frac{224 - 3 + 2}{1} + 1 = 224 \quad \text{(same padding)}$$

🟢 **基础：** $W=224, F=7, P=3, S=2$

$$O = \frac{224 - 7 + 6}{2} + 1 = \frac{223}{2} + 1 = 112$$

🟡 **中等：** 两层连续卷积：第一层 $W=56, F=3, P=1, S=1$，第二层相同。最终输出？

$$O_1 = \frac{56 - 3 + 2}{1} + 1 = 56$$
$$O_2 = \frac{56 - 3 + 2}{1} + 1 = 56 \quad \text{(same padding 保持尺寸不变)}$$

🔴 **挑战：** ResNet-18 第一层用 $F=7, S=2, P=3$，输入 $W=224$。之后接 $3 \times 3$ MaxPool $S=2, P=1$。最终特征图尺寸？

$$\text{Conv1}: O = \frac{224 - 7 + 6}{2} + 1 = 112$$
$$\text{Pool}: O = \frac{112 - 3 + 2}{2} + 1 = 56$$

## 4. 多通道卷积 (Multi-Channel Convolution)

### 4.1 直觉

RGB 图像有 3 个通道。卷积核也必须是 3 通道的，分别对每个通道卷积后求和。

### 4.2 参数量计算

| 符号      | 含义                       |
| --------- | -------------------------- |
| $C_{in}$  | 输入通道数                 |
| $C_{out}$ | 输出通道数（= 滤波器个数） |
| $F$       | 滤波器空间尺寸             |

$$\text{参数量} = F \times F \times C_{in} \times C_{out} + C_{out}$$

（$+ C_{out}$ 是偏置项，有时省略）

### 4.3 练习

🟢 **基础：** $F=3, C_{in}=3, C_{out}=64$（ResNet-18 第一个卷积层）

$$\text{参数量} = 3 \times 3 \times 3 \times 64 = 1,728 \quad \text{(不含偏置)}$$

🟡 **中等：** 对比标准卷积和深度可分离卷积的参数量（$F=3, C_{in}=64, C_{out}=128$）

$$\text{标准} = 3 \times 3 \times 64 \times 128 = 73,728$$
$$\text{深度可分离} = 3 \times 3 \times 64 + 64 \times 128 = 576 + 8,192 = 8,768$$
$$\text{节省} = 1 - \frac{8,768}{73,728} = 88.1\%$$
