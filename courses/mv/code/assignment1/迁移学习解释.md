## 1. 什么是迁移学习？

迁移学习是一种机器学习技术：把在**大数据集**（如 ImageNet，约 120 万张图片）上预训练好的模型，作为新任务的起点来使用，而不是从随机权重从零开始训练。

核心思想：ImageNet 上学到的**底层视觉特征**（边缘、纹理、角点、形状）是**通用的**，可以迁移到其他视觉任务上——包括花卉分类。

---

## 2. 我的代码中如何使用迁移学习

在我的配置文件中，通过 `init_cfg` 参数加载 **ImageNet 预训练权重**到 backbone 网络：

### ResNet-18（`resnet18_flowers17.py`）

```python
backbone=dict(
    type='ResNet',
    depth=18,
    # 【迁移学习关键】加载 ImageNet 预训练权重
    init_cfg=dict(type='Pretrained', checkpoint='torchvision://resnet18'),
)
```

### MobileNet V2（`mobilenetv2_flowers17.py`）

```python
backbone=dict(
    type='MobileNetV2',
    widen_factor=1.0,
    # 【迁移学习关键】加载 ImageNet 预训练权重
    init_cfg=dict(type='Pretrained',
        checkpoint='https://download.openmmlab.com/mmclassification/v0/mobilenet_v2/...'),
)
```

通过 `init_cfg`，backbone 的权重从 **ImageNet 预训练模型初始化**，然后在 Oxford Flowers 17 数据集上**微调（fine-tune）**。

## 3. 迁移学习工作流程

| 步骤 | 说明 | 细节 |
|------|------|------|
| **1. 下载预训练权重** | 从服务器下载 checkpoint | ResNet-18（~44MB）来自 PyTorch；MobileNet V2（~14MB）来自 OpenMMLab |
| **2. 初始化 backbone** | 将权重加载到模型中 | backbone 从 ImageNet 学到的特征开始，而不是随机值 |
| **3. 在 Flowers 17 上微调** | 在目标数据集上训练 | 所有层都以较小的学习率更新 |

---

## 4. 什么是迁移的 vs 什么是新学的

- **迁移的（来自 ImageNet）：** backbone 权重（ResNet-18 或 MobileNet V2）—— 这些编码了从 120 万张图片中学到的通用视觉特征。

- **从零学习的：** 分类头（`LinearClsHead`）—— 一个新的全连接层，将 backbone 特征（ResNet-18 的 512 维 / MobileNet V2 的 1280 维）映射到 **17 种花卉类别**。这一层必须随机初始化，因为 ImageNet 有 1000 个类，不是 17 个。

- **微调的：** 训练过程中，backbone 和 head 都会被更新。backbone 权重被轻微调整，以更好地表示花卉特有的特征。

---

## 5. 为什么这个任务必须用迁移学习

Flowers 17 数据集非常小（每类约 60 张图，总共约 1000 张）：

| 对比项 | 从零训练 | 迁移学习 |
|--------|---------|---------|
| 初始权重 | 随机初始化 | ImageNet 预训练权重 |
| 特征质量 | 只从约 1000 张图学习 | 复用 120 万张图学到的丰富特征 |
| 收敛速度 | 慢 | 快 |
| 过拟合风险 | 高 | 较低 |
| 预期准确率 | 较低 | 较高 |

## 6. 支持迁移学习的相关设计选择

**使用 ImageNet 归一化参数：**
```python
data_preprocessor = dict(
    mean=[123.675, 116.28, 103.53],  # ImageNet 的 RGB 均值
    std=[58.395, 57.12, 57.375],     # ImageNet 的 RGB 标准差
)
```
必须使用 ImageNet 的统计值（不是 Flowers 17 自己的），因为预训练权重是在这个输入分布下训练的。

**较小的学习率：**
- ResNet-18：`lr=0.01`（比 ImageNet 标准的 0.1 小 10 倍）
- MobileNet V2：`lr=0.001`

较小的学习率防止预训练特征在小数据集上微调时被破坏。

**数据增强：**
`RandomResizedCrop` 和 `RandomFlip` 有助于防止过拟合，与迁移学习的正则化效果互补。
