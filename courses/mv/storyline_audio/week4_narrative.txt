上一讲我们学习了 SIFT、SURF、ORB 这些特征检测算法，它们能提取图像的独特指纹。
但这些方法有一个共同的问题，特征都是人类手动设计的。
SIFT 的设计者决定用高斯差分来检测关键点，HOG 的设计者决定用梯度直方图来描述人体。
如果换一个任务，比如识别猫和狗，可能就需要重新设计特征。

所以核心问题来了，能不能让机器自动学会应该关注图像的哪些特征？
打个比方，手工特征就像老师画好了重点让学生背。
而我们接下来要学的方法，是给机器一堆真题，让它自己发现什么是重点。
这个方法就是 CNN，全称 Convolutional Neural Network，也就是卷积神经网络。

在讲 CNN 之前，我们先看看为什么传统的神经网络不行。
ANN 全称 Artificial Neural Network，也就是人工神经网络。
ANN 受人脑结构的启发，由互连的神经元组成，通过分析数据来学习模式。
ANN 处理图像的方式是，先把图像展平成一维向量，然后送入隐藏层处理，最后输出类别。

但这种方式有几个致命问题。
第一个问题是参数爆炸。一张 1000 乘以 1000 的彩色图像，输入层就有三百万个神经元，仅第一个隐藏层就需要数十亿个权重。
第二个问题是 Overfitting 过拟合，参数远多于训练样本，网络记住了噪声而不是真正的模式。
第三个问题是训练时间太长。
第四个也是最根本的问题，ANN 把图像展平成一维向量之后，相邻像素的空间关系就完全丢失了。
哪些像素挨在一起、哪些像素构成一条边缘，这些信息全都没了。

所以我们需要一种新的架构，既能保留图像的空间结构，又能大幅减少参数量。
这就是 CNN 卷积神经网络诞生的原因。

CNN 是一种专门为图像处理设计的 Deep Learning 深度学习架构。
它有三大核心优势。
第一，能处理图像、视频、音频这类高维结构化数据。
第二，能进行 Hierarchical Feature Learning 层次化特征学习，浅层学边缘，深层学语义。
第三，具有 Translation Invariance 平移不变性，猫在图像左边还是右边，都能识别。

CNN 的架构由三大核心组件构成。
第一个是 Convolutional Layer 卷积层，负责从图像中提取空间特征。
第二个是 Pooling Layer 池化层，负责降低维度、减少计算量。
第三个是 Fully Connected Layer 全连接层，负责整合特征进行最终分类。

我们先来深入了解最重要的卷积层。
卷积层的工作方式是这样的。
一个小的 Filter 滤波器，也叫 Kernel 卷积核，比如 3 乘以 3 的大小，在图像上逐步滑动。
在每个位置，滤波器与图像对应区域做逐元素乘法再求和。
输出的结果就形成了一个新的 Feature Map 特征图。

这里有一个关键理解。
不同的滤波器检测不同的特征。某个滤波器专门检测垂直边缘，某个专门检测水平线条，某个专门检测角点。
而且这些滤波器的值不是人工设计的，而是网络自动从数据中学习到的。
这就是 CNN 和手工特征最本质的区别。

卷积层为什么能解决 ANN 的问题呢？
第一，Parameter Sharing 参数共享。一个 3 乘以 3 的滤波器只有 9 个参数，但它在整张图像上共用，大幅减少了参数量。
第二，Local Connectivity 局部连接。每个输出只看输入的一小块局部区域，保留了空间结构。
第三，平移不变性。同一个滤波器扫描全图，无论物体出现在哪个位置都能检测到。

卷积层有三个关键的 Hyperparameter 超参数。
第一个是 Filter Size 滤波器大小，用字母 F 表示。小的滤波器捕获精细特征，大的滤波器识别宏观模式。
第二个是 Stride 步幅，用字母 S 表示，就是滤波器每次移动的步长。步幅越大，输出越小、越抽象。
第三个是 Padding 填充，用字母 P 表示，就是在输入图像的边界周围补零，用来保留边缘信息和控制输出尺寸。

这里有一个必考的公式。
输出尺寸等于 N 减 F 加 2P 除以 S 再加 1。
其中 N 是输入图像大小，F 是滤波器大小，P 是填充量，S 是步幅。
举个例子，输入 112 乘以 112，滤波器 3 乘以 3，填充为 0，步幅为 2。
代入公式，112 减 3 加 0 除以 2 加 1 等于 55。所以输出尺寸是 55 乘以 55。

讲完了卷积层，我们来看第二个组件，Pooling Layer 池化层。
卷积层输出的特征图可能仍然很大，需要通过 Down-sampling 下采样来减小尺寸。

池化有两种常见方式。
第一种是 Max Pooling 最大池化，取区域内的最大值。
第二种是 Average Pooling 平均池化，取区域内的平均值。
最大池化更常用，因为它保留了最显著的特征，也就是最强的激活。
每次 2 乘以 2 的池化操作会将特征图尺寸减半。

池化之后，特征图需要通过 Flattening 展平操作，把多维数组转换成一维向量。
比如一个 7 乘以 7 乘以 64 的特征图，展平后变成 3136 维的向量。
然后这个向量被送入 Fully Connected Layer 全连接层。

全连接层的运算公式是 output 等于 W 乘以 input 加上 b。
其中 W 是 Weight Matrix 权重矩阵，b 是 Bias Vector 偏置向量。
W 和 b 都是网络的 Learnable Parameters 可学习参数，通过训练不断调整。

全连接层还需要 Activation Function 激活函数来引入非线性。
如果没有激活函数，多层线性变换加在一起等价于一层，就无法学习复杂模式。
最常用的激活函数是 ReLU，全称 Rectified Linear Unit，规则是负值变成零，正值保持不变。

最后一层叫 Output Layer 输出层，使用 Softmax 激活函数。
Softmax 把原始分数转换成 Probability Distribution 概率分布，所有类别的概率加起来等于 1。
概率最高的那个类别就是最终的预测结果。
输出层的神经元数量等于类别数。

CNN 建好了结构，还需要训练才能工作。
训练的核心机制叫 Back Propagation 反向传播。
反向传播是一种 Supervised Learning 监督学习算法，只在训练时发生。
它的基本流程是，先前向传播得到预测结果，然后计算预测与真实标签之间的损失，再从输出层往回计算每个权重应该怎么调整，最后更新权重。
这个过程不断重复，直到损失足够小。

讲完了 CNN 的架构和训练，我们来看如何评估模型的表现。
评估分类模型最基础的工具是 Confusion Matrix 混淆矩阵。
混淆矩阵是一个 2 乘以 2 的表格，横轴是预测值，纵轴是实际值。
其中有四个格子。
TP 也就是 True Positive 真正例，表示预测为正且实际也为正，预测正确。
TN 也就是 True Negative 真反例，表示预测为负且实际也为负，也是正确的。
FP 也就是 False Positive 假正例，表示预测为正但实际为负，这是误报。
FN 也就是 False Negative 假反例，表示预测为负但实际为正，这是漏报。

基于混淆矩阵，我们可以计算四个评估指标。
Accuracy 准确率，等于 TP 加 TN 除以总数，衡量整体正确率。
Precision 精确率，等于 TP 除以 TP 加 FP，衡量预测为正的里面有多少是真正的正例。
Recall 召回率，等于 TP 除以 TP 加 FN，衡量实际为正的里面有多少被找到了。
F1 Score 等于 2 乘以精确率乘以召回率除以精确率加召回率，是精确率和召回率的调和平均。

还有一个常见的评估工具是 ROC Curve，全称 Receiver Operating Characteristic 接收者操作特征曲线。
它画的是 True Positive Rate 真正例率和 False Positive Rate 假正例率之间的关系。
ROC 曲线下的面积叫 AUC，AUC 越接近 1 说明模型越好，等于 0.5 则和随机猜测一样。
