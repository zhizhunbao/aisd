想象你走进一家工厂，流水线上每秒经过一百个零件。
你需要检查每一个零件是否有缺陷，比如裂纹、缺角，或者是颜色不均。
在这个过程中，人眼会累、会漏检，还会因为光线的变化而产生误判。

所以我们的核心问题是：能不能让机器代替人眼来看，而且看得更快、更准、更持久？
这个问题，就是机器视觉这门课要回答的。

机器视觉，英文叫 Machine Vision，字面意思就是让机器拥有视觉能力。
用一句话来定义，它就是让机器具备从采集图像，到处理图像，再到做出决策的完整能力。

说到这里，有一个概念上的区别，在考试里非常容易踩坑，那就是 Machine Vision 和 Computer Vision 的差别。
Computer Vision 翻译过来叫计算机视觉。
Machine Vision 是一套完整的系统，包含了相机、传感器、机械臂这些硬件，再加上软件算法和最终的决策输出。
而 Computer Vision 只关注图像理解的算法本身，并不涉及硬件。
打个比方，Machine Vision 就像是一辆完整的自动驾驶汽车，而 Computer Vision 仅仅是那套让汽车能看见路的眼睛算法。
我们这门课虽然叫 Machine Vision，但重点学习的还是 Computer Vision 的核心算法。

弄清楚了是什么，我们来看看机器视觉是怎么工作的。
整个流程分为标准的三步。
第一步是 Image Acquisition，也就是图像采集，意思是用摄像头或传感器把现实世界的画面变成数字图像。
第二步是 Image Processing，也就是图像处理，意思是用算法从图像里提取我们需要的特征信息。
第三步是 Interpretation 或者叫 Action，也就是解读和行动，意思是根据提取到的信息做出最终决策，比如判断零件是否合格。
这三步，构成了机器视觉最基本的工作骨架。

了解了工作流程，我们再往前推一步，看看机器视觉是怎么一步步发展到今天的。
它的历史大致经历了三个阶段。
从六十年代到九十年代是硬件时代，数码相机以及 CCD 和 CMOS 这两种图像传感器逐渐普及，实现了图像的数字化，这是一切的起点。
到了 1999 年至 2012 年，进入了算法时代。
这个阶段，人们主要靠手工设计特征提取算法。
比如著名的 SIFT，全称是 Scale-Invariant Feature Transform，也就是尺度不变特征变换。
它的核心能力是，在图像缩放和旋转的情况下仍然识别出同一个特征点。
还有 HOG，全称是 Histogram of Oriented Gradients，也就是方向梯度直方图。
它通过统计图像中像素梯度的方向分布来描述物体形状。
而 2012 年之后，我们进入了 Deep Learning 深度学习时代，Neural Network 神经网络开始能够自动从数据中学习特征，不再需要人类手工设计。

2012 年，有一个历史转折点，也是一个高频考点，那就是 AlexNet 模型。
AlexNet 是由 Alex Krizhevsky 等人设计的一个深度卷积神经网络。
它在 ImageNet 大赛中以碾压性的优势获胜。
ImageNet 是一个包含超过百万张标注图像的大型数据集，专门用来测试图像识别算法的能力。

AlexNet 的胜出，证明了 CNN 也就是卷积神经网络，全称 Convolutional Neural Network，这类网络能够自动学习图像特征，比人类手工设计的更通用、更强大。
但需要注意的是，深度学习并没有彻底取代传统方法。
在工业检测这类受控环境里，传统方法依然被广泛使用。
比如 Template Matching 模板匹配，也就是用一张标准图像去比对待检图像。
还有 Thresholding 阈值化，也就是按像素亮度把图像分成黑白两类。
这些方法速度快、成本低、结果容易解释，在受控场景下优势明显。

讲完了历史，我们来拆解一下机器视觉系统里的关键技术三件套。
首先是图像传感器，它相当于机器的视网膜，负责把光线转换成数字信号。
市面上两种主流传感器的优缺点非常容易考到。
第一种是 CCD，全称 Charge-Coupled Device，也就是电荷耦合器件，它的图像质量高、噪点低，但缺点是既费电又昂贵。
第二种是 CMOS，全称 Complementary Metal-Oxide Semiconductor，也就是互补金属氧化物半导体，它的核心优势是功耗低、制造成本便宜，所以已经主导了如今手机和消费级相机的市场。

有了传感器采集图像，接下来就需要图像处理技术，这相当于机器的视觉皮层，负责对图像进行理解和分析。
比如用 Filtering 也就是滤波技术来降噪和平滑图像，让画面更清晰。
或者用 Edge Detection 也就是边缘检测来找到物体的轮廓，边缘检测通过寻找像素亮度急剧变化的地方来确定物体的边界。
处理完的图像，最后会交给 Machine Learning 机器学习或 Deep Learning 深度学习算法，来完成 Classification 分类，也就是判断图像属于哪一类，或者 Detection 检测，也就是在图像中找到并定位特定物体。

机器视觉如今已经无处不在。
在零售业可以做条码扫描。
在制造业可以做缺陷检测。
在影视娱乐中可以做 Object Tracking 也就是物体追踪，让摄像机自动跟拍移动中的演员。
在自动驾驶里，更是可以做 Semantic Segmentation 语义分割，也就是把图像中每一个像素都归类到它所属的物体类别。
还有 Depth Estimation 深度估计，也就是从图像中推断出各个物体离摄像头有多远。

好，在我们深入算法之前，有几个图像处理的基础概念必须先打好，这里面藏着好几个必考点。
首先是 Pixel 也就是像素，像素是图像中特定位置的一个数值，是构成图像的最小单元。
在 Grayscale 灰度图里，每个像素只有一个从 0 到 255 的值，0 代表纯黑，255 代表纯白。
而彩色图的每个像素则有 Red 红色、Green 绿色、Blue 蓝色三个通道的值，这就是我们常说的 RGB 色彩空间。

除了 RGB，我们还经常用 HSV 色彩空间。
HSV 把颜色的三个维度分开来表示，分别是 Hue 色相，也就是颜色本身是红是蓝还是绿，Saturation 饱和度，也就是颜色有多鲜艳，以及 Value 明度，也就是颜色有多亮。
这里有一个考点：为什么 HSV 更适合颜色检测？
因为它把色相独立出来了，不受光照变化的影响。
比如在不同光线下寻找一个红苹果，它的 RGB 值可能会随着光线变来变去，但它的 Hue 色相值却基本保持不变。

说到这里，还要特别留意两个关于 OpenCV 的期末高频易错点。
OpenCV 全称 Open Source Computer Vision Library，是一个专门用于图像处理的开源编程库。
第一个易错点是，OpenCV 读取彩色图像时，默认格式不是 RGB，而是 BGR，也就是蓝色、绿色、红色的顺序，和我们直觉相反。
第二个易错点是，OpenCV 访问像素时坐标的顺序是先写 y 也就是行，再写 x 也就是列，和我们数学坐标系里先写 x 后写 y 的习惯是相反的。
这两点是 OpenCV 里最容易翻车的地方。

最后简单提一下常见的图像格式。
JPEG 是有损压缩格式，Lossy Compression 的意思是压缩时会丢弃一部分图像细节来换取更小的文件体积，适合存储照片。
PNG 是无损压缩格式，Lossless Compression 的意思是压缩后图像质量不会下降，并且支持透明通道。
而 RAW 是未经任何压缩处理的原始图像数据，保留了传感器捕获的全部信息，主要用于专业摄影。
