上一讲我们了解了机器视觉的三步走，采集、处理、决策。
今天我们聚焦第二步，也就是 Image Processing 图像处理。

为什么图像处理这么重要？
因为摄像头采集到的原始图像往往是脏的。
光线不均匀会导致明暗不一，传感器噪声会让图像变得模糊，前景和背景混在一起难以分离。
Image Processing 图像处理，就是机器视觉的构建基石。
它的核心任务是操作和分析图像，增强图像质量并提取有意义的信息。
打个比方，图像处理就像淘金，原始图像是沙砾混杂的河床，我们需要用各种工具把金子从沙子中分离出来。

在正式进入具体技术之前，我们先来看一下图像处理的九阶段全景图。
第一阶段是 Acquisition 采集，用摄像头或传感器获取原始图像。
第二阶段是 Enhancement 增强，通过调整对比度和亮度来改善图像质量。
第三阶段是 Restoration 复原，利用数学模型去除退化和噪声。
第四阶段是 Morphological Processing 形态学处理，基于形状来提取图像组件。
第五阶段是 Segmentation 分割，把图像划分为有意义的区域或对象，这是最困难的任务之一。
第六阶段是 Object Recognition 目标识别，根据描述给物体贴标签。
第七阶段是 Representation and Description 表示与描述，将数据转换为适合处理的形式。
第八阶段是 Image Compression 图像压缩，减少存储空间。
第九阶段是 Color Image Processing 彩色图像处理，利用颜色信息提取数据。

这里有一个重要的考点，不是每个任务都需要全部九步。
根据应用场景，通常只需要两到三步的组合就足够了。

好，了解了全景图，我们来逐一学习最核心的几种技术。
首先是 Filtering，也就是滤波。
滤波是一种通过改变像素来操作或增强图像的技术。
滤波器就像筛子一样，原始图像通过它之后，好的信息可以通过，噪声则被挡住。

滤波分为两个大方向。
第一个方向是 Blurring 模糊，用来降噪。
模糊通过对目标像素周围的邻域像素取平均值来工作，平滑掉急剧的强度变化。
常见的模糊方法有三种。
第一种是 Average Blurring 均值模糊，对邻域内所有像素等权取平均，简单但会模糊边缘。
第二种是 Gaussian Blurring 高斯模糊，按高斯分布也就是钟形曲线来分配权重，中心像素权重大、周边像素权重小，保边效果比均值模糊好，是多数场景的首选。
第三种是 Median Blurring 中值模糊，取邻域像素的中值而不是均值，对椒盐噪声特别有效。

这里有两个考试陷阱要注意。
第一，高斯模糊的核不是等权的，它按钟形分布分配权重，中心高、周边低。等权的是均值模糊。
第二，中值滤波取的是中值不是均值，名字里虽然都有一个值字，但计算方式完全不同。

第二个方向是 Sharpening 锐化。
锐化和模糊相反，它增大相邻像素之间的对比度，使边缘更清晰、细节更突出。
锐化在医学影像和精密制造这类细节至关重要的场景下非常有用。
但有一个考试陷阱，锐化会放大噪声而不是减少噪声。
所以实际使用中，通常先用模糊去噪，再适度锐化恢复细节。

讲完了滤波，我们来看图像处理中最经典的一个算法，Canny Edge Detection，也就是 Canny 边缘检测。
Edge Detection 边缘检测的目标是找到像素强度急剧变化的地方，因为那些地方通常就是物体的轮廓。
Canny 算法因为精度高、效果好，是最常用的边缘检测方法。

Canny 算法一共分为五个步骤。
第一步是 Gaussian Smoothing 高斯平滑，用高斯滤波器先对图像降噪，因为如果不降噪，噪声点会被误认为是边缘。
第二步是 Gradient Calculation 梯度计算，用 Sobel Kernel 也就是 Sobel 核分别在水平和垂直方向上计算每个像素的梯度幅值和梯度方向。
梯度幅值告诉我们变化有多大，梯度方向告诉我们变化朝哪个方向。

第三步是 Non-Maximum Suppression，缩写为 NMS，中文叫非极大值抑制。
Sobel 计算出来的边缘往往是好几个像素宽的粗线条。
NMS 的作用是沿着梯度方向只保留局部最大值的像素，把其余的设为零，从而将粗边缘细化为一个像素宽的精确线条。

第四步是 Double Thresholding 双阈值。
算法设置两个阈值，一个高阈值和一个低阈值。
梯度大于等于高阈值的像素被归为 Strong Edge 强边缘。
梯度在高阈值和低阈值之间的被归为 Weak Edge 弱边缘。
梯度低于低阈值的被归为 Non-Edge 非边缘，直接丢弃。

第五步是 Hysteresis Edge Tracking 滞后边缘跟踪。
弱边缘如果连接着强边缘就保留，因为它是真实边缘的一部分。
弱边缘如果是孤立的，周围没有强边缘，就丢弃，因为它只是噪声。

这五步可以用一个口诀来记忆，高梯非双滞。
高斯平滑、梯度计算、非极大值抑制、双阈值、滞后跟踪。

讲完了边缘检测，我们来认识一个图像分析的基础工具，Histogram 直方图。
直方图就像是图像的体检报告。
它的横轴是亮度级别，从 0 到 255，0 代表黑色，255 代表白色。
纵轴是每个亮度级别对应多少个像素。
通过直方图我们可以快速判断图像的整体特点。
分布偏左说明图像整体偏暗，分布偏右说明整体偏亮，分布均匀展开说明对比度好，集中在窄范围说明对比度低。

直方图还有一个概念叫 Bins 分箱。
默认情况下 0 到 255 一共有 256 个 bin，每个亮度值一个。
但我们也可以将范围分成更少的区间来简化分析，比如分成 16 个 bin。

了解了直方图之后，我们来看另一个非常实用的技术，Thresholding 阈值化。
阈值化是一种简单而有效的 Segmentation 图像分割方法。
它通过设定一个阈值，把图像中的每个像素分成两类，高于阈值的设为白色代表前景，低于阈值的设为黑色代表背景，从而得到一张二值图。

阈值化分为两种。
第一种是 Simple Thresholding 简单阈值，对整张图像的所有像素使用同一个全局阈值。
优点是简单快速，但缺点是当图像光照不均匀时效果很差。
第二种是 Adaptive Thresholding 自适应阈值，它根据每个像素周围的局部邻域来计算各自的阈值。
这样同一张图像的不同区域会有不同的阈值，可以有效处理光照变化。
这也是一个考点，简单阈值在理想光照下没问题，但现实世界图像往往左边亮右边暗，一个全局阈值无法同时处理两边，这时就需要自适应阈值。

阈值化之后得到的二值图像往往还有小缺陷，比如有些小白噪声点，或者物体内部有小黑洞。
这时候就需要 Morphological Operations 形态学操作来修复。
形态学操作是基于形状来处理图像的一组方法。

形态学有四种基本操作。
第一种是 Erosion 腐蚀。
腐蚀的规则是，核下所有像素都为 1 时才输出 1，否则输出 0。
效果是缩小白色区域，可以用来去除小白噪声或分离两个粘连在一起的物体。
第二种是 Dilation 膨胀。
膨胀和腐蚀相反，核下只要有至少一个像素为 1 就输出 1。
效果是扩大白色区域，可以用来连接断裂的部分或填充缺口。

第三种是 Opening 开运算，也就是先腐蚀再膨胀。
它的原理是，腐蚀先把小白噪声消除掉，但同时也缩小了目标物体。
然后膨胀把物体恢复回来，而被腐蚀掉的噪声不会再回来，因为它们已经被彻底消除了。
第四种是 Closing 闭运算，也就是先膨胀再腐蚀。
膨胀先把物体内部的小黑洞填上，然后腐蚀把整体形状恢复回来。

记忆技巧是，开运算先腐后膨去噪声，闭运算先膨后腐填黑洞。

最后，我们来看图像变换技术。
最重要的是 Affine Transformation 仿射变换。
它的公式是 y 等于 A 乘以 x 加上 b。
其中 x 是输入坐标向量，A 是线性变换矩阵，负责旋转、缩放和剪切，b 是平移向量，y 是变换后的输出坐标。
仿射变换的关键性质是，变换之后直线仍然是直线，平行线仍然平行。

仿射变换包含四种常见类型。
Translation 平移，在水平或垂直方向移动图像。
Rotation 旋转，围绕指定点旋转图像。
Scaling 缩放，改变图像的大小。
Shearing 剪切，沿轴方向倾斜图像。

好，Week 2 的内容就梳理到这里。
我们从一张脏的原始图像出发，先用滤波技术降噪和增强细节，再用 Canny 边缘检测找到物体轮廓，接着用直方图分析图像亮度分布，然后用阈值化把图像变成黑白二值图，再用形态学操作修复二值图的小缺陷，最后用仿射变换校正图像的几何形状。
这一整套技术就是图像从脏到干净的完整清洗流程。
