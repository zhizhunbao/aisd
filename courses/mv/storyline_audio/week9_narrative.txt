上一讲我们学习了目标检测，能在一张图里找到多个物体并框住它们。
但检测只能处理单帧图像。
想象你是一名监控室操作员，屏幕上有一条拥挤的商业街，数百人在走动。
你的任务不仅是看到每个人，还要记住每个人是谁，给每人贴一个编号。
即使某个人被一棵大树暂时挡住，树后面走出来时你仍然知道那还是同一个人。
而且这一切必须实时完成。
这就是 Object Tracking 目标跟踪要解决的核心问题。
一句话区分，目标检测是在单张图中找到目标，目标跟踪是在连续帧中盯住目标不丢。

目标跟踪的本质是三步流水线。
第一步是 Detection 检测，在每帧中用包围框找到物体。
第二步是 ID Assignment 编号，给每个检测到的物体分配唯一标识。
第三步是 Cross-frame Association 跨帧关联，把前一帧的编号和当前帧的检测结果匹配起来。
就像老师在课堂上点名，先看到有几个学生，再记住谁是谁，学生换了座位后还能认出来。

目标跟踪的概念其实很早就有了。
早在二战中，雷达就在做类似的事情，探测敌方飞机的位置，并在多个时间点上连续追踪它们的飞行轨迹。
雷达跟踪和今天的视频跟踪面临同样的困难，目标会消失，目标的外观会变化，有多个目标需要同时管理。

那为什么仅有检测是不够的呢？
来看一个具体场景。一个行人 A 走到一棵大树后面，暂时消失了 3 帧，然后从另一侧走出来。
纯检测系统会认为，前 3 帧有人，中间 3 帧没人，后面又有人，完全不知道前后是同一个人。
跟踪系统则不同，即使中间 3 帧看不到 A，也能根据运动预测 A 的位置，当 A 重新出现时自动匹配。

单帧检测无法维持身份、无法处理遮挡，所以我们需要跨帧关联的机制。

目标跟踪为什么实现起来这么难？有五大核心挑战。
第一是 Rapid Movement 快速运动，物体移动过快导致帧间位移过大，前后帧无法关联。
第二是尺度和形状变化，物体远近变化导致包围框大小剧变。
第三是 Occlusion 遮挡，物体被其他物体或障碍物部分或完全遮挡。
第四是光照变化，日夜交替和阴影导致物体外观剧变。
第五是实时性要求，视频通常 25 到 60 帧每秒，处理延迟必须极低。

如果只追踪一个物体就已经很难了，那同时追踪多个物体呢？
这引出了 SOT 和 MOT 的区分。
SOT，全称 Single Object Tracking 单目标跟踪，只关注一个目标。
MOT，全称 Multiple Object Tracking 多目标跟踪，把 SOT 的所有问题乘以 N，还加了新问题。
多个物体外观相似如何区分，物体互相遮挡如何处理，目标数量动态变化如何管理。
还有 ID Switch 身份切换的问题，两个外观相似的物体交错通过后，系统可能把编号搞混。

传统手工方法能应付简单场景，但面对现实世界的复杂性明显力不从心。
早期跟踪依赖三大传统技术。
Background Subtraction 背景减除，用固定背景减去当前帧提取运动前景，但背景变化时失效。
Optical Flow 光流法，计算像素点的运动方向和速度，但计算量大对光照敏感。
Frame Differencing 帧差分，比较相邻帧的差异检测运动，但无法区分不同物体。
它们的共同致命缺陷是使用手工设计的特征和简单的运动模型，在复杂动态环境中全面崩溃。

深度学习彻底改变了 MOT 的三大核心能力。
特征提取方面，从手工设计变为 CNN 自动学习，场景自适应。
目标识别方面，从简单模板匹配变为从数据中学习鲁棒表示。
运动预测方面，从线性模型变为非线性模型，能处理复杂运动。

深度学习解决了特征提取问题，但怎么组织检测加跟踪的流水线还有不同选择。
这引出了单阶段和双阶段架构之争。

Single-Stage 单阶段跟踪器，检测和跟踪合一，单次网络前向传播完成。
速度快但遮挡处理较弱，代表算法是 DeepSORT。
Two-Stage 双阶段跟踪器，先检测再关联，分两步进行。
速度较慢但精度高，尤其在拥挤场景下表现优异，代表算法是 ByteTrack 和 OCSort。

双阶段跟踪器的第一阶段用 CNN 检测器逐帧检测物体，比如 YOLO 或 Faster R-CNN。
第二阶段用关联算法在帧间匹配检测结果。
关联算法有三种。
Hungarian Algorithm 匈牙利算法，做最优二部图匹配，把当前帧的检测框和已有轨迹一一配对。
Kalman Filter 卡尔曼滤波，基于历史轨迹预测下一帧的位置。
IoU Matching 交并比匹配，用当前检测框和预测位置的空间重叠度来关联。

双阶段架构的思路很清楚，但传统实现有一个盲点。
它们只关联高置信度检测框，低置信度的检测直接丢弃。
可是被遮挡的物体恰恰会产生低置信度检测。
ByteTrack 的创新就是解决这个问题。

ByteTrack 的核心洞察是，被遮挡的物体虽然检测置信度低，但不应该被丢弃。
它们是维持跟踪连续性的关键线索。
传统做法是，检测结果过滤掉置信度低于阈值的，只用高置信度做关联。
ByteTrack 的做法是，把检测结果分成高置信度和低置信度两组，两组都参与关联。

ByteTrack 的数据关联分为两个阶段。
第一阶段是高置信度匹配，取置信度高的检测框与已有轨迹进行匹配。
第二阶段是低置信度恢复，取剩余的低置信度检测框与未匹配的轨迹进行二次匹配。
关键作用是恢复那些因遮挡而置信度下降的真实物体。
ByteTrack 还使用 Gating Mechanism 门控机制过滤冗余检测，防止同一物体被重复跟踪。

ByteTrack 的核心创新用一句话概括就是，不要浪费任何一个检测框，哪怕置信度低，也可能是被遮挡的真实目标。

目标跟踪有四大应用领域。
城市交通中的车辆和行人跟踪，零售场景的顾客行为分析，体育领域的球员运动追踪，安防监控中的异常行为检测。

评估多目标跟踪的指标有三个。
MOTA，全称 Multiple Object Tracking Accuracy，综合衡量漏检、误检和 ID 切换。
MOTP，全称 Multiple Object Tracking Precision，衡量预测框与真值框的重叠度。
IoU 衡量单次检测的空间重叠度。
