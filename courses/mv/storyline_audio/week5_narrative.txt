上一讲我们搭好了 CNN 的骨架，卷积层、池化层、全连接层。
但骨架只是骨架，要让 CNN 真正能识别猫和狗，还需要解决一系列训练问题。
数据怎么准备？激活函数用哪个？损失函数怎么选？怎么让模型一步步变准？模型背题了怎么办？
这一讲的核心问题是，如何把一个随机初始化的 CNN 训练成准确率 90% 以上的图像分类器。

首先是数据准备，巧妇难为无米之炊。
训练 CNN 之前，必须把数据分成三份。
第一份是 Training Set 训练集，大约占 70%，模型从中学习参数。
第二份是 Validation Set 验证集，大约占 15%，用来调优超参数，监控过拟合。
第三份是 Test Set 测试集，也占 15%，是最终评估用的，训练过程中完全不可见。

为什么要分三份呢？
如果用同一份数据训练和评估，模型可能只是背答案，在新数据上一塌糊涂。
验证集帮你在训练过程中发现问题，测试集给出最终的高考成绩。

数据在输入 CNN 之前还要做预处理。
第一步是统一尺寸，因为 CNN 需要固定的输入尺寸，比如全部调整为 128 乘以 128。
第二步是 Normalization 归一化，把像素值从 0 到 255 缩放到 0 到 1 之间，加速收敛、提高稳定性。
第三步是选择合适的色彩空间，根据任务选择 RGB 彩色或灰度图。

如果数据不够怎么办？可以用 Data Augmentation 数据增强来便宜地扩大数据集。
常用的变换包括随机翻转、随机旋转、随机缩放和随机裁剪。
这里有一个关键考点，数据增强只应用于训练集，不应用于验证集和测试集。
验证集需要保持确定性以准确评估模型。

弄清楚了数据准备，我们来看激活函数。
如果没有激活函数，多层神经网络的效果等同于一层。
因为多个线性变换的组合仍然是线性变换。
激活函数的作用就是引入非线性，让网络能学习复杂的模式。

三大激活函数各有特点。
第一个是 Sigmoid 函数，输出范围在 0 到 1 之间，可以解释为概率。
但它有一个致命缺陷叫 Vanishing Gradient 梯度消失，输出也不是零中心的。
第二个是 Tanh 函数，全称 Hyperbolic Tangent，输出范围在负 1 到正 1 之间。
它的优点是零中心，但同样存在梯度消失问题。
第三个是 ReLU，全称 Rectified Linear Unit，也就是修正线性单元。
ReLU 的规则很简单，负值变成零，正值保持不变。

什么是梯度消失呢？
当 Sigmoid 或 Tanh 的输入值很大或很小时，导数趋近于零。
反向传播时梯度几乎为零，浅层的权重几乎不更新，网络学习极慢。
举个例子，x 等于 10 时，Sigmoid 的输出约等于 0.9999，导数约等于 0.0001，梯度几乎消失了。

ReLU 为什么是首选呢？
第一，正区间导数恒为 1，梯度不会缩小，缓解了梯度消失。
第二，负值变成零，产生稀疏激活，有助于减少过拟合。
第三，只需判断大于零，比计算指数函数快得多。
使用建议是，隐藏层几乎总是用 ReLU。
二分类输出层用 Sigmoid，输出概率。
多分类输出层用 Softmax，输出概率分布。

讲完了激活函数，我们来看损失函数。
Loss Function 损失函数衡量模型预测与真实标签之间的差距，是训练的指南针。

有三大常用损失函数。
第一个是 MSE，全称 Mean Squared Error，也就是均方误差，用于回归任务。
它计算的是预测值和真实值之间差值的平方的平均。
第二个是 BCE，全称 Binary Cross-Entropy，也就是二元交叉熵，用于二分类。
它通过重度惩罚自信的错误预测来指导分类。
第三个是 CCE，全称 Categorical Cross-Entropy，也就是分类交叉熵，用于多分类。
因为 y 是 one-hot 编码，只有真实类别对应的 y 等于 1。
所以 CCE 简化为负的 log 预测概率，模型对正确类别预测概率越高，损失越低。

如何选择损失函数呢？
回归任务用 MSE，输出层不加激活。
二分类用 BCE，输出层用 Sigmoid。
多分类用 CCE，输出层用 Softmax。

好，选好了损失函数，下一个问题是怎么让损失越来越小。
这就要用到 Gradient Descent 梯度下降和 Back Propagation 反向传播。

梯度下降的直觉是这样的。
想象你蒙着眼睛在山上，要走到谷底也就是损失最低点。
第一步，感受脚下的坡度，也就是计算梯度。
第二步，朝下坡方向迈一步，也就是更新权重。
第三步，重复直到到达谷底。

权重更新的公式是，w 新等于 w 旧减去 eta 乘以损失对权重的梯度。
其中 eta 就是 Learning Rate 学习率，控制每一步走多大。
学习率太大会跳过最佳点来回震荡，太小则收敛速度极慢。

反向传播有六个步骤。
第一步，前向传播，将样本输入网络得到预测。
第二步，计算损失，比较预测与真实标签。
第三步，计算输出层误差。
第四步，反向传播误差，从输出层往前逐层计算隐藏层的梯度。
第五步，应用 Delta 规则，按梯度方向计算每个权重应该怎么调整。
第六步，更新权重。
这里有一个关键考点，反向传播仅在训练时执行，推理时只做前向传播。

讲完了梯度下降，我们来看优化器。
Optimizer 优化器是梯度下降的进化版本。
SGD，全称 Stochastic Gradient Descent，也就是随机梯度下降，简单稳定但需要精心调参。
Adam 是自适应学习率的优化器，对大多数问题开箱即用，是首选。
RMSprop 在训练过程中自动调整学习率，适合非平稳目标。
不确定用哪个？先试 Adam，默认参数通常就能工作得不错。

接下来讲训练 CNN 的完整流程。
第一步，初始化权重，通常是随机的。
然后对每个 Epoch 训练轮次执行以下循环。
前向传播得到预测，计算损失，反向传播计算梯度，优化器更新权重，最后在验证集上评估。
选择验证集上表现最优的模型作为最终结果。

训练过程中有几个最佳实践。
用验证集调超参数，避免在测试集上作弊。
Early Stopping 早停，当验证损失开始上升时停止训练。
定期保存模型，可以回退到最优状态。
监控训练和验证曲线，发现过拟合或欠拟合。

说到过拟合和欠拟合，这是训练的两大天敌。
Overfitting 过拟合的症状是，训练准确率 99%，验证准确率 60%。
原因是模型太复杂、参数太多，记住了训练数据的噪声。
就像一个学生把试卷答案全背下来了，包括出错的，但换一张试卷就不会了。

防止过拟合有五大策略。
第一，Dropout，训练时随机关闭一部分神经元，防止特征共适应。
第二，正则化，L1 和 L2 惩罚大权重，迫使模型更简洁。
第三，数据增强，扩展训练数据的多样性。
第四，简化模型，减少层数或神经元数。
第五，早停，验证集性能下降时停止训练。

Underfitting 欠拟合的症状是，训练准确率和验证准确率都很低。
原因是模型太简单，无法捕捉数据的模式。
解决方案包括增加模型复杂度、训练更长时间、使用更好的架构、改善数据预处理。

最后简单提一下硬件资源。
CPU 核心少，通用灵活，适合数据预处理和小模型。
GPU，全称 Graphics Processing Unit，拥有数千个核心，并行计算强，是深度学习训练首选。
TPU，全称 Tensor Processing Unit，专为神经网络设计，适合超大规模训练。

模型优化方面有三种技术。
Pruning 剪枝，移除冗余神经元和连接，让模型更小。
Quantization 量化，降低数字精度，比如从 32 位浮点降到 8 位整数，推理更快、内存更少。
还有 MobileNet 这样的高效架构，使用深度可分离卷积大幅减少参数量。
