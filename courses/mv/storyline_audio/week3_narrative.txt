上一讲我们学会了用滤波降噪、用 Canny 找边缘、用阈值化分离前景和背景。
但这些只是把物体从图像中切出来，还远远不够。

想象一个场景，你用手机拍了一本书的封面，想在书架上找到这本书。
问题是你拍照的角度和书架上看到的角度完全不同，书的大小也变了，光线也变了。
如果只靠边缘轮廓，稍微旋转一下就认不出了。

所以我们需要更高级的方法。
核心问题是，如何找到物体的指纹，无论旋转、缩放、光照怎么变，这个指纹都不会变？
这就是 Feature Detection 特征检测这一讲要解决的问题。

在进入特征检测之前，我们先补充两个预备知识。
第一个是 Contour 轮廓。
轮廓是连接一组点的闭合曲线，这些点围住的是具有相同颜色或强度的区域。
轮廓和 Edge 边缘有一个关键区别，边缘可能是断裂的，而轮廓必须是闭合的。
轮廓主要用于形状分析和目标检测。

轮廓检测的标准流水线是这样的。
先把原始彩色图转成灰度图，再用阈值化得到二值图，然后用 findContours 函数找到轮廓，最后用 drawContours 函数把轮廓画出来。
这里的二值图就充当了一个 Mask 掩模的角色，告诉算法哪些区域是前景、哪些是背景。

好，预备知识到位了，我们正式进入特征检测。
Feature Detection 特征检测，就是在图像中识别和定位重要结构或模式的过程。
所谓 Feature 特征，就是图像中有趣的部分，能帮助区分不同物体的信息。

特征有四种类型。
第一种是 Edge 边缘，也就是像素强度急剧变化的地方。
第二种是 Corner 角点，也就是两条边缘的交叉点。
第三种是 Blob 斑点，也就是相似纹理或颜色的区域。
第四种是 Ridge 脊线，也就是高强度的线条。

特征检测技术经历了三个演进阶段。
早期只有简单的边缘检测比如 Sobel 和 Canny，但它们不抗旋转、不抗缩放。
后来出现了手工特征算法，比如 SIFT、SURF 和 ORB，它们实现了旋转不变和缩放不变。
再到 2012 年之后，Deep Learning 深度学习让 CNN 卷积神经网络可以自动学习特征，精度更高但需要大量数据。

在讲具体算法之前，我们需要理解一个数学基础，Image Gradient 图像梯度。
梯度衡量的是图像函数在水平或垂直方向上的变化速度。
每个像素的梯度有两个属性，一个是 Gradient Magnitude 梯度幅值，告诉我们变化有多大，幅值越大说明边缘越清晰。
另一个是 Gradient Direction 梯度方向，告诉我们变化朝哪个方向。
梯度幅值用勾股定理计算，梯度方向用反正切函数计算。

好，有了梯度的基础，我们来看本讲最重要的算法，SIFT。
SIFT 全称 Scale-Invariant Feature Transform，也就是尺度不变特征变换。
它的目标是找到一组 Keypoint 关键点和 Descriptor 描述子，使得无论图像怎么缩放、旋转甚至部分光照变化，这些特征都能被稳定识别。

SIFT 算法分为五个步骤。
第一步是 Scale-space Extrema Detection 尺度空间极值检测。
它在多个尺度的 Difference of Gaussian 也就是 DoG 高斯差分图像中寻找局部极值点，这一步保证了尺度不变性。
第二步是 Keypoint Localization 关键点定位。
去除低对比度的不稳定点和沿边缘的点，提高关键点的稳定性和精度。
第三步是 Orientation Assignment 方向分配。
基于关键点周围的局部梯度方向，为每个关键点分配一个主方向，这一步保证了旋转不变性。
第四步是 Keypoint Descriptor Generation 关键点描述子生成。
在关键点周围取一个区域，分成 4 乘以 4 共 16 个子块，每个子块计算 8 个方向的梯度直方图，最终拼成一个 128 维的特征向量。
这个 128 维向量就是关键点的独特指纹。
第五步是 Feature Matching 特征匹配。
用 Euclidean Distance 欧氏距离来比较不同图像中描述子的相似度，找到对应的关键点。

SIFT 的核心优势可以用三个字概括，尺旋光。尺度不变加旋转不变加光照部分不变。
但 SIFT 有一个致命问题，就是太慢了，计算量大，无法用于实时视频处理。
这就引出了下一个算法。

SURF 全称 Speeded Up Robust Features，也就是加速稳健特征。
SURF 用两个技巧大幅加速了特征检测。
第一个技巧是 Integral Image 积分图像，预先计算好像素累加和，使得任意区域的求和变成常数时间操作。
第二个技巧是 Box Filter 盒式滤波器，用矩形来近似高斯函数，配合积分图像实现快速卷积。

SURF 也有四个步骤。
第一步用 Hessian Matrix 也就是 Hessian 矩阵检测器来找关键点，比 SIFT 的 DoG 更快。
第二步同样是多尺度检测，但利用积分图像加速。
第三步用 Haar Wavelet 也就是 Haar 小波来分配方向，比 SIFT 的梯度直方图更快。
第四步生成的描述子只有 64 维，比 SIFT 的 128 维少了一半，但精度几乎一样。

总结一下 SIFT 和 SURF 的区别。
SURF 速度大约是 SIFT 的三到五倍，描述子从 128 维减到 64 维，检测器从 DoG 换成了 Hessian 矩阵。
但 SURF 和 SIFT 有一个共同的问题，它们都有专利限制。
所以我们需要一个免费开源而且更快的方案。

ORB 全称 Oriented FAST and Rotated BRIEF，它是 FAST 和 BRIEF 两个算法的融合。
FAST 全称 Features from Accelerated Segment Test，负责快速关键点检测。
BRIEF 全称 Binary Robust Independent Elementary Features，负责快速生成二进制描述子。
ORB 有三大优势。速度比 SIFT 和 SURF 快一个数量级。完全免费没有专利限制。使用二进制描述子，匹配时用 Hamming Distance 汉明距离，也就是按位比较，速度极快。

这里有一个高频考点，三种算法的终极对比。
SIFT 最慢但精度最高，描述子 128 维浮点数，用欧氏距离匹配，有专利。
SURF 速度中等，描述子 64 维浮点数，用欧氏距离匹配，也有专利。
ORB 速度最快，描述子 256 位二进制，用汉明距离匹配，完全免费，适合实时应用。

除了这三种特征检测算法，还有一个专门用于人体检测的描述子，HOG。
HOG 全称 Histogram of Oriented Gradients，也就是方向梯度直方图。
HOG 通过分析图像局部区域中梯度的方向分布来描述物体形状。
它的杀手级应用是 Pedestrian Detection 行人检测，在自动驾驶和安防监控中被广泛使用。

检测到特征之后，最后一步就是在不同图像之间进行 Feature Matching 特征匹配。
常用的匹配方法有三种。
Brute Force 暴力匹配，逐一比较每对描述子，最简单但最慢。
Brute Force KNN 暴力 K 近邻，找 K 个最相似的，速度中等。
FLANN 全称 Fast Library for Approximate Nearest Neighbors，也就是快速近似最近邻搜索库，速度最快。
特征匹配的应用场景包括全景照片拼接、视频运动跟踪、三维模型构建和目标识别。
