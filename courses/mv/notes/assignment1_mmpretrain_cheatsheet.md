## 🏭 OpenMMLab / mmpretrain

| 概念           | 定义                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------ |
| **OpenMMLab**  | 香港中文大学 MMLab 开源的 CV 工具箱集合，包括 mmpretrain（分类）、mmdet（检测）、mmseg（分割）等 |
| **mmpretrain** | OpenMMLab 的图像分类/预训练工具箱，支持 100+ 预定义模型                                          |
| **配置驱动**   | 所有实验参数（模型、数据、优化器）写在 `.py` 配置文件中，不改代码只改配置                        |
| **Registry**   | 注册器机制——所有组件通过字符串名（如 `type='ResNet'`）查找并实例化                               |
| **`_base_`**   | 配置继承——子配置只写需要改的部分，其余从父配置继承                                               |

💡 **要点：** 学会一个 OpenMMLab 项目 → 所有其他项目结构类似

⚠️ **陷阱：** 配置文件的 `_base_` 路径必须正确，否则找不到父配置

## 🌻 数据集与数据准备

| 概念                  | 定义                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| **Oxford Flowers 17** | 牛津大学 VGG 组的花卉分类数据集：17 类、1360 张、每类约 80 张         |
| **SubFolder 格式**    | 数据组织方式：`train/类名/图片`，类名从文件夹名自动推断，无需标注文件 |
| **CustomDataset**     | mmpretrain 的通用数据集类，支持 SubFolder 格式                        |
| **数据增强**          | 通过随机变换（裁剪、翻转等）增加训练数据多样性                        |
| **Train/Val Split**   | 训练集（~80%）用于学习，验证集（~20%）用于评估泛化能力                |

💡 **要点：** 小数据集（~60 张/类）必须用数据增强防止过拟合

⚠️ **陷阱：** 验证集不做数据增强——必须保持确定性

## 🧠 模型架构

### ResNet-18

| 概念                           | 定义                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------- |
| **残差连接 (Skip Connection)** | 让输入跳过若干层直接加到输出上：`y = F(x) + x`，解决深层网络的退化问题        |
| **残差块 (Residual Block)**    | `Conv→BN→ReLU→Conv→BN + shortcut → ReLU`，网络学习残差 F(x) 而非完整映射 H(x) |
| **退化问题 (Degradation)**     | 更深的网络训练误差反而更高——不是过拟合，是训练本身失败                        |
| **GlobalAveragePooling**       | 对每个特征图取全局平均值，将 H×W×C 压缩为 1×1×C，替代 FC 层减少参数           |

### MobileNet V2

| 概念                                          | 定义                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------ |
| **深度可分离卷积 (Depthwise Separable Conv)** | 拆分标准卷积为两步：深度卷积（每通道独立）+ 逐点卷积（1×1 混合通道），减少 ~88% 参数 |
| **倒残差 (Inverted Residual)**                | 窄→宽→窄结构：先 1×1 膨胀维度 → 3×3 深度卷积 → 1×1 压缩回来                          |
| **线性瓶颈 (Linear Bottleneck)**              | 倒残差的最后一层不用 ReLU，防止低维空间的信息损失                                    |

📊 **对比表**

| 方面              | ResNet-18 | MobileNet V2 |
| ----------------- | --------- | ------------ |
| 参数量            | ~11.7M    | ~3.4M        |
| 卷积类型          | 标准      | 深度可分离   |
| 设计目标          | 准确率    | 效率         |
| 适用场景          | 服务器    | 手机/嵌入式  |
| Assignment 1 结果 | 77.21%    | **90.07%**   |

⚠️ **陷阱：** "参数多=更准确" 在小数据集上不成立——MobileNet V2 用 29% 参数赢了 13 个百分点

## ⚙️ 训练配置

| 概念                            | 定义                                                                               |
| ------------------------------- | ---------------------------------------------------------------------------------- |
| **Epoch**                       | 模型过完一次完整训练集                                                             |
| **Batch Size**                  | 每次更新参数时用多少张图（Assignment 1 = 32）                                      |
| **学习率 (Learning Rate)**      | 参数更新步长——太大震荡、太小卡住                                                   |
| **余弦退火 (Cosine Annealing)** | 学习率按余弦曲线从大到小衰减，开始快探索、结束细调整                               |
| **ImageNet 归一化**             | 用 ImageNet 的 mean=[123.675,116.28,103.53] / std=[58.395,57.12,57.375] 标准化输入 |

📊 **SGD vs Adam 对比**

| 方面     | SGD + Momentum   | Adam                   |
| -------- | ---------------- | ---------------------- |
| 学习率   | 固定（需手动调） | 自适应（每个参数不同） |
| 对噪声   | 敏感             | 鲁棒                   |
| 小数据集 | 需要细调         | 默认值通常够好         |
| 大数据集 | 调好后可达更优解 | 有时不如调好的 SGD     |

## 📊 评估指标

| 概念               | 定义                                                   |
| ------------------ | ------------------------------------------------------ |
| **Top-1 Accuracy** | 模型最高概率的预测 = 正确答案的比例                    |
| **Top-5 Accuracy** | 正确答案在模型前 5 个预测中的比例                      |
| **Precision**      | 预测为正的样本中真正为正的比例 = TP/(TP+FP)            |
| **Recall**         | 实际为正的样本中被正确预测的比例 = TP/(TP+FN)          |
| **F1-Score**       | Precision 和 Recall 的调和平均 = 2×P×R/(P+R)           |
| **混淆矩阵**       | 显示每对（真实类, 预测类）的计数，揭示哪些类别容易混淆 |
| **Macro Average**  | 所有类别的指标取简单平均（每个类别权重相等）           |

⚠️ **陷阱：** 类别不平衡时 Accuracy 会误导——用 F1 或 Macro Average 更公平

## 📦 环境搭建

| 概念      | 定义                                                           |
| --------- | -------------------------------------------------------------- |
| **Conda** | 包管理器，自动处理二进制兼容性（pip 做不到）                   |
| **WSL2**  | Windows 下的 Linux 子系统，运行 Ubuntu 环境                    |
| **CUDA**  | NVIDIA GPU 编程框架，PyTorch 通过 CUDA 加速训练                |
| **mim**   | OpenMMLab 的包安装工具：`mim install mmengine mmcv mmpretrain` |

💡 **要点：** 按官方教程的版本组合安装（Python 3.8 + PyTorch 2.4.1），不要混用 pip 和 conda

⚠️ **陷阱：** NumPy 2.x 与旧版 PyTorch 不兼容 → 用 conda 而非 pip 安装
