## 📖 核心定义

### Image Processing (图像处理)

- 机器视觉的**构建基石** — "manipulation and analysis of images"
- 目的：**增强**质量 + **提取**有意义信息
- Week 1 工作流中的第 2 步：Acquisition → **Processing** → Interpretation

### 9 个关键阶段

1. **Acquisition** 采集
2. **Enhancement** 增强
3. **Restoration** 复原
4. **Morphological Processing** 形态学处理
5. **Segmentation** 分割
6. **Object Recognition** 目标识别
7. **Representation & Description** 表示与描述
8. **Compression** 压缩
9. **Color Processing** 彩色处理

> ⚠️ 并非每个任务都需要全部 9 步！根据应用选 2-3 步即可。

## 💡 关键要点

### 滤波/模糊 (Filtering/Blurring)

| 方法         | 原理            | 最佳去噪类型 | 保边能力 |
| ------------ | --------------- | ------------ | -------- |
| **均值模糊** | 邻域等权平均    | 高斯噪声     | 差       |
| **高斯模糊** | 中心权重大      | 高斯噪声     | 中       |
| **中值模糊** | 取中位数        | **椒盐噪声** | 好       |
| **双边滤波** | 距离+强度双权重 | 高斯噪声     | **最好** |

- 模糊去噪但**丢细节**；锐化增细节但**放大噪声** → 矛盾取舍

### Canny 边缘检测 — 5 步流水线

| 步骤 | 名称              | 做什么            | 为什么             |
| ---- | ----------------- | ----------------- | ------------------ |
| ①    | 高斯模糊          | 平滑图像          | 去除噪声避免假边缘 |
| ②    | Sobel 梯度        | 计算梯度强度+方向 | 边缘 = 强度突变    |
| ③    | 非极大值抑制(NMS) | 细化为1像素宽     | 梯度产生粗边带     |
| ④    | 双阈值            | 强/弱/非边缘      | 区分真边缘和噪声   |
| ⑤    | 滞后跟踪          | 弱连强→保留       | 保真边缘去假边缘   |

### 直方图 (Histogram)

- X轴 = 像素值(0-255), Y轴 = 像素计数
- 左偏 = 暗图; 右偏 = 亮图; 均匀 = 高对比度
- **Bins**: 将 0-255 分成子区间（如 16 bins = 每 bin 16 像素值）
- **均衡化**: 重新分配像素值 → 增强对比度

### 阈值化 (Thresholding)

| 类型           | 阈值来源       | 适用场景     |
| -------------- | -------------- | ------------ |
| **简单阈值**   | 全局固定值     | 光照均匀     |
| **自适应阈值** | 局部邻域计算   | **光照不均** |
| **Otsu**       | 直方图自动计算 | 双峰分布     |

### 形态学操作 (Morphological Operations)

| 操作       | 定义              | 效果       | 用途               |
| ---------- | ----------------- | ---------- | ------------------ |
| **腐蚀**   | 核下**全1**才保留 | 缩小白区域 | 去白噪点、分离粘连 |
| **膨胀**   | 核下**有1**就扩展 | 扩大白区域 | 填小孔、连接断裂   |
| **开运算** | **腐蚀→膨胀**     | 去噪保形   | 去除小白噪声       |
| **闭运算** | **膨胀→腐蚀**     | 填孔保形   | 填充前景内小孔     |

### 仿射变换 (Affine Transformation)

- 公式: **y = Ax + b**
- A = 线性变换矩阵 (旋转/缩放/剪切)
- b = 平移向量
- 性质: **保持直线和平行性**
- 4种: 平移 / 旋转 / 缩放 / 剪切

| #   | 陷阱                  | 正确理解                               | 来源       |
| --- | --------------------- | -------------------------------------- | ---------- |
| 1   | 开运算 = 先膨胀后腐蚀 | ❌ 开运算 = **先腐蚀后膨胀**           | slides §11 |

| 7   | 锐化能去除噪声        | ❌ 锐化**放大**噪声（模糊才去噪）      | slides §6  |

## 📊 快速对比

### 工具链：问题→解决方案

| 问题              | 解决技术       | 原理               |
| ----------------- | -------------- | ------------------ |
| 图像有噪声        | 模糊/滤波      | 邻域平均或取中位数 |
| 细节不清          | 锐化           | 放大像素差异       |
| 找物体边界        | Canny 边缘检测 | 5步梯度分析        |
| 判断亮暗分布      | 直方图         | 统计像素值分布     |
| 分离前景/背景     | 阈值化         | 像素值与阈值比较   |
| 二值图有噪点/孔洞 | 形态学操作     | 腐蚀/膨胀组合      |
| 图像需要旋转/缩放 | 仿射变换       | 矩阵乘法 + 平移    |
