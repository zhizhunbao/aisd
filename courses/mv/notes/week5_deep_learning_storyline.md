## 📚 第一章：数据准备——"巧妇难为无米之炊"

### 1.1 数据集的三驾马车

| 数据集 | 占比 | 作用 |
| ---- | ---- | ---- |
| **训练集** (Train) | ~70% | 模型从中**学习**参数 |
| **验证集** (Validation) | ~15% | **调优超参数**、监控过拟合 |
| **测试集** (Test) | ~15% | 最终**评估**，训练过程中不可见 |

> 💡 **为什么要分三份？** 如果用同一份数据训练和评估，模型可能只是"背答案"（过拟合），在新数据上一塌糊涂。验证集帮你在训练过程中发现问题，测试集给出最终的"高考成绩"。

### 1.2 数据预处理

在输入 CNN 之前，必须做以下处理：

| 步骤 | 目的 | 示例 |
| ---- | ---- | ---- |
| **统一尺寸** | CNN 需要固定输入尺寸 | 全部 resize 为 128×128 |
| **归一化** | 加速收敛、提高稳定性 | 像素值从 [0,255] → [0,1] |
| **色彩空间** | 根据任务选择 | RGB 或灰度 |

### 1.3 数据增强 (Data Augmentation)——便宜的"扩大数据集"

数据不够？用随机变换人为扩展：

| 变换 | 效果 |
| ---- | ---- |
| **随机翻转** (Horizontal Flip) | 左右镜像 |
| **随机旋转** (Rotation) | 小角度旋转 |
| **随机缩放** (Scaling) | 放大/缩小 |
| **随机裁剪** (Cropping) | 截取不同区域 |

> 🔑 **关键考点：** 数据增强**只应用于训练集**，不应用于验证集和测试集！验证集需要保持**确定性**以准确评估。

## 🎭 第二章：激活函数——让网络学会"弯道"

### 2.1 为什么需要激活函数？

如果没有激活函数，多层神经网络的效果等同于一层（多个线性变换的组合仍是线性变换）。

**激活函数引入非线性**，让网络能学习复杂的、非线性的模式。

### 2.2 三大激活函数对决

| 激活函数 | 公式 | 输出范围 | 优势 | 缺陷 |
| ---- | ---- | ---- | ---- | ---- |
| **Sigmoid** | σ(x) = 1/(1+e⁻ˣ) | (0, 1) | 输出可解释为概率 | ❌ **梯度消失**、非零中心 |
| **Tanh** | tanh(x) = (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | (-1, 1) | 零中心 | ❌ **梯度消失** |
| **ReLU** | f(x) = max(0, x) | [0, ∞) | ✅ 缓解梯度消失、稀疏激活、计算快 | 负值"死亡" |

### 2.3 梯度消失问题 (Vanishing Gradient)

**Sigmoid 和 Tanh 的致命缺陷：**

当输入值很大或很小时，导数趋近于 0 → 反向传播时梯度几乎为零 → 浅层权重**几乎不更新** → 网络学习极慢。

```
输入 x = 10 → Sigmoid(10) ≈ 0.9999 → Sigmoid'(10) ≈ 0.0001  ← 梯度几乎消失！
```

### 2.4 ReLU 为什么是首选？

| 优势 | 解释 |
| ---- | ---- |
| **缓解梯度消失** | 正区间导数恒为 1 → 梯度不会缩小 |
| **稀疏激活** | 负值→0，减少过拟合 |
| **计算高效** | 只需判断 >0，比 exp() 快得多 |

> 💡 **使用建议：**
> - **隐藏层**：几乎总是用 **ReLU**
> - **二分类输出层**：用 **Sigmoid**（输出概率）
> - **多分类输出层**：用 **Softmax**（输出概率分布）

## 📖 第三章：损失函数——量化"错得多离谱"

### 3.1 损失函数的作用

损失函数衡量**模型预测**与**真实标签**之间的差距，是训练的"指南针"。

### 3.2 三大损失函数

**MSE (均方误差)** — 用于回归任务

$$MSE = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

**BCE (二元交叉熵)** — 用于二分类

$$BCE = -\frac{1}{N} \sum_{i=1}^{N} [y_i \cdot \log(\hat{y}_i) + (1-y_i) \cdot \log(1-\hat{y}_i)]$$

**CCE (分类交叉熵)** — 用于多分类

$$CCE = -\frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{C} y_{ij} \cdot \log(\hat{y}_{ij})$$

### 3.3 如何选择损失函数？

| 任务类型 | 推荐损失函数 | 输出层激活 |
| ---- | ---- | ---- |
| 回归 | **MSE** | 线性（无激活） |
| 二分类 | **BCE** | Sigmoid |
| 多分类 | **CCE** | Softmax |

> 💡 **直觉理解 CCE：** 因为 y 是 one-hot 编码，只有真实类别对应的 y=1，所以 CCE 简化为 **-log(ŷ_c)**——即模型对正确类别预测概率越高，损失越低。

## 🏆 第四章：梯度下降与反向传播——让损失越来越小

### 4.1 梯度下降的直觉

想象你蒙着眼睛在山上，要走到谷底（损失最低点）：

1. **感受脚下的坡度**（计算梯度）
2. **朝下坡方向迈一步**（更新权重）
3. **重复**直到到达谷底

### 4.2 权重更新公式

$$w_{new} = w_{old} - \eta \cdot \frac{\partial L}{\partial w}$$

| 符号 | 含义 |
| ---- | ---- |
| w_new | 更新后的权重 |
| w_old | 当前权重 |
| η (eta) | **学习率** — 步长（太大会跳过谷底，太小收敛慢） |
| ∂L/∂w | 损失对权重的**梯度** |

> 💡 **类比：** 学习率 η 就像你走路的步伐。步子太大容易跨过最佳点来回震荡；步子太小要走一辈子。

### 4.3 反向传播的六个步骤

```
Step 1: 前向传播 — 将样本输入网络，得到预测
Step 2: 计算损失 — 比较预测与真实标签（如 MSE）
Step 3: 计算输出层误差 — 损失对输出层权重的梯度
Step 4: 反向传播误差 — 从输出层往前，逐层计算隐藏层的梯度
Step 5: 应用 Delta 规则 — 按梯度方向计算每个权重应该怎么调整
Step 6: 更新权重 — w_new = w_old - η × gradient
```

> 🔑 **关键考点：** 反向传播**仅在训练时**执行，推理（prediction）时只做前向传播。

---

## 📖 第五章：优化器——梯度下降的进化版

### 5.1 三种主要优化器

| 优化器 | 特点 | 适用场景 |
| ---- | ---- | ---- |
| **SGD** (随机梯度下降) | 简单、稳定，但需精心调参 | 大数据集 + 充分调参 |
| **Adam** | 自适应学习率，对大多数问题开箱即用 | ✅ **首选**，尤其小数据集 |
| **RMSprop** | 训练过程中自动调整学习率 | 非平稳目标 |

> 💡 **实用建议：** 不确定用哪个？先试 **Adam**（默认参数通常就能工作得不错）。

## 📖 第六章：训练 CNN 的完整流程

### 6.1 端到端流程

```
1. 初始化权重（通常随机）
2. For each epoch:
   a. 前向传播 → 得到预测
   b. 计算损失
   c. 反向传播 → 计算梯度
   d. 优化器更新权重
   e. 在验证集上评估
3. 选择验证集上最优的模型
```

### 6.2 最佳实践

| 实践 | 目的 |
| ---- | ---- |
| 用验证集调超参数 | 避免在测试集上"作弊" |
| **早停 (Early Stopping)** | 验证损失开始上升时停止训练 |
| 定期保存模型 | 可以回退到最优状态 |
| 监控训练+验证曲线 | 发现过拟合/欠拟合 |

## 📖 第七章：过拟合与欠拟合——训练的两大天敌

### 7.1 过拟合 (Overfitting)

**症状：** 训练准确率 99%，验证准确率 60%

**原因：** 模型太复杂、参数太多 → 记住了训练数据的噪声

**五大防治策略：**

| 策略 | 原理 |
| ---- | ---- |
| 1. **Dropout** | 训练时随机关闭一部分神经元，防止特征共适应 |
| 2. **正则化** (L1/L2) | 惩罚大权重，迫使模型更简洁 |
| 3. **数据增强** | 扩展训练数据的多样性 |
| 4. **简化模型** | 减少层数或神经元数 |
| 5. **早停** (Early Stopping) | 验证集性能下降时停止训练 |

> 💡 **类比：** 过拟合 = 学生把试卷答案全背下来了（包括出错的），但换一张试卷就不会了。

### 7.2 欠拟合 (Underfitting)

**症状：** 训练准确率和验证准确率都很低

**原因：** 模型太简单 → 无法捕捉数据的模式

**解决方案：**

| 策略 | 原理 |
| ---- | ---- |
| 增加模型复杂度 | 添加更多层/神经元 |
| 训练更长时间 | 给模型更多学习机会 |
| 使用更强大的特征提取 | 换用更好的架构 |
| 改善数据预处理和增强 | 确保模型获得足够信息 |

## 📖 第八章：硬件资源与模型优化

### 8.1 CPU vs GPU vs TPU

| 硬件 | 核心数 | 特点 | 适用场景 |
| ---- | ---- | ---- | ---- |
| **CPU** | 少（4-16） | 通用、灵活 | 数据预处理、小模型 |
| **GPU** | 多（数千） | 并行计算强 | ✅ **深度学习训练首选** |
| **TPU** | 专用 | 专为神经网络设计 | 超大规模训练 |

### 8.2 模型优化技术

| 技术 | 原理 | 效果 |
| ---- | ---- | ---- |
| **剪枝** (Pruning) | 移除冗余神经元/连接 | 模型更小 |
| **量化** (Quantization) | 降低数字精度（FP32→INT8） | 推理更快、内存更少 |
| **高效架构** (MobileNet) | 深度可分离卷积 | 参数量大幅减少 |
