## 📖 核心定义

### Machine Vision (机器视觉)

- 使机器**解读和理解**周围环境视觉信息的技术
- 完整系统 = **硬件 (传感器)** + **软件 (算法)** + **决策 (action)**
- 三步工作流：**Image Acquisition → Image Processing → Interpretation/Action**

### Computer Vision vs Machine Vision

- **Computer Vision** = 图像理解**算法** → 学术导向
- **Machine Vision** = 完整端到端**系统** (含硬件+决策) → 工业导向
- ⚠️ Quiz 考点：Machine Vision 强调 "complete end-to-end systems"

### Pixel (像素)

- 图像中 `(x, y)` 位置的**数值表示**
- 灰度图：单值 `[0, 255]`，0 = 黑，255 = 白
- 彩色图(RGB)：三元组 `(R, G, B)`，每个 `[0, 255]`

### Image (图像)

- **灰度图** = 二维矩阵 `(Height × Width)` → 2D
- **彩色图** = 三维张量 `(Height × Width × 3)` → 3D
- ⚠️ Quiz 考点：灰度图**不是** 3D tensor！

## 💡 关键要点

### 色彩空间

| 空间    | 通道                | 特点                 | 用途          |
| ------- | ------------------- | -------------------- | ------------- |
| **RGB** | R红 G绿 B蓝         | 直观；受光照影响     | 显示、存储    |
| **HSV** | H色相 S饱和度 V明度 | 颜色与亮度**分离**   | 颜色检测/分割 |
| **BGR** | B蓝 G绿 R红         | OpenCV 默认通道顺序! | OpenCV 内部   |

- HSV 的 H 通道 = 颜色类型，**不受**亮度影响 → 颜色检测首选
- H: 0°-360°, S: 0-1, V: 0-1

### 图像格式

| 格式     | 压缩    | 透明度 | 大小 | 用途       |
| -------- | ------- | ------ | ---- | ---------- |
| **JPEG** | 有损 ❌ | ❌     | 小   | 照片、网页 |
| **PNG**  | 无损 ✅ | ✅     | 中   | 图标、截图 |
| **RAW**  | 无      | ❌     | 大   | 专业摄影   |

### 图像传感器

| 传感器   | 画质  | 功耗 | 成本 | 用途           |
| -------- | ----- | ---- | ---- | -------------- |
| **CCD**  | 高    | 高   | 贵   | 医学、天文     |
| **CMOS** | 中→高 | 低   | 便宜 | 手机、消费相机 |

### 传统 CV vs 深度学习

| 维度     | 传统 CV              | 深度学习                    |
| -------- | -------------------- | --------------------------- |
| 特征     | 手工设计 (SIFT, HOG) | 自动学习 (CNN)              |
| 数据     | 小数据可用           | 需大量标注数据              |
| 可解释性 | 高                   | 低 (黑箱)                   |
| 通用性   | 低                   | 高                          |
| 转折点   | —                    | **2012 AlexNet / ImageNet** |

## ⚠️ 常见陷阱 (Traps)

| #   | 陷阱                      | 正确理解                                          | 来源     |
| --- | ------------------------- | ------------------------------------------------- | -------- |
| 1   | JPEG 是无损压缩           | ❌ JPEG 是**有损**压缩；PNG 才是无损              | Quiz Q15 |
| 2   | 灰度图是 3D tensor        | ❌ 灰度图是 **2D** `(H×W)`；RGB 才是 3D `(H×W×3)` | Quiz Q11 |
| 3   | OpenCV 用 RGB 顺序        | ❌ OpenCV 默认是 **BGR**；需 `cvtColor` 转 RGB    | Quiz Q12 |
| 4   | 像素用 `image[x, y]` 访问 | ❌ OpenCV 用 `image[y, x]`（**行, 列**）          | Quiz Q13 |
| 5   | 深度学习完全取代传统方法  | ❌ 工业简单检测、小数据场景仍用传统方法           | Quiz Q14 |
| 6   | CCD 比 CMOS 便宜          | ❌ CMOS 更便宜（标准半导体工艺）                  | Quiz Q17 |
| 7   | MV 和 CV 完全相同         | ❌ MV = 完整系统；CV = 算法部分                   | Quiz Q3  |
