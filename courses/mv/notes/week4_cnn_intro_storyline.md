> **核心主题：** 为什么传统ANN不适合处理图像？CNN是如何通过卷积、池化、全连接三大组件来自动提取特征的？
> **故事线：** ANN的图像困境 → CNN用卷积层解决 → 池化层降维 → 全连接层分类 → 反向传播训练 → 性能评估

## 🎬 序幕：我们在解决什么问题？

上一讲（Week 3）我们学了 SIFT、SURF、ORB——这些算法能提取图像的"指纹"特征。

但这些方法有一个共同的问题：**特征是人类手动设计的**。

- SIFT 的设计者决定用高斯差分来检测关键点
- HOG 的设计者决定用梯度直方图来描述人体
- 如果换一个任务（比如识别猫和狗），可能需要**重新设计**特征

**核心问题：能不能让机器自动学会应该关注图像的哪些特征？**

> 💡 **类比：** 手工特征 = 老师画好了重点，学生只负责背。CNN = 给学生一堆真题，让学生**自己**发现什么是重点。

## 📚 第一章：ANN 处理图像——为什么不行？

### 1.1 什么是人工神经网络 (ANN)？

ANN 是受人脑启发的计算模型：
- **生物启发**：由互连的"神经元"组成
- **从数据学习**：通过分析数据集调整连接权重
- **模式识别**：特别擅长识别复杂模式

### 1.2 ANN 用于图像分类的流程

```
输入图像 → 展平为一维向量 → 隐藏层处理 → 输出类别
```

### 1.3 ❗ ANN 的致命问题

对于一张 1000×1000 的彩色图像：

| 问题 | 详情 |
| ---- | ---- |
| **参数爆炸** | 输入层 = 1000×1000×3 = 3,000,000 个神经元，仅第一个隐藏层就需要数十亿个权重 |
| **高计算成本** | 矩阵乘法规模巨大 |
| **过拟合** | 参数远多于训练样本 → 记住了噪声而非模式 |
| **训练时间长** | 权重太多，收敛极慢 |
| **忽略空间结构** | 展平后，相邻像素的空间关系完全丢失 |

> 🔑 **故事转折点：** ANN 把图像展平成一维向量，**丢失了所有空间信息**（哪些像素相邻、哪些像素构成边缘）。而且参数量爆炸，根本无法训练 → 我们需要一种**保留空间结构、减少参数**的新架构！

## 🎭 第二章：CNN 登场——三大法宝

### 2.1 CNN 的定义与目标

**卷积神经网络 (CNN)** = 一种专门为**图像处理**设计的深度学习架构。

**三大核心优势：**
1. 处理高维结构化数据（图像、视频、音频）
2. **层次化特征学习**——浅层学边缘，深层学语义
3. 对物体**平移具有鲁棒性**——猫在图像左边还是右边，都能识别

### 2.2 CNN 架构总览

```
┌─────────┐    ┌────────────┐    ┌──────────┐    ┌─────────┐    ┌──────────┐
│  Input   │    │ Convolutional│   │ Pooling  │    │Flattening│   │  Fully   │
│  Image   │ →  │   Layers    │ → │ Layers   │ →  │         │ → │Connected │ → 输出类别
│          │    │ 提取空间特征 │    │ 降维     │    │展平为1D │    │ 分类     │
└─────────┘    └────────────┘    └──────────┘    └─────────┘    └──────────┘
```

| 组件 | 作用 | 类比 |
| ---- | ---- | ---- |
| **卷积层** | 从图像中提取**空间特征** | 用放大镜扫描图像的每个区域 |
| **池化层** | **降低维度**，减少计算量 | 把高清图缩小为缩略图（保留关键信息） |
| **全连接层** | 整合特征进行**最终分类** | 基于所有线索做出最终判断 |

## 📖 第三章：卷积层——CNN 的核心引擎

### 3.1 卷积运算的直觉

卷积层的工作方式：
1. 一个小的**滤波器 (Filter/Kernel)**（如 3×3）在图像上**滑动**
2. 在每个位置，滤波器与图像对应区域做**逐元素乘法再求和**
3. 输出一个新的值，形成**特征图 (Feature Map)**

> 💡 **关键理解：** 不同的滤波器检测不同的特征：
> - 某个滤波器专检测**垂直边缘**
> - 某个滤波器专检测**水平线条**
> - 某个滤波器专检测**角点**
> - 这些滤波器的值是**自动学习**的，不是人工设计的！

### 3.2 为什么卷积能解决 ANN 的问题？

| ANN 的问题 | CNN 的解决方案 |
| ---- | ---- |
| 参数爆炸 (3M 输入) | **参数共享**：一个 3×3 滤波器只有 9 个参数，全图共用 |
| 忽略空间结构 | **局部连接**：每个输出只看输入的一小块局部区域 |
| 对位置敏感 | **平移不变性**：同一个滤波器扫描全图 |

### 3.3 三大超参数

| 超参数 | 含义 | 影响 |
| ---- | ---- | ---- |
| **滤波器大小 (F)** | 每个滤波器覆盖的区域 | 小=精细特征，大=宏观模式 |
| **步幅 (S, Stride)** | 滤波器每次移动的步长 | 大=输出更小、更抽象 |
| **填充 (P, Padding)** | 输入边界补零 | 保留边缘信息、控制输出尺寸 |

### 3.4 ⭐ 输出尺寸计算公式

$$Output = \frac{N - F + 2P}{S} + 1$$

- N = 输入图像大小
- F = 滤波器大小
- P = 填充量
- S = 步幅

**例题：** 输入 112×112，滤波器 3×3，padding=0，stride=2

```
Output = (112 - 3 + 0) / 2 + 1 = 109/2 + 1 = 54 + 1 = 55
```

输出尺寸为 **55×55**。

> 🔑 **必记公式！** 这个公式在考试中几乎必考。

## 🏆 第四章：池化层——聪明地"缩小"

### 4.1 为什么需要池化？

卷积层输出的特征图可能仍然很大 → 需要**下采样 (Down-sampling)** 来：
1. 减少计算量和参数量
2. 增加对微小位移的**容忍度**（泛化能力）

### 4.2 两种池化方式

| 方式 | 操作 | 示例（2×2 区域 [1,3,5,2]） |
| ---- | ---- | ---- |
| **最大池化** (Max Pooling) | 取区域内**最大值** | max(1,3,5,2) = **5** |
| **平均池化** (Average Pooling) | 取区域内**平均值** | avg(1,3,5,2) = **2.75** |

> 💡 **最大池化更常用**，因为它保留了最显著的特征（最强的激活）。

### 4.3 池化的效果

```
输入特征图 (28×28) → MaxPool2d(2,2) → 输出 (14×14) → MaxPool2d(2,2) → 输出 (7×7)
```

每次 2×2 池化将尺寸**减半**。

## 📖 第五章：全连接层——最终裁判

### 5.1 展平 (Flattening)

池化层输出的特征图是多维数组（如 7×7×64），需要**展平**为一维向量（7×7×64 = 3136 维），才能输入全连接层。

### 5.2 全连接层的工作

```
展平向量 (3136维) → FC Layer 1 (256神经元) → FC Layer 2 (10神经元) → 输出类别
```

**运算：output = W × input + b**

| 符号 | 含义 |
| ---- | ---- |
| **W** | 权重矩阵 (n × m)，n=本层神经元数，m=输入长度 |
| **b** | 偏置向量，长度=本层神经元数 |

### 5.3 激活函数——引入非线性

如果没有激活函数，多层线性变换等价于一层 → 无法学习复杂模式。

**最常用：ReLU (Rectified Linear Unit)**
- f(x) = max(0, x)
- 负值变 0，正值不变

### 5.4 输出层——Softmax

最后一层用 **Softmax** 激活函数：
- 将原始分数转换为**概率分布**（所有类别概率之和=1）
- 最高概率的类别 = 预测结果
- 神经元数 = **类别数**

## 📖 第六章：反向传播——CNN 如何学习

### 6.1 训练流程

```
1. 前向传播：输入图像 → 经过所有层 → 输出预测
2. 计算损失：比较预测与真实标签的差距
3. 反向传播：从输出层往回计算每个权重的梯度
4. 更新权重：朝减少损失的方向调整
5. 重复：直到损失足够小
```

### 6.2 反向传播的六个步骤

1. 将样本输入网络
2. 计算均方误差 (MSE)
3. 计算每个输出神经元的误差项
4. 迭代计算隐藏层的误差项
5. 应用 Delta 规则
6. **调整权重**

> 💡 **关键理解：** 反向传播**只在训练时**发生。推理时只需前向传播。

## 📖 第八章：性能评估——模型好不好怎么衡量？

### 8.1 混淆矩阵 (Confusion Matrix)

|  | **预测=正 (Positive)** | **预测=负 (Negative)** |
| ---- | :----: | :----: |
| **实际=正** | TP (真正例) ✅ | FN (假反例) ❌ |
| **实际=负** | FP (假正例) ❌ | TN (真反例) ✅ |

### 8.2 四大评估指标

| 指标 | 公式 | 含义 |
| ---- | ---- | ---- |
| **Accuracy** | (TP+TN) / (TP+TN+FP+FN) | 整体正确率 |
| **Precision** | TP / (TP+FP) | "预测为正的"有多少真是正的 |
| **Recall** | TP / (TP+FN) | "实际为正的"有多少被找到了 |
| **F1 Score** | 2×(P×R)/(P+R) | Precision 和 Recall 的调和平均 |

### 8.3 ROC 曲线与 AUC

- **ROC 曲线**：True Positive Rate vs False Positive Rate
- **AUC**（曲线下面积）：越接近 1.0 → 模型越好
- 对角线 = 随机猜测 (AUC = 0.5)

> 💡 **何时用哪个指标？**
> - 数据平衡 → **Accuracy** 即可
> - 假正例代价高（如垃圾邮件误判） → 看 **Precision**
> - 假反例代价高（如癌症漏诊） → 看 **Recall**
> - 需要平衡 → 看 **F1 Score**
