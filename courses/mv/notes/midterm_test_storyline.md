## 📚 第一章：像素与图像处理——一切的起点

### 1.1 什么是像素？（Q4）

一切始于像素（Pixel）。**Q4** 考的就是最基本的定义：

> 像素 = 图像中某个位置的数值表示（a numerical representation at a location in an image）

❌ **易错点：** 像素不是「文件格式」，不是「矢量单位」，而是一个**数字**——灰度图中是 0-255 的整数，彩色图中是 (R,G,B) 三元组。

### 1.2 怎么操作像素？——滤波（Q1, Q2）

有了像素，第一个问题是：**怎么增强图像？**

- **Q1** 告诉我们：**Filtering（滤波）** 是通过改变像素值来增强图像的核心技术
- **Q2** 进一步问：**Sharpening（锐化）** 通过增大相邻像素对比度来突出细节

> 💡 **记忆技巧：** 想象你在Photoshop里调照片——模糊（Blurring）让照片变柔和，锐化（Sharpening）让边缘更清晰。它们都是滤波的具体应用。

### 1.3 基于形状的操作——形态学（Q3, Q27）

图像不仅有灰度值，还有**形状**。**Q3** 考的是：

> 形态学运算（Morphological operations）= 基于形状处理图像（processing images based on shapes）

**Q27** 更具体：**先膨胀后腐蚀 = 闭运算（Closing）**

> 💡 **记忆口诀：**
> - **开运算（Opening）** = 先腐蚀后膨胀 → "先开门让小噪声出去"
> - **闭运算（Closing）** = 先膨胀后腐蚀 → "先关门把空洞填上"

### 1.4 边缘与梯度（Q14, Q21）

像素值的**变化**比像素值本身更有意义：

- **Q14**：**Image Gradient（图像梯度）** 度量强度的方向变化——找到像素值剧变的地方就是边缘
- **Q21**：Canny 边缘检测使用 **Double（双重）阈值化**——高阈值找强边缘，低阈值找弱边缘，两者保留，其余丢弃

### 1.5 轮廓提取（Q12, Q22）

找到边缘后，怎么把边缘连成有意义的形状？

- **Q22**：**Contour（轮廓）** = 连接相同颜色/强度点围成区域的曲线
- **Q12**：OpenCV 中用 **cv2.findContours()** 来找轮廓

> ⚠️ **考试陷阱：** `cv2.detectContours()`、`cv2.locateContours()`、`cv2.searchContours()` 都不存在！OpenCV 的命名习惯是 `find`，不是 `detect` 或 `search`。

### 1.6 分割（Q10, Q16, Q20）

轮廓是分割的一种手段。**Q10** 问分割的目的：

> 分割 = 从图像中提取对象（to extract objects from an image）

- **Q16**：分割输出 = **Binary image（二值图像）**——0或1，背景或前景
- **Q20**：**Thresholding（阈值化）** 是实现分割的经典方法

> 🔑 **故事转折点：** 到目前为止，所有操作都是**人工设计的规则**（手动选阈值、手动选滤波器）。当图像变复杂，这些手工方法就力不从心了——我们需要让机器**自动**学习！

## 🎭 第二章：特征检测——从人工规则到半自动

### 2.1 为什么需要特征？（Q5）

当我们想让机器"认识"物体时，不能直接比较原始像素——因为同一物体在不同角度、光照、大小下像素完全不同。

**Q5** 告诉我们特征描述符（Feature Descriptors）的本质：

> 为检测到的特征提供唯一表示（to provide unique representation of detected features）

### 2.2 经典特征方法（Q6, Q7, Q29）

三道题考了三种经典特征检测方法的全称：

| 缩写 | 全称 | 特点 | 题号 |
|---|---|---|---|
| **SIFT** | Scale Invariant Feature Transform — 尺度不变特征变换 | 对尺度、旋转不变 | Q6 |
| **ORB** | Oriented FAST and Rotated BRIEF — 定向FAST和旋转BRIEF | 快速、开源替代SIFT | Q29 |
| **HOG** | Histogram of Oriented Gradients — 方向梯度直方图 | 对人体检测有效 | Q7 |

> 💡 **记忆技巧：**
> - **SIFT** = **S**cale **I**nvariant（尺度不变）→ 无论物体大小如何变化都能识别
> - **HOG** = 把梯度方向做直方图 → 描述的是"形状轮廓"→ 特别适合人体这种有固定轮廓的物体
> - **ORB** = FAST（快速检测）+ BRIEF（简洁描述）的改进版 → 速度快

> 🔑 **故事转折点：** SIFT、HOG 这些都是**人类设计的特征提取规则**。它们在特定任务上表现不错，但面对复杂场景（识别1000种物体？），人类不可能为每种物体设计专门的特征→ 我们需要**自动学习特征**的方法！

## 📖 第三章：CNN——让机器自己学特征

### 3.1 CNN的核心结构（Q23, Q30）

卷积神经网络（CNN）是解决"自动学习特征"的关键方案：

- **Q23**：CNN 隐藏层 = 卷积层 + **Pooling（池化）层** + 全连接层
- **Q30**：最后一层神经元数 = **类别数（Classes）**（因为每个神经元对应一个分类结果）

### 3.2 卷积运算的细节（Q25, Q26, Q28）

三道题围绕卷积操作的关键参数：

| 概念 | 答案 | 作用 | 题号 |
|---|---|---|---|
| **Padding（填充）** | 保留边缘信息 | 防止边缘像素被忽略 | Q25 |
| **Weights and Bias（权重和偏置）** | 可学习参数 | CNN通过训练自动调整这两个参数 | Q26 |
| **Stride（步长）** | 滤波器滑动步长 | 控制输出尺寸 | Q28 |

> 💡 **核心洞察：** **Q26 是本章最关键的题**——为什么 CNN 能"自动学习特征"？因为滤波器的权重（Weights）不是人工设定的，而是通过训练数据**自动学习**的！偏置（Bias）提供平移灵活性。这就是 CNN 相比 SIFT/HOG 的本质优势。

### 3.3 卷积计算题（Q31, Q32）

**Q31（2分）** 考公式应用：

```
Output = (Input - Filter + 2×Padding) / Stride + 1
       = (32 - 5 + 0) / 1 + 1 = 28

→ 输出：28 × 28 × 16
```

> ⚠️ **关键：** 16 是滤波器数量，决定输出深度（通道数），不影响空间维度计算。

**Q32（3分）** 考手动卷积计算：

给定 5×5 的矩阵 A 和 3×3 的卷积核 K = `[[-2,0,2],[-2,0,2],[-2,0,2]]`：

```
Matrix A:                Kernel K:
| 1  5  3  9  0 |       | -2  0  2 |
| 5  9  6  1  2 |       | -2  0  2 |
| 7  1  9  0  1 |       | -2  0  2 |
| 8  2  3  4  8 |
| 6  7  8  5  9 |

输出尺寸 = ((5-3)/1+1) × ((5-3)/1+1) = 3 × 3
```

> 💡 **计算技巧：** Kernel 左列全是 -2，中列全是 0，右列全是 2。每个输出位置 = -2×(左列三元素之和) + 2×(右列三元素之和)，即 **2×(右列之和 - 左列之和)**。
>
> 例如 (0,0)：对应区域左列=[1,5,7]=-2×13=-26，右列=[3,6,9]=2×18=36 → -26+36 = **10**

结果矩阵：
```
 10  -10  -30
 -4  -14  -14
 -2   -2   -4
```

## 🏆 第四章：训练与评估——让模型越来越好

### 4.1 数据准备（Q8, Q17）

训练 CNN 之前需要准备数据：

- **Q17**：**Data Annotation（数据标注）** = 用类别名称标注图像——告诉模型"这是猫"、"这是狗"
- **Q8**：**Data Augmentation（数据增强）** = **扩展**训练数据集（旋转、翻转、裁剪 → 一张图变多张）

> ⚠️ **易错点：** 数据增强的目的是"扩展训练集"（expand），不是"减小数据集"。它不改变灰度/归一化，那是预处理。

### 4.2 激活函数选择（Q9, Q15）

这两道题形成了一个完美的对比：

| 场景 | 正确选择 | 原因 | 题号 |
|---|---|---|---|
| 二分类 | **Sigmoid** | 输出压缩到 (0,1)，天然适合概率解释 | Q9 |
| 缓解梯度消失 | **ReLU** | 正数区域梯度恒为1，不会衰减 | Q15 |

> ⚠️ **考试陷阱：** Sigmoid 虽然适合二分类输出层，但在隐藏层会导致梯度消失。ReLU 适合隐藏层但不适合输出层。

### 4.3 损失与评估（Q19, Q18, Q24）

模型训练需要量化"表现好不好"：

- **Q19**：**Loss Function（损失函数）** = 量化预测与真实结果的差异
- **Q24**：**Accuracy（准确率）** = 正确预测占总预测的比例
- **Q18**：ROC 曲线横轴 = **False Positive Rate（假阳性率）**

> 💡 **ROC 记忆法：** 横轴是"犯错率"（FPR），纵轴是"正确率"（TPR）。完美模型在左上角（不犯错 + 全找到），随机猜测在对角线上。

### 5.1 机器视觉的工业应用（Q11）

所有这些技术最终服务于现实世界。**Q11** 考的是：

> 机器视觉在**Manufacturing（制造业）** 的装配线上用于质量检查

### 5.2 技术进化的转折点（Q13）

**Q13** 是一道历史观的题目：

> 深度学习技术的兴起（The rise of deep learning techniques）是机器视觉发展的重要转折点

不是数码相机（那是成像硬件），不是CCD传感器（那更早），而是**深度学习**——因为它让机器从"人工设计规则"进化到"自动学习规则"。

## 📝 考试复习检查清单

### 基础概念（必考）
- [ ] 像素定义 = 图像中某位置的数值表示
- [ ] 滤波 = 通过改变像素增强图像
- [ ] 锐化 vs 模糊 的区别
- [ ] 形态学运算 = 基于形状处理图像
- [ ] 开运算 vs 闭运算 的顺序区别
- [ ] 轮廓（Contour）的定义 + `cv2.findContours()` 函数名
- [ ] 图像梯度 = 度量强度方向变化
- [ ] Canny 使用双阈值化（Double thresholding）
- [ ] 分割目的 = 提取对象 → 输出二值图 → 可用阈值化实现

### 特征检测（必记全称）
- [ ] SIFT = Scale Invariant Feature Transform
- [ ] ORB = Oriented FAST and Rotated BRIEF
- [ ] HOG 用于人体检测
- [ ] 特征描述符 = 提供检测特征的唯一表示

### CNN 核心（必考计算）
- [ ] CNN隐藏层 = 卷积层 + 池化层 + 全连接层
- [ ] 可学习参数 = Weights + Bias
- [ ] Padding 保留边缘信息
- [ ] Stride = 滤波器滑动步长
- [ ] 输出尺寸公式：`(Input - Filter + 2×Padding) / Stride + 1`
- [ ] 最后一层神经元数 = 类别数
- [ ] **手动卷积计算**（注意核大小、步长、无填充时的输出维度）

### 训练与评估（易混淆）
- [ ] 数据标注（Annotation）vs 数据增强（Augmentation）的区别

- [ ] 损失函数 = 量化预测与真实的差异
