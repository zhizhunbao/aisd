# Week 2 故事线：图像处理的九般武艺——从噪声中拯救信息

> **Source:** `Week 2 - Fundamentals of Image Processing1.pptx`
> **核心主题：** 拿到一张原始图像后，怎么处理它才能让机器"看懂"？
> **故事线：** 原始图像充满噪声和干扰 → 一步步用滤波、边缘检测、阈值化、形态学操作来"清洗"和"提炼"→ 最终得到干净、有用的信息

---

## 🎬 序幕：为什么需要图像处理？

上一讲（Week 1）我们知道了机器视觉的三步走：**采集 → 处理 → 决策**。

采集到的原始图像往往是"脏"的：
- 📸 光线不均匀导致明暗不一
- 🌫️ 传感器噪声让图像变得模糊
- 🔲 前景和背景混在一起，难以分离

**核心问题：如何从一张"脏"的原始图像中，提取出机器能理解的干净信息？**

> 💡 **类比：** 图像处理就像淘金——原始图像是沙砾混杂的河床，我们需要用各种工具（筛子、水流、化学试剂）把金子从沙子中分离出来。

## 📚 第一章：图像处理的九阶段全景图

图像处理不是单一操作，而是一个**工具箱**。根据需求选择工具组合：

```
┌─────────────────────────────────────────────────────────────┐
│ 图像处理九阶段（不是每次都全用，按需组合 2-3 步即可）         │
│                                                             │
│ 1. 采集 (Acquisition)        → 获取原始图像                 │
│ 2. 增强 (Enhancement)        → 改善质量（对比度、亮度）     │
│ 3. 复原 (Restoration)        → 去除退化（去噪、去模糊）     │
│ 4. 形态学处理 (Morphological) → 基于形状的操作               │
│ 5. 分割 (Segmentation)       → 分离前景/背景（最难！）       │
│ 6. 目标识别 (Recognition)    → 给物体贴标签                 │
│ 7. 表示与描述 (Representation)→ 用特征向量描述物体           │
│ 8. 压缩 (Compression)        → 减少存储空间                 │
│ 9. 彩色处理 (Color Processing)→ 利用颜色信息                │
└─────────────────────────────────────────────────────────────┘
```

> 🔑 **关键考点：** 不是每个任务都需要全部九步！根据应用场景，通常只需要 2-3 步的组合。

## 🎭 第二章：滤波——给图像做"SPA"

### 2.1 为什么需要滤波？

原始图像往往含有**噪声**（传感器引入的随机干扰），需要先"平滑"掉噪声，才能进行后续分析。

> 💡 **类比：** 滤波器就像筛子——让好的信息通过，把噪声挡住。

### 2.2 模糊 (Blurring)——降噪利器

模糊通过**对邻域像素取平均**来平滑图像，消除急剧的强度变化。

**三种主要模糊方法对比：**

| 方法 | 原理 | 特点 | 最佳用途 |
| ---- | ---- | ---- | ---- |
| **均值模糊** (Average) | 所有邻域像素等权平均 | 简单但会模糊边缘 | 一般降噪 |
| **高斯模糊** (Gaussian) | 中心像素权重大，周边权重小（钟形曲线） | 保边效果较好 | 多数场景首选 |
| **中值模糊** (Median) | 取邻域像素的**中值** | 对极端值（椒盐噪声）特别有效 | 椒盐噪声去除 |

> 💡 **考试陷阱：** 高斯模糊的核**不是**等权的！它按高斯（钟形）分布分配权重，中心高、周边低。均值模糊才是等权。

**均值模糊计算示例：**

3×3 区域像素值：`[[80, 90, 85], [95, 100, 110], [105, 115, 120]]`

```
均值 = (80+90+85+95+100+110+105+115+120) / 9 = 900 / 9 = 100
```

### 2.3 锐化 (Sharpening)——增强细节

锐化与模糊**相反**：它**增大**相邻像素的对比度，使边缘更清晰。

| 维度 | 模糊 (Blurring) | 锐化 (Sharpening) |
| ---- | :----: | :----: |
| 对噪声 | ✅ 减少噪声 | ❌ **放大**噪声 |
| 对细节 | ❌ 减少细节 | ✅ 增强细节 |
| 典型用途 | 预处理降噪 | 医学影像、精密制造 |

> 🔑 **实用技巧：** 先模糊去噪，再适度锐化恢复细节。单独使用任一种效果都不够好。

## 📖 第三章：Canny 边缘检测——五步定位物体轮廓

### 3.1 为什么需要边缘检测？

模糊和锐化是"清洗"图像，但机器视觉的核心任务是**找到物体**。物体的第一个线索就是它的**边缘**——像素强度急剧变化的地方。

### 3.2 Canny 算法的五步流水线

Canny 是最经典的边缘检测算法，它通过五个精心设计的步骤来精确提取边缘：

```
Step 1: 高斯平滑          → 先降噪（否则噪声会被误认为边缘）
    │
    ▼
Step 2: 梯度计算          → 用 Sobel 核计算每个像素的梯度幅值和方向
    │
    ▼
Step 3: 非极大值抑制 (NMS) → 把粗边缘细化为 1 像素宽的精确线条
    │
    ▼
Step 4: 双阈值分类        → 用高/低两个阈值分为：强边缘、弱边缘、非边缘
    │
    ▼
Step 5: 滞后边缘跟踪      → 弱边缘连着强边缘 → 保留；孤立弱边缘 → 丢弃
```

### 3.3 每步详解

**Step 1: 高斯平滑 (Gaussian Smoothing)**
- 目的：减少噪声干扰（噪声会产生虚假边缘）
- 方法：用高斯滤波器卷积图像

**Step 2: 梯度计算 (Gradient Calculation)**
- 用 **Sobel 核**分别在水平和垂直方向计算一阶导数
- 得到每个像素的**梯度幅值**（变化有多大）和**梯度方向**（变化朝哪个方向）

**Step 3: 非极大值抑制 (Non-Maximum Suppression, NMS)**
- 问题：Sobel 产生的边缘很"粗"（多像素宽）
- 解决：沿梯度方向，只保留**局部最大值**的像素，其余设为 0
- 效果：将粗边缘**细化为 1 像素宽**的精确线条

**Step 4: 双阈值 (Double Thresholding)**
- 设置两个阈值：高阈值 (T_high) 和低阈值 (T_low)
- 梯度 ≥ T_high → **强边缘** ✅
- T_low ≤ 梯度 < T_high → **弱边缘** ⚠️
- 梯度 < T_low → **非边缘** ❌

**Step 5: 滞后边缘跟踪 (Hysteresis Edge Tracking)**
- 弱边缘如果**连接着**强边缘 → 保留（它是真实边缘的一部分）
- 弱边缘如果**孤立**（周围没有强边缘）→ 丢弃（它只是噪声）

> 💡 **考试记忆口诀：** "**高梯非双滞**" = 高斯平滑 → 梯度计算 → 非极大值抑制 → 双阈值 → 滞后跟踪

## 🏆 第四章：直方图——读懂图像的"体检报告"

### 4.1 什么是直方图？

**直方图 (Histogram)** 展示图像中像素强度值的分布：
- **X 轴**：亮度级别 [0-255]（0=黑，255=白）
- **Y 轴**：每个亮度级别有多少像素

### 4.2 如何"读"直方图？

| 直方图特征 | 图像特点 |
| ---- | ---- |
| 分布偏**左** | 整体**偏暗** |
| 分布偏**右** | 整体**偏亮** |
| 分布**均匀展开** | 对比度**好** |
| 集中在**窄范围** | 对比度**低** |

### 4.3 Bins（分箱）

可以将 [0-255] 分成更少的区间（bins）来简化直方图：
- 默认 256 bins（每个亮度值一个）
- 可以分成 16 bins：[0-15], [16-31], ..., [240-255]

## 📖 第五章：阈值化——一刀切出黑白世界

### 5.1 为什么需要阈值化？

很多视觉任务需要把图像变成**二值图**（只有 0 和 1）：
- 1 = 感兴趣的前景
- 0 = 背景

### 5.2 简单阈值 vs 自适应阈值

| 方法 | 原理 | 优势 | 局限 |
| ---- | ---- | ---- | ---- |
| **简单阈值** (Simple) | 所有像素用**同一个**全局阈值 | 简单快速 | 光照不均匀时失败 |
| **自适应阈值** (Adaptive) | 每个像素根据**局部邻域**计算自己的阈值 | 处理不均匀光照 | 稍慢 |

> 🔑 **故事转折点：** 简单阈值在理想光照下工作得很好，但现实世界的图像**光照不均匀**——左边亮、右边暗。一个全局阈值无法同时处理两边 → 自适应阈值登场！

## 📖 第六章：形态学操作——基于形状的图像"整形手术"

### 6.1 四种基本操作

阈值化之后的二值图像往往还有小缺陷（噪声白点、物体内部小黑洞）。形态学操作用来修复这些问题：

| 操作 | 原理 | 效果 | 用途 |
| ---- | ---- | ---- | ---- |
| **腐蚀** (Erosion) | 核下**所有**像素=1 才输出1 | 缩小白色区域 | 去除小白噪声、分离连通物体 |
| **膨胀** (Dilation) | 核下**至少一个**像素=1 就输出1 | 扩大白色区域 | 连接断裂部分、填充缺口 |
| **开运算** (Opening) | 先腐蚀 → 再膨胀 | 去除小白噪声（不破坏大物体） | 噪声去除 |
| **闭运算** (Closing) | 先膨胀 → 再腐蚀 | 填充小黑洞（不改变整体形状） | 孔洞填充 |

> 💡 **记忆技巧：** 
> - **开运算** = "**先腐后膨**"（先侵蚀小噪声，再膨胀恢复主体）
> - **闭运算** = "**先膨后腐**"（先膨胀填洞，再腐蚀恢复形状）

### 6.2 腐蚀与膨胀的互补性

```
原始二值图 → 腐蚀（去噪）→ 噪声消失，但物体也缩小了
                                    │
                                    ▼
                          膨胀（恢复）→ 物体恢复大小，噪声不会回来（因为已经被彻底去除）
```

这就是**开运算 (Opening)** 的原理！

## 📖 第七章：图像变换——几何操作

### 7.1 仿射变换 (Affine Transformation)

**公式：y = Ax + b**

| 符号 | 含义 |
| ---- | ---- |
| **x** | 输入坐标向量 |
| **A** | 线性变换矩阵（旋转、缩放、剪切） |
| **b** | 平移向量 |
| **y** | 输出坐标向量 |

**关键性质：保持直线和平行性**——直线变换后仍是直线，平行线仍平行。

### 7.2 四种变换类型

| 变换 | 效果 | OpenCV 函数 |
| ---- | ---- | ---- |
| **平移** (Translation) | 在 x 或 y 方向移动 | `cv2.warpAffine()` |
| **旋转** (Rotation) | 围绕指定点旋转 | `cv2.getRotationMatrix2D()` |
| **缩放** (Scaling) | 改变图像大小 | `cv2.resize()` |
| **剪切** (Shearing) | 沿轴方向倾斜 | `cv2.warpAffine()` |
