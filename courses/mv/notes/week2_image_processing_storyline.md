# Week 2: 图像处理基础 — 故事线 (Storyline)

> 📖 Source: `week2_image_processing_slides.md` + `week2_image_processing_complete_demo.py`
> 🎯 核心问题：**拿到一张原始图像后，怎么一步步把它变成机器能"理解"的信息？**

---

## 📍 路线图 (Roadmap)

```
原始图像（有噪声、模糊、光照不均）
  ↓
[问题] 噪声干扰分析
  ↓
[方案A] 滤波/模糊 → 平滑噪声 (均值滤波, 高斯滤波, 中值滤波)
  ↓
[问题] 模糊后细节丢失
  ↓
[方案B] 锐化 → 增强边缘和细节
  ↓
[问题] 需要找到物体的边界
  ↓
[方案C] 边缘检测 (Canny) → 5步流水线精确提取边缘
  ↓
[问题] 需要分离前景和背景
  ↓
[方案D] 阈值化 → 简单/自适应二值分割
  ↓
[问题] 二值图有小噪点和断裂
  ↓
[方案E] 形态学操作 → 腐蚀/膨胀/开运算/闭运算 清理形状
  ↓
[问题] 需要对齐、缩放、旋转图像
  ↓
[方案F] 仿射变换 → 平移/旋转/缩放/剪切
  ↓
[结果] 干净、增强、可分析的图像 → 送入后续识别/分类
```

## 🔗 因果叙事 (Causal Narrative)

### 第一幕：图像处理是什么？— 机器视觉的基石

**核心问题：** Week 1 讲了机器视觉工作流的三步（采集→处理→决策），"处理"这一步到底做什么？

图像处理 = **对像素矩阵的数学操作**，目的是：

1. **增强** — 让图像更适合分析（降噪、增强对比度）
2. **提取** — 从像素中提取有意义的信息（边缘、轮廓、区域）
3. **变换** — 改变图像的几何属性（缩放、旋转）

> 💡 类比：图像处理就像是给原始食材"洗切配" — 你不会直接拿一棵沾满泥的白菜就下锅，你需要先洗净（降噪）、切块（分割）、摆盘（变换），然后才能"做菜"（识别/分类）。

课程涵盖 **9 个关键阶段**：采集 → 增强 → 复原 → 形态学 → 分割 → 识别 → 表示/描述 → 压缩 → 彩色处理。但**并非每个任务都需要全部 9 步** — 根据应用选择 2-3 步即可。

---

### 第二幕：滤波 — 像素的"筛子"

**核心问题：** 真实世界的图像总有噪声（传感器、光照、传输），怎么去掉噪声？

滤波器像一个**滑动窗口（kernel/核）**在图像上移动，对窗口内的像素做数学运算，生成新的像素值。

#### 模糊（Blurring）— 平滑噪声

- **原理：** 用核内像素的**平均值**替代中心像素 → 平滑急剧变化
- **均值滤波（Average）**：所有权重相等 `[[1,1,1],[1,1,1],[1,1,1]] / 9`
- **高斯滤波（Gaussian）**：中心权重大、边缘权重小 → 更自然的平滑
- **中值滤波（Median）**：取中位数而非平均值 → 对椒盐噪声效果最好

> ⚠️ **代价：** 模糊在去噪的同时也会**丢失细节**——这是一个取舍。核越大，去噪越彻底，但细节损失越多。

#### 锐化（Sharpening）— 增强细节

- **原理：** 与模糊相反，放大相邻像素的强度差异 → **突出边缘**
- 通过核中的负值（周围）和大的正值（中心）实现
- **用途：** 医学影像中看清细微结构、精密制造中检测微小缺陷

> 💡 模糊和锐化是一对矛盾：模糊去噪但丢细节，锐化增细节但放大噪声。实际应用中常**先模糊再锐化**。

---

### 第三幕：边缘检测 — Canny 五步流水线

**核心问题：** 怎么找到图像中物体的边界？

边缘 = **像素强度急剧变化的地方**。Canny 算法是公认的最优边缘检测器，分5步：

```
原始图像
    ↓
① 高斯模糊 → 去除噪声（避免假边缘）
    ↓
② Sobel梯度 → 计算每个像素的梯度强度和方向
    ↓
③ 非极大值抑制(NMS) → 把"粗"边缘变成1像素宽的"细"线
    ↓
④ 双阈值分类 → 分出强边缘、弱边缘、非边缘
    ↓
⑤ 滞后跟踪 → 弱边缘只有连着强边缘才保留
    ↓
最终边缘图
```

| 步骤         | 做什么 | 为什么                             |
| ------------ | ------ | ---------------------------------- |
| ① 高斯模糊   | 平滑   | 噪声会产生假梯度                   |
| ② Sobel 梯度 | 求导   | 边缘 = 强度变化大的地方            |
| ③ NMS        | 细化   | 梯度会产生粗边带                   |
| ④ 双阈值     | 分类   | 区分真边缘和噪声引起的弱响应       |
| ⑤ 滞后跟踪   | 连接   | 弱边缘若连着强边缘→保留；孤立→丢弃 |

> ⚠️ **考试要点：** Canny 需要两个阈值参数：`low_threshold` 和 `high_threshold`。高阈值决定"强边缘"，低阈值决定"弱边缘"。

### 第四幕：直方图 — 图像的"体检报告"

**核心问题：** 怎么一眼判断一张图像是偏暗、偏亮还是均衡？

- 直方图 = X轴(像素值 0-255) × Y轴(该值出现的像素数)
- **左偏** = 图像偏暗；**右偏** = 图像偏亮；**均匀** = 高对比度
- **Bins**：可以把 0-255 分成更粗的区间（如 16 bin = 每个 bin 覆盖 16 个像素值）

**直方图均衡化**：重新分配像素值，使直方图更均匀 → 增强对比度，暗区细节变可见。

> 💡 类比：直方图就像考试成绩分布图——左偏说明大家都考得差，右偏说明都考得好，均匀分布说明出题合理。均衡化就像"强制调分"使成绩均匀分布。

---

### 第五幕：阈值化 — 最简单的分割方法

**核心问题：** 怎么把前景物体从背景中分离出来？

- **简单阈值**：设一个固定值 T，像素 ≤ T → 0（黑），> T → 255（白）
- **问题：** 如果图像光照不均（左边亮右边暗），一个固定T无法适应
- **自适应阈值**：对每个像素，根据其**局部邻域**计算不同的 T → 适应光照变化

| 类型              | 阈值来源         | 适用场景       |
| ----------------- | ---------------- | -------------- |
| **简单阈值**      | 全局固定值       | 光照均匀的场景 |
| **自适应阈值**    | 局部邻域计算     | 光照不均的场景 |
| **Otsu 自动阈值** | 自动从直方图计算 | 双峰分布的图像 |

---

### 第六幕：形态学操作 — 清理二值图的"手术刀"

**核心问题：** 阈值化后的二值图有小噪点、孔洞和断裂，怎么清理？

四个基本操作，两两组合：

```
腐蚀(Erosion)         膨胀(Dilation)
  缩小白区域             扩大白区域
  去小白噪点             填小黑孔洞
  分离粘连对象           连接断裂部分
       ↓                     ↓
开运算(Opening)        闭运算(Closing)
= 先腐蚀后膨胀         = 先膨胀后腐蚀
  去噪点但保形状         填孔洞但保形状
```

| 操作       | 公式          | 效果       | 用途               |
| ---------- | ------------- | ---------- | ------------------ |
| **腐蚀**   | 核下全1才保留 | 缩小物体   | 去小白点、分离粘连 |
| **膨胀**   | 核下有1就扩展 | 扩大物体   | 填小孔、连接断裂   |
| **开运算** | 腐蚀→膨胀     | 去噪但保形 | 去除小白噪声       |
| **闭运算** | 膨胀→腐蚀     | 填孔但保形 | 填充前景内小孔     |

> ⚠️ **考试陷阱：** 开运算是**先腐蚀后膨胀**（不是反过来！），闭运算是**先膨胀后腐蚀**。

---

### 第七幕：仿射变换 — 图像的几何操作

**核心问题：** 怎么移动、旋转、缩放图像？

**仿射变换公式：** y = Ax + b

| 变量 | 含义                           |
| ---- | ------------------------------ |
| x    | 输入坐标向量                   |
| A    | 线性变换矩阵（旋转/缩放/剪切） |
| b    | 平移向量                       |
| y    | 输出坐标向量                   |

四种基本变换：

- **平移 (Translation)**：x/y 方向移动
- **旋转 (Rotation)**：围绕某点旋转
- **缩放 (Scaling)**：放大/缩小
- **剪切 (Shearing)**：沿某轴倾斜

> 💡 关键性质：仿射变换**保持直线和平行性** — 直线变换后还是直线，平行线还是平行的。

## 📊 对比总结表

### 模糊方法对比

| 方法         | 核/原理       | 噪声类型 | 保边能力 | 计算速度 |
| ------------ | ------------- | -------- | -------- | -------- |
| **均值模糊** | 等权平均      | 高斯噪声 | 差       | 快       |
| **高斯模糊** | 中心权重大    | 高斯噪声 | 中       | 中       |
| **中值模糊** | 取中位数      | 椒盐噪声 | 好       | 慢       |
| **双边滤波** | 距离+强度权重 | 高斯噪声 | 最好     | 最慢     |

### 阈值化方法对比

| 方法           | 阈值来源   | 适用场景 | OpenCV 函数                           |
| -------------- | ---------- | -------- | ------------------------------------- |
| **简单阈值**   | 手动设定   | 光照均匀 | `cv2.threshold()`                     |
| **自适应阈值** | 局部邻域   | 光照不均 | `cv2.adaptiveThreshold()`             |
| **Otsu**       | 直方图自动 | 双峰分布 | `cv2.threshold(..., cv2.THRESH_OTSU)` |

### 本周工具链总结

| 步骤 | 技术      | 输入 → 输出           | 目的          |
| ---- | --------- | --------------------- | ------------- |
| 1    | 滤波/模糊 | 有噪图 → 平滑图       | 降噪          |
| 2    | 锐化      | 平滑图 → 增强图       | 增强细节      |
| 3    | Canny     | 灰度图 → 边缘图       | 找边界        |
| 4    | 直方图    | 图像 → 分布图         | 分析亮度      |
| 5    | 阈值化    | 灰度图 → 二值图       | 分割前景/背景 |
| 6    | 形态学    | 二值图 → 清理后二值图 | 去噪/填孔     |
| 7    | 仿射变换  | 图像 → 变换后图像     | 几何对齐      |
