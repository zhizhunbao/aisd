## 🎬 序幕：我们在解决什么问题？

想象你走进一家工厂，流水线上每秒经过 100 个零件。你需要检查每一个零件是否有缺陷——裂纹、缺角、颜色不均。人眼会累、会漏检、会因光线变化而误判。

**核心问题：能不能让机器代替人眼来"看"，而且看得更快、更准、更持久？**

这就是 **机器视觉 (Machine Vision)** 要解决的问题。

> 💡 **一句话定义：** 机器视觉 = 让机器具备"采集图像 → 理解图像 → 做出决策"的完整能力。

## 📚 第一章：机器视觉 vs 计算机视觉——别搞混了

### 1.1 两个容易混淆的概念

很多人把 **Machine Vision** 和 **Computer Vision** 当同义词，但它们有关键区别：

| 维度 | 机器视觉 (Machine Vision) | 计算机视觉 (Computer Vision) |
| ---- | :----: | :----: |
| 重点 | **完整系统**（硬件 + 软件 + 决策） | **算法**（图像理解） |
| 包含硬件？ | ✅ 相机、传感器、光源、机械臂 | ❌ 只关注算法 |
| 典型场景 | 工厂检测、机器人引导 | 学术研究、算法开发 |
| 类比 | 一辆完整的自动驾驶汽车 | 汽车里的"眼睛"算法 |

> 💡 **记忆技巧：** Machine Vision = **从镜头到动作的全套方案**；Computer Vision = **从像素到理解的算法核心**。本课程标题虽是 Machine Vision，但重点学习的是 Computer Vision 的核心算法。

### 1.2 机器视觉的定义

**Machine Vision** 是一种使机器能够**解读和理解**周围环境视觉信息的技术。它包括三步：

1. **采集 (Capture)**：用摄像头或传感器获取图像/视频
2. **处理 (Process)**：提取有用信息
3. **决策 (Decide)**：基于信息做出行动

## 🎭 第二章：从胶片到深度学习——机器视觉简史

### 2.1 三个里程碑

机器视觉的发展不是一蹴而就的，它经历了三个关键阶段：

| 阶段 | 时间 | 核心突破 | 代表技术 |
| ---- | ---- | ---- | ---- |
| 📷 硬件时代 | 1960s-1990s | 数码相机、CCD/CMOS 传感器 | 图像数字化 |
| 🧮 算法时代 | 1999-2012 | 手工特征提取算法 | SIFT (1999), HOG |
| 🧠 深度学习时代 | 2012-至今 | 神经网络自动学特征 | AlexNet (2012), CNN |

### 2.2 重要转折点：AlexNet 与 ImageNet 2012

2012 年，**AlexNet** 在 ImageNet 大赛中以碾压性优势获胜，错误率从 26% 降到 16%。这一刻标志着：

- **之前**：人类手动设计特征（SIFT、HOG）→ 费时、领域依赖
- **之后**：CNN 自动从数据中学习特征 → 通用、可扩展

> 🔑 **故事转折点：** 深度学习不是"取代"传统方法，而是在需要**大规模、复杂模式识别**的场景中远超传统方法。但在工业检测等**受控环境**中，传统方法（模板匹配、阈值化）依然因**更快、更便宜、更可解释**而被广泛使用。

## 📖 第三章：关键技术三件套

### 3.1 图像传感器——机器的"视网膜"

机器视觉的第一步是用传感器采集图像。两种主流传感器：

| 传感器 | CCD (电荷耦合器件) | CMOS (互补金属氧化物半导体) |
| ---- | :----: | :----: |
| 图像质量 | ✅ 更高（低噪声） | ⚠️ 稍低（但差距缩小） |
| 功耗 | ❌ 高 | ✅ 低 |
| 制造成本 | ❌ 贵 | ✅ 便宜 |
| 主导市场 | 科学/医学相机 | 📱 手机、消费相机 |

> 💡 **记忆技巧：** CMOS = **C**heap **M**obile **O**ptimized **S**ensor（便宜、移动端、优化的传感器）。

### 3.2 图像处理技术——机器的"视觉皮层"

获取图像后需要处理：
- **滤波 (Filtering)**：降噪、平滑
- **边缘检测 (Edge Detection)**：找到物体的轮廓

这些将在 **Week 2** 详细展开。

### 3.3 机器学习/深度学习——机器的"大脑"

处理后的图像交给算法来"理解"：
- **传统 ML**：手工提取特征 → 分类器（SVM, 决策树）
- **深度学习 (CNN)**：端到端学习，自动提取特征 → 自动分类

CNN 将在 **Week 4** 详细讲解。

## 📖 第五章：机器视觉的工作流——三步走

每个机器视觉系统都遵循同一个基本流程：

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 1. Image         │     │ 2. Image         │     │ 3. Interpretation│
│    Acquisition   │ ──► │    Processing    │ ──► │    / Action      │
│    图像采集       │     │    图像处理       │     │    解读/行动      │
│                  │     │                  │     │                  │
│ 相机/传感器      │     │ 滤波、边缘检测   │     │ 分类、检测、决策  │
│ 获取原始图像     │     │ 特征提取         │     │ 输出结果         │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**例子：** 工厂自动检测系统
1. 📷 工业相机拍摄零件照片
2. 🔧 图像处理提取边缘和缺陷特征
3. ✅/❌ 判断合格/不合格，驱动机械臂分拣

## 📖 第六章：图像处理基础概念

### 6.1 像素——图像的"原子"

- **像素 (Pixel)** = 图像中位置 (x, y) 处的数值
- **灰度图 (Grayscale)**：每个像素 1 个值 [0-255]，0=黑，255=白
- **彩色图 (RGB)**：每个像素 3 个值 [R, G, B]，各 [0-255]

### 6.2 色彩空间——RGB vs HSV

| 色彩空间 | 组成 | 优势 | 应用场景 |
| ---- | ---- | ---- | ---- |
| **RGB** | 红、绿、蓝 | 直观 | 显示器、图像存储 |
| **HSV** | 色相、饱和度、明度 | 颜色与亮度分离 | 颜色检测、物体追踪 |

> 💡 **为什么 HSV 更适合颜色检测？** 因为 HSV 的 H（色相）通道把"是什么颜色"独立出来，不受光照变化影响。想象在不同光线下找一个红色苹果——RGB 值会大幅变化，但 HSV 的 H 值基本不变。

### 6.3 图像格式

| 格式 | 压缩类型 | 透明度 | 适用场景 |
| ---- | ---- | ---- | ---- |
| **JPEG** | 有损压缩 | ❌ | 照片、网页 |
| **PNG** | 无损压缩 | ✅ Alpha通道 | 图标、需要透明的场景 |
| **RAW** | 无压缩 | ❌ | 专业摄影、科学成像 |

### 7.1 CNN 预告

**卷积神经网络 (CNN)** 是一类专门为视觉任务设计的深度神经网络：
- 能**自动提取特征**（不需要人工设计 SIFT、HOG 等）
- 在图像分类、目标检测等任务上表现卓越
- 将在 **Week 4** 正式登场
