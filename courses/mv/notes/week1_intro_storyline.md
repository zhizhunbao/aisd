## 🔗 因果叙事 (Causal Narrative)

### 第一幕：机器需要"眼睛" — 图像采集

**核心问题：** 人类用视网膜感光，机器用什么？

物理世界是连续的光信号，机器无法直接理解。因此需要**图像传感器**将光信号转换为数字信号：

- **CCD（电荷耦合器件）**：高画质、低噪声，但贵、功耗高 → 用于医学影像、天文望远镜等对质量要求极高的场景
- **CMOS（互补金属氧化物半导体）**：便宜、低功耗 → 用于手机、消费级相机

> 💡 类比：CCD 像专业摄影师的全画幅单反，CMOS 像手机摄像头 — 性能差距在缩小，但成本差距依然存在

**结果：** 光信号被转换为**数字矩阵** — 每个元素就是一个**像素（Pixel）**。

---

### 第二幕：数字矩阵的"语言" — 像素与色彩

**核心问题：** 传感器给了一堆数字，这些数字怎么表示颜色和形状？

一张图像就是一个数字矩阵：

- **灰度图**：二维矩阵 `(H × W)`，每个像素是 `[0, 255]` 的单一亮度值
- **彩色图（RGB）**：三维张量 `(H × W × 3)`，每个像素是 `(R, G, B)` 三元组

但 RGB 有一个大问题 — **光照变化会同时影响三个通道**。比如同一个红苹果，在阳光下和阴影中的 RGB 值差异很大。

**解决方案：HSV 色彩空间**，将颜色分解为：

- **H (Hue/色相)**：颜色本身（0°-360°）→ 不受亮度影响
- **S (Saturation/饱和度)**：颜色的鲜艳程度
- **V (Value/明度)**：亮度

> 💡 类比：RGB 像"这个颜色是 128 红 + 0 绿 + 255 蓝"——很精确但不直觉；HSV 像"这是一个很鲜艳的紫色，中等亮度"——更接近人类描述颜色的方式

**为什么重要？** 在做颜色检测（如"找出画面中所有红色物体"）时，HSV 只需要限定 H 通道的范围，而 RGB 需要复杂的三通道联合判断。

---

### 第三幕：存储的取舍 — 图像格式

**核心问题：** 图像矩阵很大，怎么存储和传输？

不同格式在**质量、体积、功能**之间做取舍：

| 格式     | 压缩方式 | 透明度? | 适用场景                        |
| -------- | -------- | ------- | ------------------------------- |
| **JPEG** | 有损压缩 | ❌      | 照片、网页 — 文件小但细节丢失   |
| **PNG**  | 无损压缩 | ✅      | 图标、截图 — 完美还原但文件较大 |
| **RAW**  | 无压缩   | ❌      | 专业摄影 — 最大信息量但文件巨大 |

> ⚠️ **考试陷阱**：JPEG 是**有损**压缩，不是无损! PNG 才是无损的。

---

### 第四幕：从像素到理解 — 机器视觉系统工作流

**核心问题：** 有了图像，机器怎么"理解"图像内容并做出决策？

完整的机器视觉系统分三步：

```
1. Image Acquisition     →  2. Image Processing      →  3. Interpretation/Action
   图像采集                    图像处理                    解读与行动
   (相机/传感器)              (滤波/特征提取/分类)       (做出决策)
```

**制造业例子：**

- 步骤 1：摄像头拍摄流水线上的产品
- 步骤 2：算法检测产品表面是否有划痕
- 步骤 3：有划痕 → 自动剔除；无划痕 → 放行

> 💡 **Machine Vision vs Computer Vision 的区别：**
>
> - **Machine Vision** = 完整系统（硬件 + 软件 + 决策）→ 工业级，强调端到端
> - **Computer Vision** = 算法部分 → 学术向，强调图像理解算法

---

### 第五幕：从手工到自动 — 深度学习革命

**核心问题：** 传统方法需要人类专家手动设计特征（SIFT、HOG、边缘检测），太慢、太脆弱、不通用。有没有更好的方法？

```
传统 CV 流水线                    深度学习流水线
─────────────                    ─────────────
Input Image                      Input Image
    ↓                                ↓
Hand-crafted Features            CNN
(SIFT, HOG, edges)               (自动学习特征!)
    ↓                                ↓
Feature Extraction               Fully Connected
(人工设计)                        Classifier
    ↓                                ↓
Classifier (SVM, kNN)            Output
    ↓
Output
```

**关键转折点：2012 年 AlexNet 赢得 ImageNet 竞赛**

- AlexNet 用 CNN 自动学习特征，准确率远超手工方法
- 从此开启了深度学习主导机器视觉的时代

> ⚠️ **但传统方法并没有死！** 在以下场景中，传统方法仍然更合适：
>
> - 工业检测中的简单模板匹配（更快、更便宜）
> - 数据量不足以训练深度网络
> - 需要可解释性的场景

## 📊 对比总结表

| 维度         | 传统 CV                | 深度学习 CV       |
| ------------ | ---------------------- | ----------------- |
| **特征设计** | 手工设计 (SIFT, HOG)   | 自动学习 (CNN)    |
| **数据需求** | 小数据集可用           | 需要大量标注数据  |
| **可解释性** | 高（每步可追踪）       | 低（黑箱）        |
| **通用性**   | 低（每任务需重新设计） | 高（迁移学习）    |
| **计算成本** | 低（CPU 可运行）       | 高（需要 GPU）    |
| **精度**     | 受限于人类设计能力     | 通常更高          |
| **代表算法** | SIFT, HOG, 模板匹配    | CNN, ResNet, YOLO |

| 格式 | 压缩 | 透明度 | 文件大小 | 典型用途               |
| ---- | ---- | ------ | -------- | ---------------------- |
| JPEG | 有损 | ❌     | 小       | 照片、网页             |
| PNG  | 无损 | ✅     | 中       | 图标、截图、需要透明度 |
| RAW  | 无   | ❌     | 大       | 专业摄影、科学成像     |

| 色彩空间 | 通道含义           | 特点             | 适用场景       |
| -------- | ------------------ | ---------------- | -------------- |
| RGB      | 红、绿、蓝         | 直观但受光照影响 | 显示、存储     |
| HSV      | 色相、饱和度、明度 | 颜色与亮度分离   | 颜色检测、分割 |
| BGR      | 蓝、绿、红         | OpenCV 默认顺序! | OpenCV 编程    |

| 传感器 | 画质  | 功耗 | 成本 | 用途           |
| ------ | ----- | ---- | ---- | -------------- |
| CCD    | 高    | 高   | 贵   | 医学影像、天文 |
| CMOS   | 中→高 | 低   | 便宜 | 手机、消费相机 |

## 🎯 考试 Checklist

1. ✅ 能定义 Machine Vision（三步工作流：Acquisition → Processing → Interpretation）
2. ✅ 能区分 Machine Vision 和 Computer Vision
3. ✅ 知道像素在灰度图中是单值 `[0-255]`，在 RGB 中是三元组
4. ✅ 知道 RGB 三通道分别代表什么
5. ✅ 理解 HSV 色彩空间各通道含义，以及为什么做颜色检测时优于 RGB
6. ✅ 能区分 JPEG（有损）、PNG（无损+透明度）、RAW（无压缩）
7. ✅ 知道 CCD vs CMOS 传感器的差异
8. ✅ 理解传统 CV 和深度学习 CV 的核心区别（手工 vs 自动特征提取）
9. ✅ 知道 AlexNet / 2012 ImageNet 是深度学习革命的转折点
10. ✅ 知道 OpenCV 默认使用 BGR 通道顺序，不是 RGB
11. ✅ 知道 OpenCV 中像素访问是 `image[y, x]`（行, 列），不是 `image[x, y]`
