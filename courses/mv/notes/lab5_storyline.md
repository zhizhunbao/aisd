## 📍 路线图 (Roadmap)

```
任务：区分猫和狗
  ↓
[方案A] 人规定规则："如果尖耳朵 + 胡须 → 猫"
  ↓ ❌ 失败：规则太多、光照/角度变化让规则全部失效
  ↓
[方案B] 手工提取特征（SIFT, HOG）→ 送入分类器
  ↓ ⚠️ 勉强能用：但特征需要领域专家手工设计，换一个任务就要重来
  ↓
[方案C] 让网络自己从原始像素学特征
  ↓ 问题：全连接网络 → 对 128×128 图像，第一层就需要 ~50亿个参数
  ↓
[方案D] CNN (卷积神经网络)：权重共享 + 局部感受野
  ↓ ✅ 成功：3 个卷积块 + 2 个全连接层，~850万参数，88% 准确率
  ↓
训练策略问题：如何处理数据有限、防止过拟合？
  ↓
[解法] 数据增强 + Dropout + Adam 优化器
  ↓ ✅ val_acc 从 Epoch 1 的 72% 成长到 Epoch 10 的 88%，无过拟合
```

## 🔗 因果叙事 (Causal Narrative)

### 第一幕：为什么"规定规则"不管用？

**问题出发点：** 你能认出猫，计算机能吗？

人类认出猫时不是在执行什么显式规则——你从来没有意识到自己在"检查耳朵形状"。这种"无意识识别"背后是数年视觉经验的积累。

那如果我们试着写出规则呢？

```
规则集：
  IF 尖耳朵 AND 胡须 AND 竖瞳孔 → Probability(Cat) += 0.7
  IF 圆头 AND 小鼻子 → Probability(Cat) += 0.3
  ...
```

**为什么失败？**
- 猫翻身了 → 尖耳朵不在常规位置
- 夜晚照片 → 竖瞳孔看不清
- 卡通猫？ → 胡须可能被风格化了

**结论：** 规则是脆弱的，因为规则依赖固定的视觉属性，而现实图像的**视觉属性会随姿势/光照/拍摄角度变化**。我们需要一种**不依赖人工规则**的方法。

---

### 第二幕：为什么普通全连接网络不够用？

**下一个想法：** 既然不能手写规则，能不能让神经网络自己学？

最简单的神经网络是**全连接网络（Fully-Connected Network）**——每个像素连接到下一层的每个神经元。

**计算一下代价：**

```
128×128 彩色图 → 49,152 个输入
第一个隐层假设有 1024 个神经元

参数量 = 49,152 × 1,024 + 1,024 = 50,332,672 (≈ 5千万)

仅第一层就有 5000 万参数！
```

参数量巨大带来三个问题：
1. **过拟合**：参数太多，模型死记训练图片的噪声而非学到真正规律
2. **不识别位移**：狗在图片左边和右边会被视为"不同的输入"（没有平移不变性）
3. **计算成本高**：训练、推理都慢

**结论：** 全连接网络对图像来说**参数效率太低**，且**不利用图像的空间结构**（相邻像素是相关的，全连接网络无法利用这一点）。

---

### 第三幕：CNN 的核心洞察 — 权重共享

**关键问题：** 图像的哪种结构特性可以被利用？

**洞察 1：局部性（Locality）**
- 一个像素最相关的信息来自它的**邻近像素**，而不是图片角落的像素
- 因此：不需要全连接，只需要连接 3×3 或 5×5 的局部窗口

**洞察 2：平移不变性（Translation Invariance）**
- 无论猫在图片的哪个位置，用来检测"猫耳朵"的特征提取器应该是**同一个**
- 因此：同一个滤波器（kernel）可以在整张图上**滑动**——这就是**权重共享**

**这两个洞察的结合 = 卷积层**

```
全连接层：每个位置独立学习不同的权重
  位置(5,5) 有一套权重
  位置(6,5) 有另一套权重（即使它们相邻）
  → 参数量 ∝ H × W × C

卷积层：同一个 3×3 滤波器在所有位置共享
  → 参数量 = 3 × 3 × C_in × C_out（与图像尺寸无关！）
  → 比全连接减少几个数量级的参数
```

**Lab 5 验证：**
- `Conv2d(3, 32, 3, padding=1)` 只有 **896 个参数**
- 等效的全连接层：128×128×3 → 任意尺寸，参数 ≫ 百万

### 第四幕：特征如何生长 — 三层卷积块的作用

SimpleCNN 有三个卷积块，每层学到的东西是不同的：

```
Layer 1 (Conv2d 3→32, 128→64 after pool):
  学到：边缘 / 颜色渐变 / 简单纹理
  直觉：把照片中的"笔触"找出来

Layer 2 (Conv2d 32→64, 64→32 after pool):
  学到：纹理组合 / 局部形状（毛发方向、皮肤纹理）
  直觉：把几根"笔触"组合成"一块毛发"

Layer 3 (Conv2d 64→128, 32→16 after pool):
  学到：高级语义特征（眼睛、耳朵、嘴形）
  直觉：把"一块毛发"+轮廓组合成"猫脸部件"

FC Layer (128×16×16 → 256 → 2):
  整合所有部件，判断是猫还是狗
```

**为什么要接 MaxPooling？**

池化（Pooling）取区域内最大值，作用是：
1. **缩小特征图尺寸** → 减少后续计算量
2. **引入位移鲁棒性** → 特征稍微位移一些，最大值不变

---

### 第五幕：训练的两个挑战 — 过拟合与收敛

模型定义好了，训练时面临两个主要问题：

#### 挑战1：过拟合（Overfitting）

数据集只有 ~25,000 张图，模型有 850 万参数，参数比数据多——很容易死记数据。

**解法一：数据增强（Data Augmentation）**
```
同一张猫的照片 → 随机水平翻转 → 变成了"另一张" 训练样本
                → 随机旋转 ±15°  → 变成了"又另一张"
→ 实际有效训练样本量翻倍/翻数倍，但没有增加标注成本
```

**解法二：Dropout**
```
训练时，随机关掉 50% 的神经元
每次 forward pass，网络结构都不同
→ 强迫不同神经元子集学会独立完成任务
→ 推理时所有神经元都参与，效果更稳定
```

#### 挑战2：收敛速度与稳定性

**解法：Adam 优化器**
- 对每个参数维护独立的学习率（自适应）
- 对频繁更新的参数用小学习率，对稀少更新的参数用大学习率
- 比普通 SGD（随机梯度下降）收敛更快、更稳定

**Lab 5 验证：**
```
Epoch 1:  val_acc = 72% （刚开始，随机猜测是 50%，已经超出基准线）
Epoch 5:  val_acc = 85% （快速提升阶段）
Epoch 10: val_acc = 88% （趋于稳定，仍有提升空间）
```
训练 loss 和验证 loss 的差距始终很小 → **没有发生过拟合**。

## 📊 关键对比表（Key Comparisons）

### 方案演进对比

| 方案 | 核心思路 | 为什么不够用 |
|------|---------|-------------|
| 手工规则 | 人定义"猫的特征" | 规则脆弱，变角度/光照就失效 |
| 手工特征 + 分类器 (HOG+SVM) | 手工提取特征后分类 | 特征设计需要领域知识，不通用 |
| 全连接网络 | 让网络学 | 参数爆炸，忽视空间结构 |
| **CNN（本Lab）** | 利用局部性+权重共享 | — 当前最佳方案 ✅ |
| 预训练 CNN (ResNet, etc.) | 迁移学习 | 超出本Lab范围 |

### 防止过拟合的三个手段

| 手段 | 作用阶段 | 机制 |
|------|---------|------|
| 数据增强 | 数据预处理 | 人工扩大训练集多样性 |
| Dropout(0.5) | 训练时 | 随机丢弃神经元，防止共适应 |
| 验证集监控 | 训练过程 | 对比 train_loss 和 val_loss，发现过拟合 |
