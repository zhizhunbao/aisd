## Q1: What is Machine Vision?

**Answer:**

Machine vision is a technology that enables machines to **interpret and understand visual information** from the surrounding environment.

It involves three core steps:

1. **Capturing** images or videos using cameras or sensors
2. **Processing** these images to extract useful information
3. **Using** this information to make decisions or perform specific tasks

---

## Q2: What are the applications of Machine Vision?

**Answer:**

### Everyday Applications

| Application | Description |
|---|---|
| **Retail** | Barcode scanning and inventory management |
| **Manufacturing** | Quality checks on the assembly line |
| **Entertainment** | Detection and tracking of objects, enhancing visual effects |
| **Autonomous vehicles** | Lane keeping, blind spot checking, adaptive cruise |

### Advanced Applications

| Application | Description |
|---|---|
| **Autonomous vehicles** | Navigation |
| **Medical imaging** | Diagnostics and surgical assistance |
| **Facial recognition** | Security and personalized experiences |

## Q3: What is the basic workflow of a Machine Vision system?

**Answer:**

The basic workflow consists of **three stages**:

| Step | Description |
|---|---|
| **1. Image Acquisition** | Capturing the image using cameras or sensors |
| **2. Image Processing** | Analyzing and manipulating the image (filtering, edge detection, etc.) |
| **3. Interpretation / Action** | Making decisions based on the processed image |

**Example:** In an automated inspection system in manufacturing, this workflow ensures quality control.

## Q5: What is a pixel?

**Answer:**

A **pixel** is a numerical representation at location (x, y) in an image.

| Type | Representation |
|---|---|
| **Grayscale** | Single value (0–255) representing brightness — 0 = black, 255 = white |
| **Color (RGB)** | Tuple of 3 values (Red, Green, Blue) |

---

## Q6: How has deep learning impacted Machine Vision?

**Answer:**

- AI, especially **deep learning**, has revolutionized Machine Vision
- AI enhances accuracy and enables recognition of **complex patterns**
- **CNNs** are a class of deep neural networks most commonly applied to analyzing visual imagery
- CNNs are powerful for **automated feature extraction** in images
