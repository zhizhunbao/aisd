# Model Evaluation & Metrics 第一性原理

> 📚 Book: Hastie et al., [《ESL》](../../../textbooks/hastie_esl.pdf), Ch.7
> 📚 Book: Murphy, [《PML1》](../../../textbooks/murphy_pml1.pdf), Ch.5

---

## 核心问题链

> 用"5 个为什么"递归追问，从表层功能到不可再分公理。

1. **模型评估在做什么？** → 用数字量化模型对未见数据的预测能力
2. **为什么要量化预测能力？** → 因为训练误差不能反映泛化能力——模型可能只是"记住了"训练数据
3. **为什么训练误差不可靠？** → 因为在有限样本上最小化经验风险（训练误差）会导致过拟合——模型的复杂度超过了数据能支撑的信息量
4. **过拟合的根基是什么？** → 偏差-方差分解（Bias-Variance Decomposition）：测试误差 = 偏差² + 方差 + 不可约噪声。训练误差只降低了偏差项，但方差（对特定训练集的敏感性）却增加了
5. **偏差-方差分解能否继续拆分？** → 不能 → **到达公理：** 泛化误差分解是统计学习理论的基石，后续所有模型选择/评估方法都是在管理 bias-variance trade-off

## 公理与基本假设

### 公理 1: i.i.d. 假设 (Independent and Identically Distributed)

**陈述：** 训练样本和测试样本独立地从同一个未知分布 P(X, Y) 中抽取。

**白话：** 你拿到的数据和将来要预测的数据来自同一个"世界"，而且每个数据点之间不互相影响。

**来源：** 统计学习理论的基本公设，贯穿 ESL 全书。

**可验证性：**
- ✅ 成立：标准的监督学习数据集（每个样本独立采集，分布稳定）
- ❌ 不成立：时间序列（相邻数据点相关）、概念漂移（分布随时间变化）、抽样偏差（训练数据非随机）

> 📚 Book: Hastie et al., [《ESL》](../../../textbooks/hastie_esl.pdf), Ch.7.2

### 公理 2: 偏差-方差分解 (Bias-Variance Decomposition)

**陈述：** 对于均方误差损失，模型在测试点 x₀ 上的期望预测误差可分解为：E[(y - f̂(x₀))²] = Bias²(f̂(x₀)) + Var(f̂(x₀)) + σ²

**白话：** 模型的错误来自三个来源：系统性偏差（偏差）、对训练数据的敏感程度（方差）、和无法消除的噪声。前两个可以调控，第三个是天花板。

**来源：** 概率论中期望的线性性 + 方差定义的直接推导。

**可验证性：**
- ✅ 成立：均方误差损失 + 回归问题
- ⚠️ 部分成立：分类问题下分解形式不同（0-1 loss 下没有简洁的加法分解）
- ❌ 不成立：非标准损失函数下没有保证

> 📚 Book: Hastie et al., [《ESL》](../../../textbooks/hastie_esl.pdf), Ch.7.3, Eq. 7.9

### 公理 3: 有限样本下的估计不确定性

**陈述：** 任何基于有限样本的统计量（包括模型性能指标）都是随机变量，具有采样方差。

**白话：** 你算出来的 Accuracy = 0.85 不是一个确定的数字，而是一个估计值。如果你重新采样，它可能是 0.83 或 0.87。样本越少，波动越大。

**来源：** 中心极限定理和大数定律的直接推论。

**可验证性：**
- ✅ 永远成立（只要样本是有限的）
- 但不确定性的大小取决于样本量和数据分布的复杂度

> 📚 Book: Hastie et al., [《ESL》](../../../textbooks/hastie_esl.pdf), Ch.7.10

### 公理 4: 决策论框架 — 不同错误有不同代价

**陈述：** 一个最优决策规则应最小化期望风险 R(f) = E[L(y, f(x))]，其中 L 是损失函数。

**白话：** "什么才算好"取决于你怎么定义"错"的代价。癌症漏诊和垃圾邮件误判的"错"显然不一样重。

**来源：** 统计决策论（Wald, 1950）+ 贝叶斯决策论。

**可验证性：**
- ✅ 成立：损失函数可以正确反映业务代价时
- ❌ 不成立：损失函数无法量化时（如"用户信任度"——很难用数字表达）

> 📚 Book: Murphy, [《PML1》](../../../textbooks/murphy_pml1.pdf), Ch.5.1

## 从公理到技术的推导链

### Step 1: 从 i.i.d. 假设 → 泛化误差的定义

**推理：** 因为数据来自同一个分布（公理 1），所以我们可以定义"泛化误差"= 模型在新样本上的期望损失。如果分布不同（比如时间漂移），这个定义就没有意义。

**结果：** 泛化误差 = E_{(x,y)~P}[L(y, f̂(x))]

### Step 2: 从偏差-方差分解 → 模型选择的必要性

**推理：** 因为泛化误差包含偏差和方差两个矛盾的项（公理 2），所以不存在一个"最复杂"或"最简单"的最优模型——我们必须在偏差和方差之间权衡。这就需要**模型选择**工具（交叉验证）。

**结果：** 需要一种方法来估计泛化误差 → 交叉验证

### Step 3: 从有限样本不确定性 → 交叉验证的设计

**推理：** 因为任何估计都有采样方差（公理 3），单次 train/test split 的结果不可靠。K-Fold CV 通过 K 次重复来降低方差，但代价是计算量增加 K 倍。

**结果：** K-Fold CV（K=5 或 10 在偏差和方差之间取得平衡）

### Step 4: 从决策论 → 多指标评估体系

**推理：** 因为不同错误有不同代价（公理 4），所以没有一个"万能指标"。Accuracy 假设所有错误等价，F1 假设 FN 和 FP 同等重要，MCC 平衡四格。选择哪个指标取决于你的损失函数。

**结果：** 根据业务场景选择指标，或报告多个互补指标

### 推导链全景图

```
公理 1: i.i.d. ──→ 泛化误差可定义 ──→ "评估什么"
        │
公理 2: Bias-Var ──→ 模型选择必要性 ──→ "为什么需要评估"
        │
公理 3: 有限样本 ──→ 估计有不确定性 ──→ "怎么评（K-Fold CV）"
        │
公理 4: 决策论 ──→ 不同错误不同代价 ──→ "评什么指标（P/R/F1/MCC/AUC）"
```

## 如果公理不成立？

### 公理 1 失效：数据不是 i.i.d.

**如果不成立：** 时间序列数据（相邻点相关）、概念漂移（分布随时间变化）、域迁移（训练和部署数据来自不同分布）

**技术后果：** 标准 K-Fold CV 给出过度乐观的估计（未来数据混入训练集）

**替代方案：** TimeSeriesSplit、Walk-forward validation、领域自适应方法

### 公理 2 失效：偏差-方差分解不适用

**如果不成立：** 使用 0-1 loss（分类错误率）时，分解形式不再是简洁的加法分解

**技术后果：** 不能简单地说"降低方差就好"——分类问题中偏差和方差的交互更复杂

**替代方案：** 使用 Domingos (2000) 的分类问题偏差-方差分解，或直接用 CV 做经验估计

### 公理 3 失效：样本看起来"够大"但实际不够

**如果不成立：** 在高维小样本场景下（如基因组学：n=100, p=10000），即使用 CV 也可能不稳定

**技术后果：** CV 方差很大，每折结果差异悬殊

**替代方案：** 重复交叉验证（Repeated CV）、.632+ Bootstrap、报告置信区间

### 公理 4 失效：损失函数无法量化

**如果不成立：** "用户信任度下降"、"品牌声誉损伤"——这些代价很难用数字表达

**技术后果：** 选择任何标准指标都可能不完全反映真实业务影响

**替代方案：** 人工评估（A/B testing with human judges）、代理指标 + 业务专家判断

## 第一性原理速查表

| 公理/假设 | 一句话陈述 | 成立条件 | 失效后果 |
|----------|-----------|---------|---------| 
| i.i.d. | 数据来自同一分布且独立 | 标准监督学习 | CV 结果不可靠 → TimeSeriesSplit |
| Bias-Var | 泛化误差 = 偏差² + 方差 + 噪声 | MSE 损失、回归 | 分类下分解更复杂 → 经验 CV |
| 有限样本 | 任何估计都有采样方差 | 永远成立 | 报告置信区间、重复 CV |
| 决策论 | 不同错误不同代价 | 代价可量化 | 人工评估、A/B testing |
