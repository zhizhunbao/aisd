# Graph Neural Networks Knowledge Map

> 来源课程：Stanford CS224W (Jure Leskovec) · Hamilton《Graph Representation Learning》
> 级别：研究生 Master · 角色：ML 工程师
> 前置课程：`deep-learning` · `machine-learning` · `linear-algebra`

## 课程定位

GNN 将深度学习从规则网格 (图像/序列) 推广到任意图结构数据。

| 维度 | Deep Learning (研究生) | GNN (研究生) |
|------|----------------------|-------------|
| 数据类型 | 图像 (网格) / 文本 (序列) | 图 (任意拓扑) |
| 核心操作 | 卷积 / 注意力 | 消息传递 / 邻域聚合 |
| 典型任务 | 分类 / 生成 | 节点分类 / 链接预测 / 图分类 |
| 应用 | CV / NLP | 社交网络 / 分子 / 推荐 / 知识图谱 |
