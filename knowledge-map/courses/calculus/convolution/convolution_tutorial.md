# 卷积 (Convolution) 教程 — 信号处理视角

> **前置知识：** 积分/求和 | 函数图像平移/翻转 | δ 函数基本概念
> **参考来源：** Oppenheim & Willsky, 《Signals and Systems》, Ch.2–4

---


## Section 0: 前置知识速查

1. **积分**：$\int f(t) dt$ 是"函数曲线下的面积"
2. **函数翻转**：$f(t) \to f(-t)$，关于 $y$ 轴做镜像
3. **函数平移**：$f(t) \to f(t-t_0)$，整个图向右移 $t_0$ 个单位
4. **δ 函数**：无穷窄、面积为 1 的脉冲，$\int f(t)\delta(t-t_0)dt = f(t_0)$（筛选性质）

> 📚 Book: Oppenheim & Willsky, Ch.1

---


## Section 1: 它解决什么问题（Why）

### 没有它会怎样？

- 🔥 **无法预测系统输出**：你有一个滤波器，知道它对脉冲的响应 $h(t)$，但来了一个任意输入信号 $x(t)$——输出是什么？不用卷积就只能一个点一个点模拟。

- 🔥 **信号处理失去统一框架**：模糊、锐化、边缘检测、回声、混响——这些不同的效果看起来毫不相关。没有卷积，就没有统一描述 LTI 系统的工具。

- 🔥 **频域分析断线**：时域操作与频域操作之间需要一个桥梁——卷积定理提供了这个桥梁。没有它，FFT 就只是一个变换，不与实际系统操作相连。

### 它的核心价值

1. **一个公式描述所有 LTI 系统**：只要知道脉冲响应 $h(t)$，$y(t) = x(t) * h(t)$ 就能计算系统对**任何输入**的输出。
2. **连接时域与频域**：卷积定理——时域卷积 = 频域乘法，让复杂的积分变成简单的乘法。
3. **计算可加速**：通过 FFT，$O(N^2)$ 的直接卷积变为 $O(N \log N)$。
4. **统一理解多种操作**：模糊 = 与高斯核卷积；边缘检测 = 与微分核卷积；回声 = 与延迟脉冲卷积。

> 📚 Book: Oppenheim & Willsky, Ch.2.4

## Section 2: 它怎么工作的（How）

### 2.1 直觉：翻转-滑动-求和

**为什么要"翻转"？**

想象你把一叠扑克牌（信号 $f$）推过一个窗口（核 $g$）。当牌序列"推进"窗口时，牌的顺序和窗口的顺序是**相反的**——第一张牌先遇到窗口最右边的位置。这种"倒序叠加"的效果，正好对应数学上的翻转 $g(\tau) \to g(t - \tau)$。

```
时间 t=0:     f: ──→ [1, 2, 3]
              g:            [a, b] ←── 翻转后的 g
              重叠区域: f[0]·b = 1·b

时间 t=1:     f: ──→ [1, 2, 3]
              g:        [a, b]
              重叠区域: f[0]·a + f[1]·b

时间 t=2:     f: ──→ [1, 2, 3]
              g:    [a, b]
              重叠区域: f[1]·a + f[2]·b

时间 t=3:     f: ──→ [1, 2, 3]
              g: [a, b]
              重叠区域: f[2]·a
```

> 📚 Book: Oppenheim & Willsky, Ch.2.4

### 2.2 LTI 系统视角的推导

**核心思想：** 任何信号都可以分解为加权的脉冲之和。

1. **离散信号分解：** $x[n] = \sum_k x[k] \cdot \delta[n-k]$（用 δ 脉冲表示）
2. **线性性质：** $y[n] = \sum_k x[k] \cdot h[n-k]$（每个脉冲独立通过系统，输出叠加）
3. → $y[n] = x[n] * h[n]$

```
输入分解          每个脉冲的响应          叠加
x[0]·δ[n]    → x[0]·h[n]           ┐
x[1]·δ[n-1]  → x[1]·h[n-1]         ├→ y[n] = Σ x[k]·h[n-k]
x[2]·δ[n-2]  → x[2]·h[n-2]         │         = x * h
  ...          ...                  ┘
```

> 📚 Book: Oppenheim & Willsky, Ch.2.4

### 2.3 频域视角

```
时域                     频域
┌───────┐    FFT    ┌───────┐
│ f(t)  │ ────────→ │ F(ω)  │
└───────┘           └───┬───┘
    *                    ×    ← 复杂积分变成简单乘法！
┌───────┐    FFT    ┌───┴───┐
│ g(t)  │ ────────→ │ G(ω)  │
└───────┘           └───────┘
    ‖                    ‖
    ▼                    ▼
┌───────┐   IFFT   ┌───────┐
│ f*g   │ ←─────── │ F·G   │
└───────┘           └───────┘
```

> 📚 Book: Oppenheim & Willsky, Ch.4.4

## Section 3: 局限性

1. **仅适用于 LTI 系统**：卷积完整描述系统行为的前提是系统线性且时不变。非线性系统（如 ReLU、阈值器）不能用单次卷积描述。

2. **无限支撑问题**：连续卷积的积分范围是 $(-\infty, \infty)$，实际计算中需要截断——引入截断误差。

3. **因果性约束**：实时系统要求 $h(t) = 0$ for $t < 0$（因果系统）。非因果的理想滤波器无法物理实现。

4. **循环卷积 vs 线性卷积的陷阱**：FFT 计算的是循环卷积，直接使用会产生"混叠"——需要补零避免。

> 📚 Book: Oppenheim & Willsky, Ch.2, Ch.8

## Section 4: 方案对比

| 方案 | 计算方式 | 复杂度 | 适用场景 |
|------|---------|--------|---------|
| 直接卷积 | 逐点相乘求和 | $O(N_1 \cdot N_2)$ | 短序列、核很小 |
| FFT 卷积 | FFT → 相乘 → IFFT | $O(N \log N)$ | 长序列 |
| 重叠相加法 | 分段 FFT 卷积 | $O(N \log N)$ | 实时流处理 |
| 重叠保留法 | 分段 FFT + 丢弃混叠 | $O(N \log N)$ | 实时流处理 |
| 矩阵乘法 (im2col) | 展开为矩阵乘法 | $O(N_1 \cdot N_2)$ | GPU 上的 DL 卷积 |

> 📚 Book: Oppenheim & Willsky, Ch.8
