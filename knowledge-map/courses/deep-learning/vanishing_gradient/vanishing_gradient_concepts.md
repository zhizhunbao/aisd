# 梯度消失 (Vanishing Gradient) 核心概念

> 📖 Paper: Hochreiter (1991) | Hochreiter & Schmidhuber (1997) | Pascanu et al. (2013)

---


## 术语定义

### 梯度 (Gradient)

损失函数对参数的偏导数，告诉参数该往哪个方向调、调多少。可以理解为"下山时脚下的坡度"——坡越陡，调整越大。

> 易混淆：**导数**是一维的，**梯度**是多维的（向量）

### 梯度消失 (Vanishing Gradient)

反向传播中梯度在多层/时间步连乘后趋近于 0，导致远端权重几乎不更新。就像传话游戏中每个人只传递一半音量，传几轮后就完全听不见了。

> 易混淆：**梯度爆炸** — 方向相反的问题（趋近 ∞ 而非 0）

### 梯度爆炸 (Exploding Gradient)

反向传播中梯度在多层/时间步连乘后趋近于 ∞，权重更新失控，loss 变 NaN。比梯度消失容易检测（NaN 立刻暴露），但同样破坏训练。

> 易混淆：**梯度消失** — 一个让训练停滞，一个让训练崩溃

### BPTT (Backpropagation Through Time)

把 RNN 在时间维度上展开成多个副本后，沿时间方向做反向传播。本质上就是标准反向传播应用到展开的 RNN 上，但梯度要穿越所有时间步。

> 易混淆：**普通 Backprop** — BPTT 多了"穿越时间步"这一维度

### 细胞状态 (Cell State)

LSTM 中专门用来传递长期记忆的"信息高速公路"。关键创新：**通过加法而非乘法更新**，所以梯度可以长距离流通而不衰减。

> 易混淆：**隐藏状态** — 细胞状态是长期记忆（保险箱），隐藏状态是短期工作记忆（桌面）

### 隐藏状态 (Hidden State)

RNN/LSTM 每一步的短期工作记忆，会被直接用于预测输出。在 LSTM 中，它是细胞状态经过输出门过滤后的结果。

> 易混淆：**细胞状态** — 隐藏状态直接参与预测，细胞状态不直接输出

### 门控机制 (Gating Mechanism)

LSTM/GRU 中用 sigmoid 函数控制信息流通的"开关"。sigmoid 输出 0~1 之间的值：0=完全关闭（不让信息通过），1=完全打开。门的值是**学出来的**，不是手动设定的。

> 易混淆：**注意力机制 (Attention)** — 门控作用于时间步内部，注意力作用于时间步之间

### 遗忘门 (Forget Gate)

LSTM 三门之一。看当前输入和上一步隐藏状态，决定细胞状态中**哪些旧信息该丢弃**。公式：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$

> 类比：清理保险箱——"这个旧笔记还有用吗？没用就扔掉腾空间"

### 输入门 (Input Gate)

LSTM 三门之一。决定当前输入中**哪些新信息要写入细胞状态**。配合候选状态 $\tilde{c}_t$ 一起工作：$i_t$ 控制"存多少"，$\tilde{c}_t$ 是"存什么"。

> 类比：往保险箱存东西——"这条新信息值得锁进去吗？存多少？"

### 输出门 (Output Gate)

LSTM 三门之一。决定细胞状态中**哪些信息要输出到隐藏状态**，用于当前步的预测。不是所有长期记忆都跟当前任务相关。

> 类比：从保险箱取东西——"现在做题需要用到哪些存着的知识？"

### 梯度裁剪 (Gradient Clipping)

当梯度的范数超过设定阈值时，按比例缩小梯度。主要用于防止**梯度爆炸**（不解决梯度消失）。是训练 RNN/LSTM 的标准做法。

> 易混淆：**权重衰减 (Weight Decay)** — 梯度裁剪限制梯度大小，权重衰减限制权重大小

### 残差连接 (Residual/Skip Connection)

在网络中加一条"捷径"，让信息（和梯度）可以跳过中间层直接传递。$y = F(x) + x$，其中 $+x$ 就是残差连接。ResNet（2015）的核心创新。

> 易混淆：**密集连接 (Dense Connection)** — 残差连接跳过若干层，密集连接连接到所有前面的层

> 📖 Paper: Hochreiter & Schmidhuber (1997) | Pascanu et al. (2013) | He et al., "Deep Residual Learning" (2015)

## 概念辨析

### 梯度消失 vs 梯度爆炸

| 维度 | 梯度消失 (Vanishing) | 梯度爆炸 (Exploding) |
|------|---------------------|---------------------|
| **本质** | 连乘因子 < 1 → 梯度→0 | 连乘因子 > 1 → 梯度→∞ |
| **症状** | 训练停滞，loss 不再下降 | loss 突然变 NaN 或 Inf |
| **哪些层受影响** | 远离输出的早期层/时间步 | 所有层，但爆炸更明显 |
| **常见激活函数** | sigmoid / tanh（导数 < 1） | 线性激活 + 大权重 |
| **解决方案** | LSTM, GRU, 残差连接, ReLU | 梯度裁剪, 权重正则化 |
| **检测难度** | 难（静默失败） | 易（NaN/极大值） |

> 📖 Paper: Pascanu et al. (2013), Sections 2-3

### 隐藏状态 vs 细胞状态 (LSTM)

| 维度 | 隐藏状态 (h_t) | 细胞状态 (c_t) |
|------|---------------|---------------|
| **本质** | 短期工作记忆 | 长期信息存储 |
| **更新方式** | 经过 tanh + 输出门 | 加法更新（遗忘+输入） |
| **直接用途** | 用于预测输出 y_t | 不直接用于输出 |
| **梯度流动** | 经过非线性变换，容易衰减 | "高速公路"，梯度可以长距离流通 |
| **类比** | 你正在想什么 | 你记在笔记本上的知识 |

> 📖 Paper: Hochreiter & Schmidhuber (1997), Sections 2-4

### RNN vs LSTM vs GRU

| 维度 | Vanilla RNN | LSTM | GRU |
|------|-------------|------|-----|
| **隐藏状态数量** | 1 个 (h) | 2 个 (h + c) | 1 个 (h) |
| **门的数量** | 0 | 3（遗忘/输入/输出） | 2（重置/更新） |
| **长期记忆** | ❌ 严重消失 | ✅ 细胞状态保持 | ✅ 更新门保持 |
| **参数量** | 最少 | 最多 | 中等 |
| **训练速度** | 快但学不好 | 慢但效果好 | 折中 |

> 📖 Paper: Hochreiter & Schmidhuber (1997) | Cho et al. (2014)

## 核心属性

### 信息架构

```
┌── 梯度消失问题 ──────────────────────────────────┐
│                                                  │
│  ┌── 根因分析 ────────────────┐                   │
│  │ • 链式法则连乘             │                   │
│  │ • sigmoid/tanh 导数 < 1   │                   │
│  │ • Wh 谱半径 < 1           │                   │
│  └────────────────────────────┘                   │
│                                                  │
│  ┌── 解决方案 ────────────────┐                   │
│  │ 架构级:                   │                   │
│  │ • LSTM (门控 + 加法更新)   │                   │
│  │ • GRU (简化门控)          │                   │
│  │ • 残差连接               │                   │
│  │ • Transformer (无递归)    │                   │
│  │                           │                   │
│  │ 技巧级:                   │                   │
│  │ • ReLU 激活               │                   │
│  │ • 权重初始化 (Xavier/He)  │                   │
│  │ • Batch Normalization     │                   │
│  └────────────────────────────┘                   │
└──────────────────────────────────────────────────┘
```

> 📖 Paper: Pascanu et al. (2013), Sections 2-5

### 适用场景 ✅

- 诊断 RNN 训练中 loss 停滞不下降的原因
- 选择序列模型架构（RNN vs LSTM vs GRU）
- 设计深层网络时预防训练困难
- 理解为什么 Transformer 不需要递归

### 不适用场景 ❌

- 浅层网络（< 3 层），梯度消失不显著
- 已使用 Transformer 架构（无递归，不存在此问题）
- 非序列任务的 CNN（可通过残差连接+BN解决）

## 速查表

| 项 | 说明 | 示例 |
|-----|------|------|
| 消失条件 | \|Wh\| < 1 + 饱和激活函数 | sigmoid 导数最大 0.25 |
| 爆炸条件 | \|Wh\| > 1 | 权重未正确初始化 |
| LSTM 核心 | 细胞状态加法更新 | c_t = f_t·c_{t-1} + i_t·c̃_t |
| GRU 核心 | 更新门插值 | h_t = (1-z_t)·h_{t-1} + z_t·h̃_t |
| 梯度裁剪 | 截断梯度范数 | `torch.nn.utils.clip_grad_norm_(params, 5)` |
| Xavier 初始化 | W ~ N(0, 1/n_in) | 保持前向/反向方差一致 |
