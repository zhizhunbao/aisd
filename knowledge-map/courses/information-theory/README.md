# Information Theory Knowledge Map

> 来源课程：MIT 6.441 (Yury Polyanskiy) · Cover & Thomas《Elements of Information Theory》
> 级别：研究生 Master · 角色：ML 工程师
> 前置课程：`probability` · `statistics`

## 课程定位

信息论为 ML 提供根基概念 — 交叉熵损失、KL 散度、互信息、信息瓶颈都出自此处。

| 维度 | Probability (基础) | Information Theory (研究生) |
|------|--------------------|-----------------------------|
| 重点 | 概率分布 + 大数定律 | 熵 + 信道容量 + 编码定理 |
| 核心定理 | 贝叶斯 + 中心极限 | Shannon 信源/信道编码定理 |
| ML 连接 | 先验/后验/似然 | 交叉熵损失 / KL 散度 / 信息瓶颈 |
